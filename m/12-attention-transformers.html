Attention and the Transformer

Soft dictionary lookup, derived from the variance of a dot product to a working model.

on this page

Why this module exists

This is the module the rest of the curriculum stands on. Every model configuration you will read from here on — n_heads, n_kv_heads, rope_theta, intermediate_size, max_position_embeddings — is a parameter of the mechanism derived below, and every claim about context length, inference cost, or training throughput is an arithmetic consequence of it. Skip it and M13's architecture zoo is a list of acronyms, M16's scaling laws are numbers without a cost model, and M19's inference engineering is folklore. The transformer is also the cleanest example in the whole of machine learning of a design where every detail is load-bearing. Remove the $1/\sqrt{d_k}$ and deep stacks stop training. Remove the residual connections and the gradient dies at depth 12. Put the normalization on the wrong side of the residual and you need a learning-rate warmup you cannot explain. Move the mask by one position and your model silently learns to copy its input. There is no part of this architecture you can treat as a convention.

Prerequisites check

  1. Write the softmax of a vector and its Jacobian $\partial p_i/\partial z_j$. [M03]
  2. Multiply a $3\times4$ matrix by a $4\times5$; how many multiply-accumulates, and what are the shapes? [M01]
  3. A block computes $\mathbf{y} = \mathbf{x} + f(\mathbf{x})$. What is $\partial\mathbf{y}/\partial\mathbf{x}$? [M07]
  4. LayerNorm normalizes over which axes, and how does that differ from BatchNorm on a sequence? [M08]
  5. What does the inner product $\langle\mathbf{a},\mathbf{b}\rangle$ measure, and what does it ignore? [M01]
  6. For independent zero-mean $X, Y$ with variances $\sigma_X^2, \sigma_Y^2$, what is $\mathrm{Var}(XY)$? [M03]
Answers 1. $p_i = e^{z_i}/\sum_j e^{z_j}$; $\partial p_i/\partial z_j = p_i(\delta_{ij} - p_j)$, i.e. $\operatorname{diag}(\mathbf{p}) - \mathbf{p}\mathbf{p}^\top$. Note it is rank-deficient: softmax is invariant to adding a constant to all logits, so the Jacobian annihilates $\mathbf{1}$. 2. $3\times5$ output; $3\cdot4\cdot5 = 60$ multiply-accumulates. Cost scales as the product of all three dimensions. 3. $\mathbf{I} + \partial f/\partial\mathbf{x}$ — the identity is always present, which is what makes the product of block Jacobians $\prod_l(\mathbf{I}+\mathbf{J}_l)$ well-conditioned versus $\prod_l\mathbf{J}_l$. 4. LayerNorm normalizes across the *feature* axis for each token independently, so it does not couple different sequence positions and behaves identically in training and inference. BatchNorm normalizes across the batch (and, for images, space), coupling positions and requiring running statistics. 5. Alignment: $\langle\mathbf{a},\mathbf{b}\rangle = \|\mathbf{a}\|\|\mathbf{b}\|\cos\theta$. It ignores magnitude in the sense that scaling either vector scales the product, and it is symmetric — it cannot express "a is a query for b" differently from the reverse. 6. For zero-mean independent variables, $\mathrm{Var}(XY) = \mathbb{E}[X^2]\mathbb{E}[Y^2] - (\mathbb{E}X)^2(\mathbb{E}Y)^2 = \sigma_X^2\sigma_Y^2$.

Core concepts

Attention as a soft dictionary lookup

Intuition. A Python dictionary maps a key to exactly one value: d[k] looks up k and returns the stored v, or raises. That is content-based addressing, and it is powerful — but it is also brittle, because it needs an exact key match and it can only return one thing. Now soften both constraints: let every key be a partial match, and return a blend of all values, weighted by how well each key matches. That is attention. Nothing more.

Formal definition. A hard lookup with keys $\mathbf{k}_1,\ldots,\mathbf{k}_n$ and values $\mathbf{v}_1,\ldots,\mathbf{v}_n$ is

$$ \mathbf{y} = \mathbf{v}_{j^\star}, \qquad j^\star = \arg\min_j \|\mathbf{q} - \mathbf{k}_j\| . $$

Replace the $\arg\min$ with a softmax over negative distances, or equivalently over inner products, and you get

$$ \mathbf{y} = \sum_{j=1}^{n}\alpha_j\,\mathbf{v}_j,\qquad \alpha_j = \frac{\exp\big(\langle\mathbf{q},\mathbf{k}_j\rangle/\tau\big)}{\sum_{j'}\exp\big(\langle\mathbf{q},\mathbf{k}_{j'}\rangle/\tau\big)} . $$

The temperature $\tau$ controls the sharpness: $\tau\to0$ recovers the hard lookup, $\tau\to\infty$ gives a uniform average. In the transformer $\tau = \sqrt{d_k}$ and the inner product is computed in a learned space rather than the input space.

Why it is built this way. The alternative — carrying state forward through time — was derived in M11 and has a specific, fatal property: the state is a single fixed-size vector with no address space. It cannot say "retrieve the token that is the subject of this verb". Attention gives the model a read operation whose location is computed from the data at inference time, so the function "copy the token that matches this pattern" is representable as a function, regardless of how far away that token is. This is the capability that recurrent models cannot express cheaply, and it is the intuitive reason induction heads and in-context learning exist at all.

Worked micro-example. Four keys in $\mathbb{R}^2$: $\mathbf{k}_1=(1,0)$, $\mathbf{k}_2=(0,1)$, $\mathbf{k}_3=(1,1)/\sqrt2$, $\mathbf{k}_4=(-1,0)$, with values $\mathbf{v}_1=(1,0)$, $\mathbf{v}_2=(0,1)$, $\mathbf{v}_3=(1,1)$, $\mathbf{v}_4=(0,0)$. Query $\mathbf{q}=(1,0)$.

$$ \langle\mathbf{q},\mathbf{k}\rangle = (1,\;0,\;0.707,\;-1). $$

With $\tau=1$: $e^{(\cdot)} = (2.718,\;1,\;2.028,\;0.368)$, summing to $6.114$, so $\boldsymbol{\alpha} = (0.4446,\;0.1636,\;0.3317,\;0.0602)$, and

$$ \mathbf{y} = 0.4446(1,0) + 0.1636(0,1) + 0.3317(1,1) + 0.0602(0,0) = (0.776,\;0.495). $$

With $\tau = 0.1$ the same scores give $\boldsymbol{\alpha}\approx(1.000,\;0.000,\;0.001,\;0.000)$: the lookup becomes hard. That is the entire behaviour of the temperature knob, and the reason the $1/\sqrt{d_k}$ divisor matters — it is a temperature, and a badly chosen one is either too sharp to train or too flat to be selective.

Scaled dot-product attention and where $1/\sqrt{d_k}$ comes from

Intuition. The dot product of two random $d_k$-dimensional vectors grows with $d_k$ — longer vectors have more room to align. Feed logits whose spread grows with $d_k$ into a softmax and it saturates into a one-hot vector. A one-hot softmax has zero Jacobian, so nothing learns. Dividing by $\sqrt{d_k}$ rescales the logits back to unit variance, and only $\sqrt{d_k}$ does exactly that.

Formal definition. For $\mathbf{Q}\in\mathbb{R}^{n\times d_k}$, $\mathbf{K}\in\mathbb{R}^{n\times d_k}$, $\mathbf{V}\in\mathbb{R}^{n\times d_v}$:

$$ \operatorname{Attn}(\mathbf{Q},\mathbf{K},\mathbf{V}) = \operatorname{softmax}\!\left(\frac{\mathbf{Q}\mathbf{K}^\top}{\sqrt{d_k}} + \mathbf{M}\right)\mathbf{V}, $$

where the softmax is applied independently to each of the $n$ rows and $\mathbf{M}$ is an additive mask.

The variance argument, in two lines. Take $\mathbf{q},\mathbf{k}\in\mathbb{R}^{d_k}$ with components iid, mean $0$, variance $\sigma^2$. Then $s = \sum_{i=1}^{d_k}q_ik_i$ has $\mathbb{E}[s] = 0$ and, by independence and Problem 6 of the prerequisites,

$$ \mathrm{Var}(s) = \sum_{i=1}^{d_k}\mathrm{Var}(q_ik_i) = \sum_{i=1}^{d_k}\sigma^2\cdot\sigma^2 = d_k\,\sigma^4 . $$

So the standard deviation is $\sigma^2\sqrt{d_k}$, which grows as $\sqrt{d_k}$. Dividing by $\sqrt{d_k}$ gives variance $\sigma^4$ — unit variance for $\sigma=1$, independent of $d_k$. The full derivation, including the saturation argument and why the standard deviation rather than the variance is the thing to normalize, is Derivation 1.

Why it is built this way. Because at initialization (and approximately throughout training, since LayerNorm keeps activations unit-scale) the logits are zero-mean with spread $\sqrt{d_k}$. Empirically, on one random attention row with 8 keys:

$d_k$ logit std (raw) $p_{\max}$ (raw) entropy (raw) $p_{\max}$ (scaled) entropy (scaled)
$4$ $0.99$ $0.343$ $1.725$ $0.229$ $1.970$
$64$ $2.92$ $0.832$ $0.623$ $0.213$ $2.015$
$1024$ $33.35$ $1.000$ $0.000$ $0.420$ $1.682$

Maximum entropy over 8 keys is $\ln 8 = 2.079$. Unscaled, a $d_k = 1024$ head is already a hard argmax at initialization — the softmax is saturated, its Jacobian is zero, and the gradient cannot teach the head to be selective because it is already maximally selective in an arbitrary direction. Scaled, entropy stays in the useful range at every $d_k$. This is exactly the failure mode diagnosed in M06 for saturating activations, reappearing inside the softmax.

Worked micro-example. $\mathbf{q} = (2,0)$, keys $\mathbf{k}_1=(1,2)$, $\mathbf{k}_2=(1,0)$, $\mathbf{k}_3=(1,1)$, so raw scores are $2, 2, 2$ — identical, and the (1/\sqrt{2}) divisor does not change that. A more informative pair: $\mathbf{q}=(1,2)$, $\mathbf{k}_1=(1,0)\Rightarrow\langle\mathbf{q},\mathbf{k}_1\rangle = 1$, $\mathbf{k}_2=(0,1)\Rightarrow 2$, $\mathbf{k}_3=(1,1)\Rightarrow 3$. Divided by $\sqrt{2} = 1.414$: scores $(0.707, 1.414, 2.121)$. Softmax: $e^{(\cdot)} = (2.028, 4.113, 8.343)$, sum $14.484$, giving $\boldsymbol{\alpha} = (0.140,\;0.284,\;0.576)$. Unscaled, the same scores would give $(0.090,\;0.245,\;0.665)$ — markedly sharper. The divisor is doing real work even at $d_k = 2$; at $d_k = 1024$ it is the difference between learning and not.

Hover a query token and watch its attention weights light up across the keys, then toggle the causal mask to see the upper triangle vanish. Watch two things: the weights always sum to 1 across the *visible* keys, and turning the mask on changes the weights for early positions the most, because they have the fewest keys available.

Q, K, V geometrically

Intuition. Every token emits three vectors. The query says what this token is looking for; the key advertises what this token contains; the value is what it hands over if chosen. They are three different learned views of the same token, because "what I need" and "what I offer" are different questions.

Formal definition. With $\mathbf{W}_Q,\mathbf{W}_K,\mathbf{W}_V\in\mathbb{R}^{d\times d_k}$:

$$ \mathbf{Q} = \mathbf{X}\mathbf{W}_Q,\quad \mathbf{K} = \mathbf{X}\mathbf{W}_K,\quad \mathbf{V} = \mathbf{X}\mathbf{W}_V,\quad \mathbf{S}_{ij} = \frac{\mathbf{q}_i^\top\mathbf{k}_j}{\sqrt{d_k}} = \frac{\mathbf{x}_i^\top\mathbf{W}_Q^\top\mathbf{W}_K\mathbf{x}_j}{\sqrt{d_k}} . $$

Note what the score really is: a bilinear form with matrix $\mathbf{W}_Q^\top\mathbf{W}_K \in \mathbb{R}^{d\times d}$. Its rank is at most $d_k$ — so however wide the model is, each head can only compare tokens along $d_k$ learned directions. That is not a limitation to be fixed; it is the design. Many heads with small $d_k$ give many different low-rank comparisons rather than one high-rank one, which is what makes specialization possible.

Why it is built this way. Three reasons, each a distinct design decision. (i) Decoupling role from content: a token can be a good key for one head and a good value for another, because the projections differ. Without separate $\mathbf{W}_K$ and $\mathbf{W}_V$ a token could only offer what it advertises. (ii) Asymmetry: the form $\mathbf{x}_i^\top\mathbf{W}_Q^\top\mathbf{W}_K\mathbf{x}_j$ is not symmetric, so "i attends to j" and "j attends to i" are different numbers — a plain inner product cannot express the direction of the relation. (iii) Rank control: the low rank means each head's score matrix is a structured object, which is why heads can be interpreted at all (some attend to the previous token, some to syntactically matching tokens, some to repeated tokens).

Worked micro-example. $d = 4$, $d_k = 2$:

$$ \mathbf{W}_Q = \begin{pmatrix}1&0\\0&1\\1&0\\0&1\end{pmatrix},\qquad \mathbf{W}_K = \begin{pmatrix}0&1\\1&0\\1&1\\0&0\end{pmatrix} \quad\Longrightarrow\quad \mathbf{W}_Q^\top\mathbf{W}_K = \begin{pmatrix}1&1\\1&1\\1&1\\0&0\end{pmatrix}\cdot\text{(collapse)} . $$

Computing it explicitly: $(\mathbf{W}_Q^\top\mathbf{W}_K)_{ab} = \sum_{c}\mathbf{W}_{Q,ca}\mathbf{W}_{K,cb}$. Row 0 of $\mathbf{W}_Q^\top$ is the first column of $\mathbf{W}_Q$, i.e. $(1,0,1,0)$. Dotting that with each column of $\mathbf{W}_K$ — column 0 is $(0,1,1,0)$, column 1 is $(1,0,1,0)$ — gives $(\mathbf{W}_Q^\top\mathbf{W}_K)_{0,\cdot} = (0+0+1+0,\;1+0+1+0) = (1,2)$. Row 1 of $\mathbf{W}_Q^\top$ is $(0,1,0,1)$, giving $(0+1+0+0,\;0+0+0+0) = (1,0)$. So

$$ \mathbf{W}_Q^\top\mathbf{W}_K = \begin{pmatrix}1&2\\1&0\end{pmatrix}, $$

which has rank 2 = $d_k$, confirming the bound is achieved here. A single head with $d_k=2$ in a $d=4$ model compares tokens along only two learned directions; with $h=2$ heads you get two such forms, and their outputs are concatenated, giving the model a rank-4 comparison overall.

Multi-head attention

Intuition. One head must commit to a single way of comparing tokens, and then it must average the values of every token that looks relevant by that one comparison. If a sentence needs one head tracking the previous token and another tracking syntactic agreement, one head must compromise. Give it several independent heads and let each ask its own question; concatenate the answers.

Formal definition. With $h$ heads, per-head dimension $d_k = d/h$, and $h$ separate projection triples:

$$ \operatorname{head}_i = \operatorname{Attn}\big(\mathbf{X}\mathbf{W}_Q^{(i)},\; \mathbf{X}\mathbf{W}_K^{(i)},\; \mathbf{X}\mathbf{W}_V^{(i)}\big) \in \mathbb{R}^{n\times d_k}, $$ $$ \operatorname{MHA}(\mathbf{X}) = \big[\operatorname{head}_1;\ldots;\operatorname{head}_h\big]\mathbf{W}_O, \qquad \mathbf{W}_O\in\mathbb{R}^{d\times d}. $$

Shapes: $\mathbf{X}\in\mathbb{R}^{n\times d} \to$ per head $\mathbb{R}^{n\times d_k} \to$ concatenated $\mathbb{R}^{n\times hd_k} = \mathbb{R}^{n\times d} \to \mathbb{R}^{n\times d}$. Parameters: $4d^2 + 4d$ (the three input projections and $\mathbf{W}_O$, with biases). Compute: projections $4nd^2$ MACs; the $h$ score matrices and value products together $2n^2d$ MACs; so per layer the attention core is $2n^2d$ and the projections are $4nd^2$.

Why it is built this way. From the previous section, one head's score function is a bilinear form of rank at most $d_k$. Splitting $d$ into $h$ heads of width $d/h$ does not increase the total rank available — the concatenated output still lives in rank-$d$ space — but it produces $h$ different forms and $h$ different softmaxes. That matters because the softmax is where the model commits: one softmax over one score matrix must decide a single weighted average of values for each query. With $h$ softmaxes the model can average over several different notions of relevance at once, and the concatenation lets the next layer see all of them side by side.

The empirical support is real but should be read carefully. Ablations find that many heads can be removed at test time with little loss (Michel et al., 2019 — "Are Sixteen Heads Really Better than One?"), which shows redundancy; and analyses of trained translation models find a small number of heads doing linguistically identifiable jobs while most are prunable (Voita et al., 2019). The claim "each head has a clean role" is contested — but the claim "more than one head is useful because one softmax is too committed" is supported by the pruning experiments themselves: a few heads carry the work, and which few depends on the input.

Worked micro-example. $d = 512$, $h = 8$, so $d_k = 64$. Per-head scores are $n\times n$; per-head output is $n\times 64$; concatenation gives $n\times512$; $\mathbf{W}_O$ is $512\times512$. Parameters: $3\cdot512\cdot512$ for Q,K,V $= 786{,}432$, plus $512\cdot512 = 262{,}144$ for $\mathbf{W}_O$, total $1{,}048{,}576$ plus biases. With $n = 1024$: projections cost $4\cdot1024\cdot512^2 = 1.074\times10^{9}$ MACs; the attention core costs $2\cdot1024^2\cdot512 = 1.074\times10^{9}$ MACs. The two are equal — which is not a coincidence, it is the $n = 2d$ crossover derived in Derivation 5.

The causal mask, and what a mask bug looks like

Intuition. A language model predicts token $t+1$ from tokens $\le t$. If the attention matrix lets position $t$ see position $t+1$, the model is being asked to copy the answer from the input, and it will happily learn to do exactly that.

Formal definition. Define the additive mask

$$ \mathbf{M}_{ij} = \begin{cases}0 & j \le i\\ -\infty & j > i\end{cases} $$

and compute

$$ \mathbf{A} = \operatorname{softmax}\big(\mathbf{S} + \mathbf{M}\big),\qquad \mathbf{S} = \frac{\mathbf{Q}\mathbf{K}^\top}{\sqrt{d_k}} . $$

Since $e^{-\infty} = 0$ and the softmax is row-wise, row $i$ places zero weight on every $j > i$ and renormalizes over the $i+1$ visible keys. Row $0$ has exactly one visible key (itself) and therefore has weight $1$ there — the first position's attention output is always $\mathbf{v}_0$, regardless of the data.

Why it is built this way — and the four ways it goes wrong. The mask is the entire difference between an encoder (bidirectional) and a decoder (autoregressive) with the same code, so it is both essential and easy to get subtly wrong. Each failure has a distinct symptom:

  1. Masking after the softmax ($\mathbf{A}' = \mathbf{A}\odot\text{mask}$). Rows no longer sum to 1, so the layer is no longer a convex combination — it computes a scaled-down weighted average. Symptoms: the loss decreases but plateaus above where it should; the model compensates by growing activation norms; attention weights are not a distribution. Diagnostic: assert that A.sum(-1) is 1 to within $10^{-5}$ on every row.
  2. Off-by-one mask ($j \le i+1$ or $j < i$). If the current token is visible, the model can read the answer directly. Symptoms: training loss collapses to near zero within a few hundred steps — far below any plausible language-model entropy — while validation loss stays at or above $\ln|V|$, and generation is incoherent or degenerates to copying the prompt. If the current token is masked out ($j < i$), position 0 has an empty row, the softmax denominator is $0$, and you get nan on the first step.
  3. Mask on the wrong axis, or a broadcast that silently does nothing. A mask of shape $(1,n)$ or $(n,)$ can broadcast without error in some frameworks and mask the wrong thing. Symptoms: it trains, but worse than it should, with no crash. Diagnostic: the causality test — run a forward pass on a sequence, change token $t$, and assert that no logit at positions $< t$ changes. This is a five-line unit test and it catches every mask bug, including the ones that do not crash.
  4. $-\infty$ in reduced precision. In fp16, -inf + finite = -inf and exp(-inf) = 0 behave correctly, but a fully masked row would give $0/0$; some kernels also produce nan when -inf meets a 0 gradient. The robust practice is a large finite negative value such as torch.finfo(dtype).min or -1e9, chosen so that $e^{z - (-1e9)}$ underflows to $0$ cleanly.

Worked micro-example. Scores for 3 tokens (from the full trace later in the module): $\mathbf{S} = \begin{pmatrix}1.414&1.414&1.414\\2.828&0.000&1.414\\2.121&0.707&1.414\end{pmatrix}$.

Unmasked, row 0 is uniform: $(0.3333,\;0.3333,\;0.3333)$. Masked, row 0 is $(1,\;0,\;0)$. Row 1 changes from $(0.768,\;0.045,\;0.187)$ to $(0.944,\;0.056,\;0)$. Row 2 is unaffected, because position 2 can already see everything. With values $\mathbf{V} = (3,0),\,(0,3),\,(1,2)$, the causal output for token 0 is exactly $(3,0)$ — $\mathbf{v}_0$ itself. If you mask after the softmax instead, you get $(1,0)$ for token 0 and $(2.30,0.14)$ for token 1, and the row sums are $0.333, 0.813, 1.000$: the bug is visible in the row sums before you ever look at the loss.

Positional information: why order must be injected

Intuition. Self-attention sees a set. Shuffle the tokens and it will do the same thing to the shuffled set. But "dog bites man" and "man bites dog" are different sentences with the same tokens.

Formal definition and proof of permutation equivariance. Let $\mathbf{P}$ be a permutation matrix and let $\mathbf{X}' = \mathbf{P}\mathbf{X}$. Then $\mathbf{Q}' = \mathbf{P}\mathbf{Q}$, $\mathbf{K}' = \mathbf{P}\mathbf{K}$, $\mathbf{V}' = \mathbf{P}\mathbf{V}$, so

$$ \mathbf{S}' = \frac{\mathbf{Q}'\mathbf{K}'^\top}{\sqrt{d_k}} = \frac{\mathbf{P}\mathbf{Q}\mathbf{K}^\top\mathbf{P}^\top}{\sqrt{d_k}} = \mathbf{P}\,\mathbf{S}\,\mathbf{P}^\top,\qquad \mathbf{A}' = \operatorname{softmax}_{\text{row}}(\mathbf{P}\mathbf{S}\mathbf{P}^\top) = \mathbf{P}\,\mathbf{A}\,\mathbf{P}^\top, $$

because permuting rows and columns just relocates the same row-wise softmax results. Therefore

$$ \operatorname{Attn}(\mathbf{P}\mathbf{X}) = \mathbf{P}\,\mathbf{A}\,\mathbf{P}^\top\mathbf{P}\,\mathbf{V} = \mathbf{P}\,\mathbf{A}\,\mathbf{V} = \mathbf{P}\operatorname{Attn}(\mathbf{X}). $$

The layer commutes with every permutation of the sequence. This is not a bug to be fixed at the operator level — it is the property that makes attention translation-invariant in the way convolution is, and it is why positional information must enter through the data.

Why it is built this way. There are exactly three places to inject position: add it to the input embeddings, multiply or rotate the queries and keys, or add a distance-dependent bias to the scores. Each choice encodes a different assumption about what "position" means, and the rest of this section is those three options.

Worked micro-example. Two tokens with $\mathbf{X} = \begin{pmatrix}1&0\\0&1\end{pmatrix}$, $\mathbf{W}_Q=\mathbf{W}_K=\mathbf{W}_V=\mathbf{I}$, no scaling. Scores $\mathbf{S} = \mathbf{X}\mathbf{X}^\top = \begin{pmatrix}1&0\\0&1\end{pmatrix}$, softmax rows $(0.731,\;0.269)$ each, output $\begin{pmatrix}0.731 & 0.269\\0.269 & 0.731\end{pmatrix}$. Swap the tokens: $\mathbf{P}\mathbf{X} = \begin{pmatrix}0&1\\1&0\end{pmatrix}$, and the output is $\begin{pmatrix}0.731&0.269\\0.269&0.731\end{pmatrix}$ again — the identical matrix, because this particular symmetric example is permutation-invariant by construction. That is the degeneracy: without position information, the two distinct orders are literally the same input.

Sinusoidal encodings

Intuition. Give each position a unique multi-scale clock reading. The fastest hand ticks every step and tells you about local order; the slowest takes thousands of steps per revolution and tells you roughly where in the sequence you are. Read all the hands at once and the position is unambiguous.

Formal definition. For position $pos$ and dimension pair $i = 0,\ldots,d/2-1$:

$$ PE(pos, 2i) = \sin\!\big(pos\cdot\omega_i\big),\qquad PE(pos, 2i+1) = \cos\!\big(pos\cdot\omega_i\big),\qquad \omega_i = 10000^{-2i/d}. $$

The encoding is added to the token embedding: $\mathbf{X} = \mathbf{E}_{\text{tok}} + \mathbf{PE}$. It has no parameters.

Why it is built this way — the relative-position property. The decisive fact is that a shift in position is a rotation in each 2-D subspace, with an angle that depends only on the shift. Using the angle-addition identities,

$$\begin{aligned} \sin\big(\omega_i(pos+k)\big) &= \sin(\omega_ipos)\cos(\omega_ik) + \cos(\omega_ipos)\sin(\omega_ik),\\ \cos\big(\omega_i(pos+k)\big) &= \cos(\omega_ipos)\cos(\omega_ik) - \sin(\omega_ipos)\sin(\omega_ik), \end{aligned}$$

so

$$ \begin{pmatrix}\sin(\omega_i(pos+k))\\ \cos(\omega_i(pos+k))\end{pmatrix} = \underbrace{\begin{pmatrix}\cos(\omega_ik) & \sin(\omega_ik)\\ -\sin(\omega_ik) & \cos(\omega_ik)\end{pmatrix}}_{\text{depends only on }k} \begin{pmatrix}\sin(\omega_ipos)\\ \cos(\omega_ipos)\end{pmatrix}. $$

The matrix is fixed by the offset $k$ alone; it does not depend on $pos$. Consequently $\mathbf{PE}(pos+k) = \mathbf{R}(k)\,\mathbf{PE}(pos)$ for a block-diagonal orthogonal $\mathbf{R}(k)$, and since rotations preserve inner products,

$$ \big\langle \mathbf{PE}(pos),\, \mathbf{PE}(pos+k)\big\rangle = \sum_{i}\cos(\omega_i k), $$

a function of $k$ only. Two structural bonuses follow from the geometry of the frequencies $\omega_i = 10000^{-2i/d}$: the wavelengths $\lambda_i = 2\pi/\omega_i$ form a geometric progression from $2\pi$ at $i=0$ to $2\pi\cdot10^{4}$ at $i = d/2-1$ (for $d=512$: $6.28$ to about $56{,}000$), giving a binary-counter-like code in which low dimensions distinguish fine offsets and high dimensions distinguish coarse ones; and every entry is bounded in $[-1,1]$, so the encoding cannot swamp the token embedding as position grows.

Worked micro-example. $d = 4$, so $i\in\{0,1\}$ with $\omega_0 = 10000^{0} = 1$ and $\omega_1 = 10000^{-1/2} = 0.01$.

$pos$ $\sin(pos)$ $\cos(pos)$ $\sin(0.01\,pos)$ $\cos(0.01\,pos)$
0 $0.0000$ $1.0000$ $0.0000$ $1.0000$

Position 0 is the all-ones-plus-zero vector, so it is a fixed, nonzero embedding — which is why adding a sinusoidal encoding does not disturb the meaning of the first token.

Learned absolute position embeddings

Intuition. Just let position be another token: allocate one embedding vector per slot and add it.

Formal definition. $\mathbf{X} = \mathbf{E}_{\text{tok}}[\,\text{token}\,] + \mathbf{E}_{\text{pos}}[\,pos\,]$, with $\mathbf{E}_{\text{pos}}\in\mathbb{R}^{L_{\max}\times d}$ learned. GPT-2 uses $L_{\max} = 1024$, $d = 768$: $786{,}432$ parameters, about $0.6\%$ of the model.

Why it is built this way. It gives up the relative-position guarantee and buys complete freedom: the model can learn whatever position-dependent structure the data contains, with no inductive bias beyond "slot $k$ is slot $k$". Empirically it works very well up to the trained length, which is why BERT and GPT-1/2/3 used it.

Its fatal property is that there is no value at position $L_{\max}+1$: the model has never seen that row of the table, and there is no principled way to extend it. Learned absolute embeddings do not extrapolate, and the truncation at the maximum trained length is a hard wall — the reason modern open-weight models all use RoPE or ALiBi instead.

Worked micro-example. Extending GPT-2's 1024-position table to 2048 by simply adding 1024 new random rows is catastrophic: the model has learned functions of $\mathbf{e}_{\text{pos}}$ for $pos<1024$ and nothing about the new rows, so perplexity on longer inputs explodes immediately after position 1024. Interpolating (rescaling positions into $[0,1024]$) works much better but changes the meaning of every learned position vector — which is why the field moved to relative schemes.

RoPE: rotary position embedding

Intuition. Do not add position to the vectors, because addition is a one-time operation that the subsequent linear layers can scramble. Instead rotate the query and key by an angle proportional to position. Then when a query at position $m$ dots a key at position $n$, the rotations combine and only the difference survives — and rotation, unlike addition, commutes with the attention mechanism's own algebra.

Formal definition. Identify the $d_k$-dimensional space as $d_k/2$ two-dimensional subspaces. In each subspace $i$ with frequency $\theta_i = 10000^{-2i/d_k}$, define the rotation

$$ \mathbf{R}(\phi) = \begin{pmatrix}\cos\phi & -\sin\phi\\ \sin\phi & \cos\phi\end{pmatrix}, $$

and set

$$ f_q(\mathbf{x}_m, m) = \mathbf{R}(m\theta)\,\mathbf{q}_m,\qquad f_k(\mathbf{x}_n, n) = \mathbf{R}(n\theta)\,\mathbf{k}_n, $$

applied block-wise: the full $\mathbf{R}$ is block-diagonal with blocks $\mathbf{R}(m\theta_i)$. Values are not rotated.

Derivation of the relative property. Let $\mathbf{R}_m = \mathbf{R}(m\theta)$ and $\mathbf{R}_n = \mathbf{R}(n\theta)$, so $\mathbf{R}_m$ is orthogonal ($\mathbf{R}_m^\top\mathbf{R}_m = \mathbf{I}$) and rotations compose additively ($\mathbf{R}_a\mathbf{R}_b = \mathbf{R}_{a+b}$). Then

$$ \big\langle f_q(\mathbf{q}_m,m),\, f_k(\mathbf{k}_n,n)\big\rangle = \big(\mathbf{R}_m\mathbf{q}_m\big)^\top\big(\mathbf{R}_n\mathbf{k}_n\big) = \mathbf{q}_m^\top\mathbf{R}_m^\top\mathbf{R}_n\mathbf{k}_n = \mathbf{q}_m^\top\mathbf{R}_{n-m}\mathbf{k}_n . $$

Because $\mathbf{R}_m^\top = \mathbf{R}_{-m}$ and $\mathbf{R}_{-m}\mathbf{R}_{n} = \mathbf{R}_{n-m}$. The result depends on $m$ and $n$ only through $n-m$: the score is a function of content and relative offset. Note what the proof did not use: nothing about the particular content vectors, and no linearity assumption beyond the dot product. It holds for every head, every frequency, and every pair.

Why it is built this way. Four properties, each of which the alternatives lack. (i) Relative by construction, unlike sinusoidal-plus-addition which only gives relative information as a by-product that later linear layers can and do destroy. (ii) Norm-preserving: $\|\mathbf{R}_m\mathbf{q}\| = \|\mathbf{q}\|$, so attention scores do not drift in scale with position — the failure mode of additive encodings where the sum $\mathbf{e}_{\text{tok}}+\mathbf{pe}$ changes norm as a function of position. (iii) Parameter-free and multiplicative, so positions compose: $\mathbf{R}_m\mathbf{R}_n = \mathbf{R}_{m+n}$, which lets long-context methods rescale positions ($m\to m\cdot L/L'$ in position interpolation) by simply changing the angle. (iv) It leaves the value path alone, so what a token hands over does not depend on where it sits — only how findable it is does.

Implementation detail worth knowing. The original formulation pairs adjacent coordinates $(x_{2i}, x_{2i+1})$; the widely used "rotate-half" convention pairs $(x_i, x_{i+d/2})$ instead. The two are equivalent up to a permutation of the coordinate basis, but the permutation changes which weight indices are paired — so a checkpoint trained with one convention and loaded into code implementing the other produces garbage that trains but never converges. This is one of the most common silent bugs in the field.

Worked micro-example. One 2-D subspace, $\theta = 1$, $\mathbf{q} = (1,0)$, $\mathbf{k} = (0,1)$.

$m$ $n$ $n-m$ $f_q(\mathbf{q},m)$ $f_k(\mathbf{k},n)$ score
0 0 0 $(1,\,0)$ $(0,\,1)$ $0.0000$
0 1 1 $(1,\,0)$ $(-0.8415,\,0.5403)$ $-0.8415$
1 2 1 $(0.5403,\,0.8415)$ $(-0.9093,\,-0.4161)$ $-0.8415$
0 2 2 $(1,\,0)$ $(-0.9093,\,-0.4161)$ $-0.9093$

Rows 2 and 3 have the same offset and produce the identical score, even though every individual vector is different. That is the relative property, visible as arithmetic. Also note the magnitudes: $e^{-0.8415}$ against $e^{0}$ for offset $0$ means a mild preference for recent keys, which is learned rather than imposed — $\theta$ is fixed but the content vectors are not.

Drag the position offset and watch the query and key vectors rotate in their 2-D subspace while their dot product stays pinned to the value for that offset. Watch the readout: rotate either vector on its own and the score changes; add the same offset to both and the score does not move at all.

ALiBi

Intuition. Do not encode position in the vectors at all. Instead, penalize attention scores by distance: a key 20 tokens away starts with a handicap of $20m$. Recent tokens are cheap to attend to; distant ones must earn it.

Formal definition. With head $i$ of $h$ heads having slope $m_i = 2^{-8i/h}$ (a fixed geometric sequence):

$$ \mathbf{S}_{ij} = \frac{\mathbf{q}_i^\top\mathbf{k}_j}{\sqrt{d_k}} - m\cdot(i - j)\quad\text{for } j \le i, $$

and $-\infty$ for $j > i$. No positional embedding is added to the input at all, and there are no positional parameters.

Why it is built this way. Three properties, all consequences of using distance rather than position. (i) Zero parameters: the bias is a fixed function, so nothing is learned about position and nothing can overfit to it. (ii) A locality prior: the penalty is linear in distance and cumulative, so the model is biased toward local attention unless content similarity overcomes the penalty, which is a sensible prior for language. (iii) Extrapolation in principle, because the bias is defined for every distance, including distances longer than any seen in training — the model has seen the penalty at distance 1 through $L$, and continues to see the same function beyond $L$. The paper's evidence (Press, Smith and Lewis, 2021) is that models trained with ALiBi retain more of their quality past their training length than learned-absolute or sinusoidal models.

The caveat, and it is contested territory: "extrapolates" means "degrades more gently", not "works at any length". All length-extension claims need to be read against the specific benchmark and the specific extrapolation factor, and most models still lose substantial accuracy at 4–8× their training length regardless of the positional scheme.

Worked micro-example. Two heads with slopes $m = 0.5$ and $m = 0.25$. A key at distance $0$ gets no penalty; at distance $4$ it gets $-2.0$ (head 0) or $-1.0$ (head 1); at distance $16$ it gets $-8.0$ or $-4.0$. Since scores are in the range of a few units for unit-variance $\mathbf{Q},\mathbf{K}$, the first head is effectively local beyond ~10 tokens and the second remains nearly global — the geometric slope schedule gives the stack a mixture of attention spans for free.

The transformer block, with every residual and norm in place

Intuition. Picture a single wide vector per token — a shared bus running the length of the model. Nothing ever overwrites it; every sublayer reads from it through a normalization, computes something, and adds its result back. Two sublayers alternate: one moves information between positions (attention) and one transforms each position independently (the feed-forward network).

Formal definition. The original (post-LN) block, as published:

$$\begin{aligned} \mathbf{x}' &= \operatorname{LN}\big(\mathbf{x} + \operatorname{Attn}(\mathbf{x})\big),\\ \mathbf{x}'' &= \operatorname{LN}\big(\mathbf{x}' + \operatorname{FFN}(\mathbf{x}')\big). \end{aligned}$$

The modern (pre-LN) block, used by essentially every open-weight model since GPT-2/GPT-3 era:

$$\begin{aligned} \mathbf{x}' &= \mathbf{x} + \operatorname{Attn}\big(\operatorname{LN}(\mathbf{x})\big),\\ \mathbf{x}'' &= \mathbf{x}' + \operatorname{FFN}\big(\operatorname{LN}(\mathbf{x}')\big), \end{aligned}$$

followed after the final layer by one last $\operatorname{LN}$ before the unembedding. LayerNorm here is per token:

$$ \operatorname{LN}(\mathbf{x}) = \gamma\odot\frac{\mathbf{x} - \mu}{\sqrt{\sigma^2+\epsilon}} + \beta,\qquad \mu = \frac{1}{d}\sum_{j=1}^{d}x_j,\quad \sigma^2 = \frac{1}{d}\sum_{j=1}^{d}(x_j-\mu)^2 . $$

Why it is built this way. Four decisions, each load-bearing. (i) Residual on every sublayer: by the argument of M10, the block's Jacobian is $\mathbf{I} + \mathbf{J}$, so the product over $L$ blocks retains an identity term and $\sigma_{\min}\ge(1-\epsilon)^L$ rather than $\epsilon^L$. Without residuals a 12-layer transformer is essentially untrainable, and a 96-layer one is unthinkable. (ii) Normalization before each sublayer in pre-LN: the sublayer sees unit-scale input, so its output scale is controlled, and the residual path itself is never normalized — the gradient reaching layer 1 travels on a clean identity path. (iii) Per-token normalization: LayerNorm does not couple positions, so it works identically for a batch of one and never needs running statistics; an autoregressive model cannot use BatchNorm because position $t$ would leak statistics from position $t+1$. (iv) The two-sublayer split: attention is the only operation in the block that mixes positions, and the FFN is the only one that does substantial per-position computation. Isolating them makes the residual stream a clean communication channel.

Worked micro-example. One block at $d = 768$, $d_{\text{ff}} = 3072$:

Component Shape Parameters
Q, K, V, O $768\times768$ each $4\cdot768^2 + 4\cdot768 = 2{,}362{,}368$
FFN $W_1$ $3072\times768$ $2{,}359{,}296$
FFN $W_2$ $768\times3072$ $2{,}359{,}296$
FFN biases — $3072 + 768 = 3{,}840$
2 × LayerNorm $768$ each for $\gamma,\beta$ $2\cdot1536 = 3{,}072$
Block total $7{,}087{,}872$

Twelve such blocks plus a $50{,}257\times768$ token embedding and a $1024\times768$ position table give $85{,}054{,}464 + 38{,}597{,}376 + 786{,}432 = 124{,}438{,}272$ — GPT-2 small's 124M parameters, accounted for to the unit. Note that the FFN holds two-thirds of every block's parameters: attention is the communicator, not the knowledge store.

The feed-forward network as key-value memory

Intuition. Attention decides what to look at; the FFN decides what to make of it. Because it acts on one position at a time, it cannot move information — so it is free to be a large, position-local lookup table of learned patterns.

Formal definition. With $d_{\text{ff}} = 4d$ (the classic ratio):

$$ \operatorname{FFN}(\mathbf{x}) = \mathbf{W}_2\,\sigma\big(\mathbf{W}_1\mathbf{x} + \mathbf{b}_1\big) + \mathbf{b}_2,\qquad \mathbf{W}_1\in\mathbb{R}^{d_{\text{ff}}\times d},\ \mathbf{W}_2\in\mathbb{R}^{d\times d_{\text{ff}}} . $$

Why it is built this way — the memory reading. Write the output as a weighted sum over the columns of $\mathbf{W}_2$. Let $\mathbf{k}_i = \mathbf{W}_{1,i,:}\in\mathbb{R}^d$ be the $i$-th row of $\mathbf{W}_1$ and $\mathbf{v}_i = \mathbf{W}_{2,:,i}\in\mathbb{R}^d$ be the $i$-th column of $\mathbf{W}_2$. Then

$$ \operatorname{FFN}(\mathbf{x}) = \sum_{i=1}^{d_{\text{ff}}} \underbrace{\sigma\big(\langle\mathbf{k}_i,\mathbf{x}\rangle + b_{1,i}\big)}_{a_i(\mathbf{x})}\;\mathbf{v}_i + \mathbf{b}_2 . $$

This is a key-value memory with $d_{\text{ff}}$ entries: the rows of $\mathbf{W}_1$ are keys (patterns to detect), the columns of $\mathbf{W}_2$ are values (what to write back when detected), and $a_i(\mathbf{x})$ is the address — a nonnegative scalar that is large exactly when $\mathbf{x}$ aligns with $\mathbf{k}_i$. Because $\sigma$ is monotone and mostly near $0$ or large, the address is sparse-ish, so a given input reads only a few memories. Geva et al. (2021) formalized exactly this and showed that the top activations of specific FFN neurons correspond to interpretable patterns like "a word following 'Tuesday'".

The parameter cost is the reason this layer dominates: $2dd_{\text{ff}} = 8d^2$ against attention's $4d^2$. In LLaMA-7B ($d=4096$, $d_{\text{ff}} = 11008$, SwiGLU with three matrices) the MLP is $3\cdot4096\cdot11008 = 135.3$M per layer against attention's $67.1$M.

The SwiGLU variant, and where $8/3$ comes from. Modern models replace the two-matrix FFN with a gated one:

$$ \operatorname{FFN}_{\text{SwiGLU}}(\mathbf{x}) = \big(\mathbf{W}_1\mathbf{x}\odot\operatorname{SiLU}(\mathbf{W}_3\mathbf{x})\big)\mathbf{W}_2 . $$

This has three matrices instead of two, so to keep the parameter count equal to the classic $8d^2$ you need $3\cdot d\cdot d_{\text{ff}} = 8d^2$, i.e. $d_{\text{ff}} = \frac{8}{3}d \approx 2.67d$. That is why LLaMA's $11008 = 2.6875\times4096$ rather than 4×4096: the odd-looking number is exactly the parameter-neutral choice.

Worked micro-example. $d=4$, $d_{\text{ff}} = 8$, one input $\mathbf{x} = (1,0,1,0)$. Suppose $\mathbf{W}_1$ rows 2 and 5 are $\mathbf{k}_2 = (1,0,1,0)$ and $\mathbf{k}_5=(0,1,0,1)$ with biases 0, and all other rows are orthogonal to $\mathbf{x}$. Then $\langle\mathbf{k}_2,\mathbf{x}\rangle = 2$ and $\langle\mathbf{k}_5,\mathbf{x}\rangle = 0$, so with ReLU $a_2 = 2$ and $a_5 = 0$: only one memory fires, and the output is $2\mathbf{v}_2 + \mathbf{b}_2$. The layer has 8 memories and reads 1 — the sparse-addressing picture in one line.

Pre-LN versus post-LN: where the normalization sits changes the gradient

Intuition. Post-LN normalizes after the addition, so every path from input to output passes through a normalization. Pre-LN normalizes only inside the branch, so the residual path is clean — but the residual stream's magnitude then grows with depth, which is why pre-LN needs a final LayerNorm.

Formal definition and derivation. The LayerNorm Jacobian, indexed $i,j$ over the $d$ features:

$$ \frac{\partial\,\operatorname{LN}_i}{\partial x_j} = \frac{\gamma_i}{\sigma}\left(\delta_{ij} - \frac{1}{d} - \frac{\hat{x}_i\hat{x}_j}{d}\right),\qquad \hat{\mathbf{x}} = \frac{\mathbf{x}-\mu}{\sigma}. $$

In matrix form:

$$ \mathbf{J}_{\operatorname{LN}} = \frac{1}{\sigma}\operatorname{diag}(\boldsymbol{\gamma})\left(\mathbf{I} - \frac{1}{d}\mathbf{1}\mathbf{1}^\top - \frac{1}{d}\hat{\mathbf{x}}\hat{\mathbf{x}}^\top\right). $$

Now examine the operator in brackets. $\mathbf{1}/\sqrt{d}$ and $\hat{\mathbf{x}}/\sqrt{d}$ are orthonormal (because $\sum_i\hat{x}_i = 0$ and $\sum_i\hat{x}_i^2 = d$), and the operator acts as the identity on the $(d-2)$-dimensional complement of their span while annihilating both of them. So $\|\mathbf{J}_{\operatorname{LN}}\|_2 = \max_i|\gamma_i|/\sigma$, but on a random input vector it contracts by

$$ \left\|\left(\mathbf{I} - \tfrac{1}{d}\mathbf{1}\mathbf{1}^\top - \tfrac{1}{d}\hat{\mathbf{x}}\hat{\mathbf{x}}^\top\right)\mathbf{u}\right\|^2 \approx 1 - \frac{2}{d} $$

in expectation, since two of $d$ directions are removed. Compounded over $L$ blocks:

$$ \text{contraction} \approx \left(1-\frac{2}{d}\right)^{L/2}. $$

For $d=512$, $L=24$: $(1-0.0039)^{12} = 0.954$. For $L=96$: $0.83$. So the systematic part of the contraction is mild at large $d$ — a few percent per dozen layers. That is exactly why post-LN does not fail loudly; it degrades, and it degrades in a way that depends sensitively on initialization and learning rate. The empirical facts are not in doubt: post-LN transformers require learning-rate warmup and diverge without it at moderate depth, while pre-LN transformers train without warmup (Xiong et al., 2020, proved the depth-dependence statements for the two variants and matched them to the observed warmup requirement).

Why it is built this way. Pre-LN wins because it makes the gradient path independent of depth by construction: the block is $\mathbf{I} + \mathbf{J}$, so the product over blocks has an identity term at every order. Post-LN's block is $\mathbf{J}_{\operatorname{LN}}(\mathbf{I} + \mathbf{J})$, so every term in the expansion carries at least one normalization Jacobian. The cost of pre-LN is that nothing controls the residual stream's norm: with iid sublayer outputs of variance $v$, the stream's variance grows like $Lv$ with depth (a random walk), reaching $\mathrm{RMS}\approx\sqrt{Lv}$. That is harmless for the gradient but not for the final logits, hence the final LayerNorm.

Worked micro-example. Scalar proxy, per-block branch derivative $a = -0.5$.

Recurrence Form $\partial x_L/\partial x_0$ after $L=48$
plain $x_{l+1} = a x_l$ $0.5^{48} = 3.6\times10^{-15}$
residual $x_{l+1} = x_l + a x_l$ $0.5^{48}$ — worst case, sign-aligned

The quadratic wall

Intuition. Every token talks to every other token. Twice the context means four times the conversations.

Formal definition. Per layer, per sequence, in MACs:

$$ \text{attention core} = 2n^2d \quad(\text{the } \mathbf{Q}\mathbf{K}^\top \text{ and } \mathbf{A}\mathbf{V} \text{ products, summed over heads}),\qquad \text{projections} = 4nd^2 . $$

Setting them equal gives the crossover:

$$ 2n^2d = 4nd^2 \quad\Longrightarrow\quad n = 2d . $$

$d = 4096$ $n$ core MACs projection MACs core share
$1024$ $8.6\times10^{9}$ $6.9\times10^{10}$ $11\%$
$8192$ $5.5\times10^{11}$ $5.5\times10^{11}$ $50\%$
$32768$ $8.8\times10^{12}$ $2.2\times10^{12}$ $80\%$

Why it is built this way. It is not a choice; it is the arithmetic of the operator. Fixing it structurally is M13's subject (sliding windows, sparse patterns, linear attention, state-space models). Fixing it at the constant factor level — same FLOPs, less memory traffic — is FlashAttention.

Worked micro-example. A 32-layer, $d=4096$ model at $n=8192$: attention core $= 32\cdot5.5\times10^{11} = 1.76\times10^{13}$ MACs $= 3.5\times10^{13}$ FLOPs for one forward pass of one sequence. At an optimistic sustained $3\times10^{14}$ FLOP/s that is 0.12 s of pure attention, per sequence, per forward pass — and training needs three passes.

FlashAttention: tiling, and why it is exact

Intuition. The slow part of attention on a GPU is not the multiply-accumulates; it is writing the $n\times n$ score matrix to high-bandwidth memory and reading it back. If you never write it down — if you compute the softmax in tiles that fit in on-chip SRAM and accumulate the result as you go — you keep the same answer and touch far less memory.

Formal definition of the IO-aware algorithm. Partition $\mathbf{Q}$ into row-blocks $\mathbf{Q}_1,\ldots,\mathbf{Q}_{T_r}$ and $\mathbf{K},\mathbf{V}$ into column-blocks, each sized to fit in SRAM. For each query block, maintain running statistics $(\mathbf{m},\boldsymbol{\ell},\mathbf{O})$ and, for each key block $j$:

$$ \mathbf{S}^{(j)} = \mathbf{Q}_i\mathbf{K}_j^\top/\sqrt{d_k},\qquad \mathbf{m}^{\text{new}} = \max(\mathbf{m},\;\operatorname{rowmax}(\mathbf{S}^{(j)})), $$ $$ \boldsymbol{\ell}^{\text{new}} = e^{\mathbf{m}-\mathbf{m}^{\text{new}}}\odot\boldsymbol{\ell} + \operatorname{rowsum}\big(e^{\mathbf{S}^{(j)}-\mathbf{m}^{\text{new}}}\big), $$ $$ \mathbf{O}^{\text{new}} = \frac{e^{\mathbf{m}-\mathbf{m}^{\text{new}}}\odot\boldsymbol{\ell}\odot\mathbf{O} \;+\; e^{\mathbf{S}^{(j)}-\mathbf{m}^{\text{new}}}\mathbf{V}_j}{\boldsymbol{\ell}^{\text{new}}} . $$

Why this is exact. Maintain the invariant that after processing a set $S$ of key blocks,

$$ \mathbf{O}_S = \frac{\sum_{j\in S}e^{\mathbf{s}_j - m_S}\,\mathbf{v}_j}{\sum_{j\in S}e^{\mathbf{s}_j - m_S}},\qquad m_S = \max_{j\in S}s_j . $$

When a new block $B$ arrives, both numerator and denominator are multiplied by the same factor $e^{m_S - m^{\text{new}}}$, so their ratio is unchanged; adding the new block's terms (scaled by $e^{m_B - m^{\text{new}}}$, the same factor for all of them) preserves the invariant with the correct new maximum. At the end, $m = \max_j s_j$ over all keys and $\mathbf{O}$ is exactly the softmax-weighted average. The final result differs from the naive computation only by floating-point reassociation — not by approximation. Nothing is skipped, no entries are dropped, and no low-rank surrogate is used. This is the distinction between FlashAttention (an exact, IO-aware implementation) and sparse or linear attention (approximations of the function).

Why it is built this way. Three measured wins, in order of importance. (i) Memory: the $n\times n$ matrix is never materialized, so activation memory drops from $O(n^2)$ to $O(n)$. For $n=8192$ in fp16 that matrix is $8192^2\cdot2 = 134$ MB per head; with 32 heads that is 4.3 GB per layer, which is why long context was impossible before tiling. (ii) IO: high-bandwidth memory traffic drops from $O(n^2 + nd)$ to $O(n^2d^2/M)$ where $M$ is SRAM size, so a larger SRAM tile buys a quadratic reduction in traffic. (iii) Speed: the measured speedup is 2–4× on attention for typical dimensions, larger at long context. The backward pass recomputes the tiles rather than storing them, trading FLOPs for memory — a trade that is nearly free because the kernel is memory-bound.

Worked micro-example. $n=8192$, $d=4096$, $h=32$ heads so $d_k=128$. Naive: the score matrix per head is $8192\times8192$ fp16 $=134$ MB; all 32 heads $=4.3$ GB, per layer, held for the backward pass. Tiled with $128\times128$ blocks: each score tile is $128\cdot128\cdot2 = 32$ KB, which fits comfortably in the 192 KB of SRAM per streaming multiprocessor. The whole computation proceeds without any tensor larger than a tile plus the $n\times d_k$ output.

The KV cache

Intuition. At generation time you produce one token at a time, but every new token attends over all the old ones — and the old tokens' keys and values never change. Recomputing them is pure waste. Store them.

Formal definition. For a model with $L$ layers, $n_{kv}$ key/value heads, head dimension $d_h$, context length $T$, and $b$ bytes per element:

$$ \text{KV cache bytes} = 2\,L\,n_{kv}\,d_h\,T\,b . $$

The factor 2 is for both $\mathbf{K}$ and $\mathbf{V}$; $n_{kv}=h$ for multi-head attention. Time to generate $T$ tokens drops from $O(T^2d)$ (recomputing everything each step) to $O(Td)$ after the first, because each new token costs one query against $T$ cached keys.

Why it is built this way. It is a pure time–memory trade with no approximation, and its size is the binding constraint on inference. For LLaMA-2-7B ($L=32$, $h=32$, $d_h=128$, fp16 so $b=2$):

$$ 2\cdot32\cdot32\cdot128\cdot2 = 524{,}288\ \text{bytes per token} = 512\ \text{KiB per token}, $$

which is $2\ \text{GiB}$ at a 4096-token context — larger than the 14 GB of weights divided by a batch of 8, meaning the cache, not the model, limits the batch size. M13 covers the architectural fixes (MQA, GQA, MLA); M19 covers the systems ones (paging, quantization).

Worked micro-example. The same model at batch 32 and context 4096: $32\cdot2\ \text{GiB} = 64$ GiB of cache, against 14 GB of weights on an 80 GB card — so you can batch heavily at short context and barely at all at long context. Halving $n_{kv}$ from 32 to 8 (GQA with 8 groups) cuts the cache to 16 GiB and quadruples the feasible batch. This single arithmetic is why no modern open-weight model uses full multi-head attention.

The algorithm, step by step

A complete forward pass for one decoder block stack, batch $B$, sequence $T$, width $d$, $h$ heads, $d_k = d/h$, $L$ layers, vocabulary $V$. Every intermediate shape is written out, because this is where more implementation bugs live than anywhere else in the architecture.

  1. Embed. Token ids $\in\mathbb{Z}^{B\times T}$ → $\mathbf{X} = \mathbf{E}_{\text{tok}}[\text{ids}] \in\mathbb{R}^{B\times T\times d}$. If using absolute positions, add $\mathbf{E}_{\text{pos}}[:T]$. If using RoPE, do not add anything here — position enters at step 4.
  2. Enter the layer stack. For $l = 1,\ldots,L$, let $\mathbf{x}\in\mathbb{R}^{B\times T\times d}$ be the residual stream.
  3. Pre-normalize. $\mathbf{u} = \operatorname{LN}(\mathbf{x})$, same shape. (Post-LN: skip this and normalize after the residual add instead.)
  4. Project to queries, keys, values. $\mathbf{Q} = \mathbf{u}\mathbf{W}_Q^\top$, $\mathbf{K} = \mathbf{u}\mathbf{W}_K^\top$, $\mathbf{V}=\mathbf{u}\mathbf{W}_V^\top$, each $\in\mathbb{R}^{B\times T\times d}$. Reshape to $B\times T\times h\times d_k$ and transpose to $\mathbb{R}^{B\times h\times T\times d_k}$ — the head dimension moves out of the token axis. Apply RoPE to $\mathbf{Q}$ and $\mathbf{K}$ only.
  5. Score. $\mathbf{S} = \mathbf{Q}\mathbf{K}^\top/\sqrt{d_k} \in \mathbb{R}^{B\times h\times T\times T}$. Add the mask: $\mathbf{S}_{ij} = -\infty$ for $j>i$. Note the memory: this tensor is the quadratic one.
  6. Softmax and mix. $\mathbf{A} = \operatorname{softmax}_{\text{last axis}}(\mathbf{S})$ (row-wise, over keys), then $\mathbf{Z} = \mathbf{A}\mathbf{V}\in\mathbb{R}^{B\times h\times T\times d_k}$.
  7. Merge heads. Transpose back to $B\times T\times h\times d_k$ and reshape to $\mathbb{R}^{B\times T\times d}$. This is the concatenation $[\operatorname{head}_1;\ldots;\operatorname{head}_h]$.
  8. Output projection and residual. $\mathbf{x} \leftarrow \mathbf{x} + \mathbf{Z}\mathbf{W}_O^\top$. (Post-LN: $\mathbf{x}\leftarrow\operatorname{LN}(\mathbf{x})$ here.)
  9. Feed-forward with its own pre-norm. $\mathbf{x} \leftarrow \mathbf{x} + \operatorname{FFN}\big(\operatorname{LN}(\mathbf{x})\big)$, shapes $B\times T\times d \to B\times T\times d_{\text{ff}}\to B\times T\times d$.
  10. Unembed. After the stack, one final $\mathbf{x} = \operatorname{LN}(\mathbf{x})$, then logits $= \mathbf{x}\mathbf{E}_{\text{tok}}^\top \in \mathbb{R}^{B\times T\times V}$ (untied) or the same matrix transposed (tied).
  11. Loss. Cross-entropy between logits at positions $0..T-2$ and targets at $1..T-1$. Shifting is the causal-mask contract restated as a data contract.

```text function transformer_forward(ids, params): x = embed(ids) # (B, T, d) for l in range(L): u = layer_norm(x, ln1[l]) # (B, T, d) q = (u @ Wq[l].T).view(B, T, h, dk).transpose(1, 2) # (B, h, T, dk) k = (u @ Wk[l].T).view(B, T, h, dk).transpose(1, 2) v = (u @ Wv[l].T).view(B, T, h, dk).transpose(1, 2) q, k = rope(q, k) # positions only, no shape change S = q @ k.transpose(-1, -2) / sqrt(dk) # (B, h, T, T) <-- the quadratic tensor S = S + causal_mask(T) # 0 / -inf A = softmax(S, dim=-1) # row sums == 1 z = (A @ v).transpose(1, 2).reshape(B, T, d) # (B, T, d) x = x + z @ Wo[l].T # residual 1 w = layer_norm(x, ln2[l]) x = x + (silu(w @ W1[l].T) * (w @ W3[l].T)) @ W2[l].T # SwiGLU, residual 2 x = layer_norm(x, ln_f) return x @ E_tok.T # (B, T, V) ```

Complexity. Per layer, per sequence, in MACs: projections $4nd^2$, attention core $2n^2d$, FFN $8nd^2$ (two matrices at $d\cdot4d$ each; $8nd^2$ also for SwiGLU at $d_{\text{ff}}=8d/3$). Total $12nd^2 + 2n^2d$ per layer, so $L(12nd^2+2n^2d)$ per forward pass. In FLOPs that is $2\times$ those numbers, and since the parameter count is $L\cdot 12d^2$, the familiar statement "forward FLOPs $\approx 2NT$" (with $N$ parameters and $T$ tokens) is exactly this accounting with the quadratic term dropped. Training costs about $6NT$: two forward-equivalents for the backward pass, plus the forward.

Memory: activations $O(Lnd)$ per sequence, attention $O(n^2)$ per layer per head if materialized (removed by FlashAttention), parameters $O(Ld^2 + Vd)$, KV cache $O(L\,n_{kv}d_h T)$ per sequence at inference.

Derivations

1. Why the divisor is $\sqrt{d_k}$: variance, saturation, and the gradient

Step 1 — the variance of the score. Let $\mathbf{q},\mathbf{k}\in\mathbb{R}^{d_k}$ have iid components with $\mathbb{E}[q_i]=\mathbb{E}[k_i]=0$, $\mathrm{Var}(q_i)=\mathrm{Var}(k_i)=\sigma^2$, and let $q$ and $k$ be independent. The score is $s = \sum_{i=1}^{d_k}q_ik_i$.

$$ \mathbb{E}[s] = \sum_{i=1}^{d_k}\mathbb{E}[q_i]\mathbb{E}[k_i] = 0 . $$

$$\begin{aligned} \mathrm{Var}(s) &= \sum_{i=1}^{d_k}\mathrm{Var}(q_ik_i) \quad\text{(independent terms)}\\ &= \sum_{i=1}^{d_k}\Big(\mathbb{E}\big[q_i^2k_i^2\big] - \big(\mathbb{E}[q_ik_i]\big)^2\Big)\\ &= \sum_{i=1}^{d_k}\mathbb{E}\big[q_i^2\big]\mathbb{E}\big[k_i^2\big] \quad\text{(independence, zero mean)}\\ &= \sum_{i=1}^{d_k}\sigma^2\cdot\sigma^2 = d_k\sigma^4 . \end{aligned}$$

So $\mathrm{std}(s) = \sigma^2\sqrt{d_k}$. With $\sigma=1$ the score has standard deviation $\sqrt{d_k}$: measured over 20,000 draws, $d_k=4$ gives $2.01$ against $\sqrt4=2$, $d_k=64$ gives $8.05$ against $8$, and $d_k=256$ gives $16.11$ against $16$. Dividing by $\sqrt{d_k}$ yields variance $\sigma^4$ — unit variance under the natural normalization, and independent of $d_k$.

Note why the divisor is $\sqrt{d_k}$ and not $d_k$: the softmax depends on differences of logits, and differences of two independent copies of $s$ have standard deviation $\sqrt2\sigma^2\sqrt{d_k}$. The relevant scale is therefore the standard deviation, so the correct normalization is the square root. Dividing by $d_k$ would make the logits shrink as $1/\sqrt{d_k}$ — attention would become uniform for large heads, and the model would lose all selectivity.

Step 2 — what happens without it. With $n$ logits each of standard deviation $s = \sigma^2\sqrt{d_k}$ and roughly Gaussian, the maximum of the $n$ is about $s\sqrt{2\ln n}$. So the gap between the largest logit and the bulk grows as $\sqrt{d_k}$, and

$$ p_{\max} = \frac{e^{z_{\max}}}{\sum_j e^{z_j}} \longrightarrow 1 \quad\text{as } d_k\to\infty . $$

Measured on a single row with $n=8$ keys (from the table earlier in this module): $d_k=1024$ unscaled gives $p_{\max}=1.0000$ and attention entropy $0.000$; with the divisor it gives $p_{\max}=0.42$ and entropy $1.68$ out of a possible $\ln 8 = 2.079$.

Step 3 — why a saturated softmax cannot learn. The softmax Jacobian is

$$ \frac{\partial p_i}{\partial z_j} = p_i\big(\delta_{ij} - p_j\big). $$

Suppose $p_{\max} = 1-\epsilon$ with $\epsilon\ll1$ and let $i$ be the argmax. Then

$$ \frac{\partial p_i}{\partial z_j} = (1-\epsilon)\big(\delta_{ij} - p_j\big) = \begin{cases}(1-\epsilon)(1 - (1-\epsilon)) \approx \epsilon & j = i\\ -(1-\epsilon)p_j \approx 0 & j\ne i\end{cases} $$

so every entry of that row of the Jacobian is $O(\epsilon)$. Since the gradient reaching the scores is $\partial\mathcal{L}/\partial\mathbf{S} = \mathbf{A}^\top(\partial\mathcal{L}/\partial\mathbf{Z})\mathbf{V}^\top$ contracted through that Jacobian, a saturated row passes essentially zero gradient. The head cannot learn to be differently selective, because it is already maximally selective in a direction chosen by random initialization. This is the same failure as a saturating sigmoid (M06), transplanted into the softmax.

Step 4 — why this matters at depth. One saturated head at layer 1 is survivable; $L$ of them stacked means the attention sublayers are frozen random projections, and only the FFNs learn. The scaling divisor costs one multiplication per score and converts a dead network into a trainable one. It is the single highest-leverage constant in the architecture.

2. Residual stream variance and the $1/\sqrt{2L}$ output-projection initialization

Step 1 — variance accounting. Let $\mathbf{x}_0$ be the embedding with per-component variance $v_0 = 1$. Each block adds two sublayer outputs. Model each addition as independent with per-component variance $c_l$:

$$ \mathrm{Var}(\mathbf{x}_L) = v_0 + \sum_{l=1}^{2L}c_l . $$

Step 2 — the growth. If every sublayer contributes $c_l = 1$, then $\mathrm{Var}(\mathbf{x}_L) = 1 + 2L$ and the residual stream's RMS is $\sqrt{2L+1}$: at $L=48$ that is $9.9$, at $L=96$ it is $13.9$. The stream does not blow up, but its scale depends on depth, so the final LayerNorm's input scale, and the relative contribution of the early layers to the final representation, both drift with depth. Worse, the learned LayerNorm $\gamma$ must compensate for a scale it cannot know in advance.

Step 3 — the fix. Scale the output projection of each sublayer (the $\mathbf{W}_O$ of attention and the $\mathbf{W}_2$ of the FFN) so that its contribution has variance $1/(2L)$. Since a linear map with weights of standard deviation $s$ multiplies variance by $ds^2$, choosing

$$ s \propto \frac{1}{\sqrt{2L}} $$

makes each sublayer's contribution $O(1/L)$, and

$$ \mathrm{Var}(\mathbf{x}_L) = 1 + 2L\cdot\frac{1}{2L} = 2, $$

independent of depth. GPT-2 does exactly this: its residual output projections are initialized with standard deviation $0.02/\sqrt{2L}$ while everything else uses $0.02$. The consequence is that a 96-layer model starts training with the same residual-stream scale as a 12-layer one, which is why depth is trainable at all.

Step 4 — why this is not the same as initialization of the branch. Scaling $\mathbf{W}_O$ controls what the block writes; it does not control what the block computes. The branch still receives unit-scale input from its LayerNorm and computes a full-magnitude function. The initialization controls only the write gain into the bus — which is exactly the variable that must be kept independent of depth.

3. FlashAttention's online softmax: the exactness proof

Claim. The tiled algorithm computes exactly $\operatorname{softmax}(\mathbf{S})\mathbf{V}$, with no approximation, for any tiling.

Proof by induction on the set of processed key blocks. Fix a query row with scores $\mathbf{s}\in\mathbb{R}^{n}$ and values $\mathbf{v}_1,\ldots,\mathbf{v}_n$. After processing a set $S$ of key blocks, maintain

$$ m_S = \max_{j\in S}s_j,\qquad \ell_S = \sum_{j\in S}e^{s_j - m_S},\qquad \mathbf{o}_S = \sum_{j\in S}e^{s_j-m_S}\mathbf{v}_j . $$

Base case: the empty set, with $m = -\infty$, $\ell = 0$, $\mathbf{o} = \mathbf{0}$ (or the first block computed directly).

Inductive step: let block $B$ have $m_B = \max_{j\in B}s_j$, $\ell_B = \sum_{j\in B}e^{s_j - m_B}$, $\mathbf{o}_B = \sum_{j\in B}e^{s_j-m_B}\mathbf{v}_j$, and set $m' = \max(m_S, m_B)$. Define

$$ \ell' = e^{m_S - m'}\ell_S + e^{m_B - m'}\ell_B,\qquad \mathbf{o}' = e^{m_S-m'}\mathbf{o}_S + e^{m_B-m'}\mathbf{o}_B . $$

Then

$$ \ell' = \sum_{j\in S}e^{s_j - m'} + \sum_{j\in B}e^{s_j-m'} = \sum_{j\in S\cup B}e^{s_j-m'}, $$

and identically $\mathbf{o}' = \sum_{j\in S\cup B}e^{s_j-m'}\mathbf{v}_j$ — because multiplying a sum by $e^{m-m'}$ multiplies every term by the same factor and can be pulled inside. So the invariant holds for $S\cup B$ with the correct new maximum $m'$. At the end, $m = \max_j s_j$ over all $n$ keys and

$$ \frac{\mathbf{o}}{\ell} = \frac{\sum_j e^{s_j - m}\mathbf{v}_j}{\sum_j e^{s_j-m}} = \sum_j \frac{e^{s_j}}{\sum_{j'}e^{s_{j'}}}\mathbf{v}_j = \operatorname{softmax}(\mathbf{s})^\top\mathbf{V}, $$

which is the exact definition. $\square$

What is not claimed. The arithmetic is reassociated and the running maximum changes, so the floating-point result differs from the naive one in the last few bits. That is the only difference. The function computed is identical; no entry is dropped, no low-rank structure is assumed, and the backward pass (which recomputes tiles rather than storing them) is also exact, being the transpose of the same computation.

IO accounting. Let $M$ be the number of elements that fit in on-chip SRAM. Take query blocks of $c$ rows with $c = M/d$. Each of the $n/c$ query blocks must read all $n$ keys, each of width $d$:

$$ \text{HBM traffic} = \frac{n}{c}\cdot n d = \frac{n^2 d}{c} = \frac{n^2d^2}{M} . $$

The naive implementation instead writes and re-reads the $n\times n$ score and probability matrices: $\Theta(n^2 + nd)$. When $n^2d^2/M < n^2$, i.e. $d^2 < M$, tiling wins — and $M$ (about $1.7\times10^5$ fp16 elements on an A100 SM) is comfortably larger than $d^2$ for all realistic $d$ up to ~400. This is why the speedup is real rather than cosmetic.

4. Attention FLOPs, the backward pass, and the crossover

Step 1 — forward MACs per layer. For $\mathbf{Q}\mathbf{K}^\top \in \mathbb{R}^{n\times n}$ from $\mathbb{R}^{n\times d_k}$ factors: $n^2d_k$ MACs, $\times h$ heads $= n^2d$ MACs. For $\mathbf{A}\mathbf{V}$: another $n^2d$. So the core is $2n^2d$. Projections: $4\times nd^2$. FFN: $2\times nd_{\text{ff}}d = 8nd^2$ at $d_{\text{ff}} = 4d$. Total $12nd^2 + 2n^2d$.

Step 2 — the crossover. The quadratic term overtakes the linear term when

$$ 2n^2d > 12nd^2 \quad\Longrightarrow\quad n > 6d . $$

Including only the attention part (comparing the core against the attention projections alone), the crossover is $n > 2d$. Both statements appear in the literature; state which you mean. For $d=4096$ the full-block crossover is $n \approx 24{,}576$ — a context length that was unreachable when the transformer was published and is routine now, which is exactly why attention efficiency became a first-class architectural concern.

Step 3 — the backward pass. Reverse-mode differentiation of the block costs roughly twice the forward pass in FLOPs: each matmul in the forward needs two in the backward (one for each operand's gradient). So training costs $\approx 3\times$ the forward per step, giving the familiar

$$ \text{training FLOPs} \approx 6\,N\,T $$

for $N$ non-embedding parameters and $T$ tokens, since forward $= 2NT$ FLOPs when the quadratic term is negligible. The quadratic term is the reason long-context training cost grows faster than this linear law.

Step 4 — memory, the real constraint. The score tensor is $h\cdot n^2$ fp16 elements per layer. At $n=8192$, $h=32$: $32\cdot8192^2\cdot2 = 4.3$ GB per layer, (\times 32) layers $= 137$ GB — impossible. FlashAttention removes the tensor entirely (keeping only $O(n)$ per layer), and the KV cache stores $2Ln_{kv}d_hT$ elements. The conclusion to hold onto: attention's compute is quadratic but tolerable, while its memory is quadratic and fatal, and every efficiency technique in M13 is aimed at the memory first.

Implementation from scratch

A complete decoder-only transformer in one file: RMSNorm, RoPE, causal multi-head attention, SwiGLU, residual blocks, and a training loop that also runs the causality test. This is the architecture every open-weight model you have heard of uses, at a scale where you can run it on a CPU in under a minute.

Worked example

One complete attention head, by hand. Three tokens, $d = 4$, one head with $d_k = 2$ (so $\sqrt{d_k} = 1.4142$). The input, and the three projections:

$$ \mathbf{X} = \begin{pmatrix}1&0&1&0\\0&1&0&1\\1&1&0&0\end{pmatrix},\qquad \mathbf{W}_Q = \begin{pmatrix}1&0\\0&1\\1&0\\0&1\end{pmatrix},\quad \mathbf{W}_K = \begin{pmatrix}0&1\\1&0\\1&1\\0&0\end{pmatrix},\quad \mathbf{W}_V = \begin{pmatrix}1&0\\0&2\\2&0\\0&1\end{pmatrix} . $$

Step 1 — project.

$$ \mathbf{Q} = \mathbf{X}\mathbf{W}_Q = \begin{pmatrix}2&0\\0&2\\1&1\end{pmatrix},\quad \mathbf{K} = \mathbf{X}\mathbf{W}_K = \begin{pmatrix}1&2\\1&0\\1&1\end{pmatrix},\quad \mathbf{V} = \mathbf{X}\mathbf{W}_V = \begin{pmatrix}3&0\\0&3\\1&2\end{pmatrix}. $$

Check token 0: $\mathbf{x}_0 = (1,0,1,0)$; the first column of $\mathbf{W}_Q$ is $(1,0,1,0)$, so $q_{0,0}=1+1=2$; the second column is $(0,1,0,1)$, so $q_{0,1}=0$. Hence $(2,0)$. Same arithmetic for the rest.

Step 2 — score. $\mathbf{S} = \mathbf{Q}\mathbf{K}^\top/\sqrt2$:

$$ \mathbf{S} = \frac{1}{1.4142}\begin{pmatrix}2&2&2\\4&0&2\\3&1&2\end{pmatrix} = \begin{pmatrix}1.4142&1.4142&1.4142\\2.8284&0.0000&1.4142\\2.1213&0.7071&1.4142\end{pmatrix}. $$

Row 0 is constant because $\mathbf{q}_0 = (2,0)$ is orthogonal-adjacent to all three keys in that coordinate — token 0 has a query that is uninformative here, and the softmax will be uniform. Row 1's entry $(1,2)$ comes from $\mathbf{q}_1\cdot\mathbf{k}_1 = 0\cdot1+2\cdot2 = 4$.

Step 3 — softmax, with and without the mask.

key 0 key 1 key 2 row sum
$\mathbf{A}$, no mask, row 0 $0.3333$ $0.3333$ $0.3333$ $1$
$\mathbf{A}$, causal, row 0 $1.0000$ $0$ $0$ $1$
$\mathbf{A}$, no mask, row 1 $0.7679$ $0.0454$ $0.1867$ $1$
$\mathbf{A}$, causal, row 1 $0.9442$ $0.0558$ $0$ $1$
$\mathbf{A}$, no mask, row 2 $0.5760$ $0.1400$ $0.2840$ $1$
$\mathbf{A}$, causal, row 2 $0.5760$ $0.1400$ $0.2840$ $1$

Row 2 is identical in both cases because position 2 can see everything; the mask only removes weight from rows that had a future to look at.

Step 4 — mix values.

$$ \mathbf{Z}_{\text{causal}} = \mathbf{A}_{\text{causal}}\mathbf{V} = \begin{pmatrix}3.0000&0.0000\\2.8326&0.1674\\2.0119&0.9881\end{pmatrix},\qquad \mathbf{Z}_{\text{unmasked}} = \begin{pmatrix}1.3333&1.6667\\2.4904&0.5096\\2.0119&0.9881\end{pmatrix}. $$

The causal output for token 0 is exactly $\mathbf{v}_0 = (3,0)$, as it must be: with one visible key the softmax is a point mass. Unmasked, token 0 averages all three values and gets $(1.33, 1.67)$ — it has been told about the future, and a language model trained in that regime learns to copy the answer.

Step 5 — the divisor's effect, same example. Row 2's raw scores are $(3,1,2)$ instead of $(2.121, 0.707, 1.414)$. Unscaled softmax: $\boldsymbol{\alpha} = (0.665,\;0.090,\;0.245)$ against the scaled $(0.576,\;0.140,\;0.284)$ — sharper, and the output changes from $(2.012, 0.988)$ to $0.665(3,0)+0.090(0,3)+0.245(1,2) = (2.240,\;0.760)$. At $d_k = 2$ the difference is a reshuffling; at $d_k = 1024$ it is the difference between a distribution and a point mass.

Step 6 — the mask bug, quantified. Multiply the unmasked $\mathbf{A}$ by the causal mask instead of adding $-\infty$ before the softmax, and the row sums become $(0.3333,\;0.8133,\;1.0000)$ — the first token's output is $(1.0, 0.0)$ instead of $(3.0, 0.0)$, and the second is $(2.3038, 0.1362)$ instead of $(2.8326, 0.1674)$. Nothing crashes, the shapes are right, and the row sums are the only symptom. This is why the assertion A.sum(-1) == 1 belongs in every attention implementation's test suite.

Common misconceptions

"Attention weights are explanations."

A high attention weight from query $i$ to key $j$ means the weighted average leans on $\mathbf{v}_j$ — it does not mean $\mathbf{v}_j$ caused the output, because the value is transformed by $\mathbf{W}_O$ and then by every subsequent layer, and because the softmax normalizes away absolute scale. The empirical case against reading weights as importance is strong: different heads with nearly identical outputs can have very different weight patterns, and gradient-based attributions frequently disagree with weights rank-for-rank (Jain and Wallace, 2019). The counter-argument (Wiegreffe and Pinter, 2019) is that attention can still be predictive of importance even if it is not a faithful explanation. The honest position: attention weights are a useful diagnostic and a weak explanation, and the question "are attention weights explanations" is genuinely contested rather than settled.

"The transformer has no inductive bias — it learns everything from data."

It has several, all structural. Permutation equivariance of the attention operator (which is why position must be injected at all); per-token independence of the FFN; a rank-$d_k$ bilinear form per head, which limits each head to comparing along $d_k$ directions; and, with RoPE, an explicit prior that scores should depend on relative offset. The accurate claim is that the transformer's biases are weaker and more general than a convolution's locality prior — which is why it needs more data to reach the same accuracy on vision tasks, and why it wins when data is plentiful.

"Attention is $O(n^2)$, so long context is impossible."

Three separate claims are being conflated. The memory for the score matrix is $O(n^2)$ and is genuinely fatal — which is what FlashAttention fixes, reducing it to $O(n)$ while keeping the computation exact. The compute is $O(n^2d)$ and is not fixed by any constant-factor trick; it requires changing the function (sliding windows, linear attention, state-space models — M13). And the practical limit is usually neither: it is the KV cache, which is $O(n)$ in length but multiplied by batch size and layer count, and which is what actually runs a server out of memory first.

"The feed-forward network is just a nonlinearity after attention."

It holds roughly two-thirds of every block's parameters ($8d^2$ of $12d^2$), it never mixes positions, and it is where the model's stored associations live. Written as $\sum_i a_i(\mathbf{x})\mathbf{v}_i$, it is a key-value memory with $4d$ slots whose addressing is content-dependent — the mechanism by which "a word following Tuesday" or "the capital of" retrieves anything at all. Removing it and keeping attention leaves a model that can route information but has nothing to route it to.

"The $1/\sqrt{d_k}$ is a normalization detail; you can drop it if you tune the learning rate."

It cannot be compensated by the learning rate, because the problem is not step size — it is that the softmax is saturated at initialization, so its Jacobian is $O(\epsilon)$ and the gradient is zero regardless of how large the step is. The derivation is unambiguous: the score's standard deviation is $\sigma^2\sqrt{d_k}$, so without the divisor the logits' spread grows without bound in $d_k$, $p_{\max}\to1$, and $\partial p_i/\partial z_j\to0$. What you can tune is the initial scale of $\mathbf{W}_Q,\mathbf{W}_K$ — which is mathematically the same intervention arriving through a different door.

"Pre-LN and post-LN differ only in where you put the normalization."

They differ in what the gradient path contains. In pre-LN the block is $\mathbf{I}+\mathbf{J}$ and every term of the expanded product contains an identity; in post-LN the block is $\mathbf{J}_{\operatorname{LN}}(\mathbf{I}+\mathbf{J})$, so every term carries at least one normalization Jacobian, whose contraction $\approx(1-2/d)^{1/2}$ per block compounds with depth. The observable consequences are the practical signature: post-LN transformers need learning-rate warmup and diverge without it at moderate depth, while pre-LN transformers train without warmup. Both facts are well established experimentally, and the theoretical depth-dependence was worked out by Xiong et al. (2020).

"Position is always added to the input embeddings."

That is one of three designs, and the least used today. Sinusoidal and learned-absolute embeddings add a position vector at the input; RoPE rotates queries and keys at every layer and adds nothing; ALiBi adds a distance-dependent bias directly to the scores. The three encode different assumptions — absolute address, relative rotation, or distance penalty — and their behaviour on sequences longer than the training length differs sharply. Knowing which one a model uses is necessary to reason about anything it claims about context extension.

Exercises

Warm-up (check understanding)

1. $B=2$, $T=16$, $d=512$, $h=8$. Give the shape of every tensor in one block: after the first LN, after the Q projection, after the head split, the score matrix, the attention output after merging heads, and after $\mathbf{W}_O$.

Solution LN: $(2,16,512)$. $\mathbf{Q}$: $(2,16,512)$. After reshape/transpose: $(2,8,16,64)$. Scores: $(2,8,16,16)$ — $d_k = 64$. After $\mathbf{AV}$: $(2,8,16,64)$; after transpose+reshape: $(2,16,512)$; after $\mathbf{W}_O$: $(2,16,512)$. The number of elements is invariant across the head split; only the axis order changes.

2. For $d=1024$, $h=16$, $d_{\text{ff}}=4096$, give the parameter count of one block and the fraction in the FFN.

Solution Attention: $4\cdot1024^2 + 4\cdot1024 = 4{,}198{,}400$. FFN: $2\cdot1024\cdot4096 + 4096 + 1024 = 8{,}392{,}704$. Two LayerNorms: $4\cdot1024 = 4096$. Block: $12{,}595{,}200$. FFN share: $66.6\%$. The $8d^2$ versus $4d^2$ ratio is exact in the large-$d$ limit.

3. Why is the causal attention output for position 0 always exactly $\mathbf{v}_0$, regardless of the data?

Solution Position 0 has one visible key, so its score row after masking has exactly one finite entry. The softmax over a single finite entry plus $-\infty$ elsewhere is $1$ at that entry, so the output is $1\cdot\mathbf{v}_0 + 0\cdot(\ldots) = \mathbf{v}_0$. This is a useful sanity check on any implementation: after one block the first token's attention output must be $\mathbf{W}_O\mathbf{v}_0$.

4. Compute the softmax of $(2, 0, -1)$ and its entropy. Is it closer to uniform or to one-hot?

Solution $e^{(\cdot)} = (7.389, 1.000, 0.368)$, sum $8.757$, so $\mathbf{p} = (0.8438, 0.1142, 0.0420)$. Entropy $= -(0.8438\ln0.8438 + 0.1142\ln0.1142 + 0.0420\ln0.0420) = 0.1434 + 0.2478 + 0.1328 = 0.524$ against a maximum of $\ln3 = 1.099$. Closer to one-hot — and these logits span only 3 units, which is why a spread of $\sqrt{d_k}$ at $d_k=64$ (about 8 per component) is so destructive.

Core (do the math)

5. Derive $\mathrm{Var}(\langle\mathbf{q},\mathbf{k}\rangle)$ for iid zero-mean components, and compute the ratio of the logit standard deviations for $d_k=64$ and $d_k=256$ both with and without the divisor.

Solution $\mathrm{Var}(s) = \sum_i\mathrm{Var}(q_ik_i) = \sum_i\mathbb{E}[q_i^2]\mathbb{E}[k_i^2] = d_k\sigma^4$, using independence and zero mean, so std $=\sigma^2\sqrt{d_k}$. With $\sigma=1$: $d_k=64$ gives $8$, $d_k=256$ gives $16$ — a factor $2$ without the divisor. With it, both give $1$: the ratio becomes $1$. The general statement: without normalization the spread grows as $\sqrt{d_k}$, so a 4× increase in head width doubles the logit spread and halves the effective temperature.

6. Prove that a self-attention layer is permutation-equivariant, and state the one place in a full transformer where that property is deliberately broken.

Solution With $\mathbf{X}' = \mathbf{P}\mathbf{X}$: $\mathbf{Q}' = \mathbf{P}\mathbf{Q}$ etc., so $\mathbf{S}' = \mathbf{P}\mathbf{S}\mathbf{P}^\top$, and since the row-wise softmax commutes with simultaneous row and column permutation, $\mathbf{A}' = \mathbf{P}\mathbf{A}\mathbf{P}^\top$. Then $\mathbf{A}'\mathbf{V}' = \mathbf{P}\mathbf{A}\mathbf{P}^\top\mathbf{P}\mathbf{V} = \mathbf{P}\mathbf{A}\mathbf{V}$, and $\mathbf{W}_O$ acts on features only, so $\operatorname{Attn}(\mathbf{P}\mathbf{X}) = \mathbf{P}\operatorname{Attn}(\mathbf{X})$. The property is deliberately broken by whatever injects position — RoPE's rotation, an added positional embedding, or ALiBi's distance bias — and by nothing else. The FFN, LayerNorm and residuals are all per-token and preserve equivariance.

7. Verify the sinusoidal relative-position property numerically for $\omega = 0.1$: compute $\mathbf{PE}(pos)$ and $\mathbf{PE}(pos+k)$ for $pos = 5$, $k = 3$, and check that the second is a rotation of the first.

Solution $\mathbf{PE}(5) = (\sin0.5,\cos0.5) = (0.4794, 0.8776)$. $\mathbf{PE}(8) = (\sin0.8,\cos0.8) = (0.7174, 0.6967)$. The rotation by $\omega k = 0.3$: $\mathbf{R}(0.3) = \begin{pmatrix}\cos0.3 & \sin0.3\\ -\sin0.3 & \cos0.3\end{pmatrix} = \begin{pmatrix}0.9553&0.2955\\-0.2955&0.9553\end{pmatrix}$. Applying it: $(0.9553\cdot0.4794 + 0.2955\cdot0.8776,\; -0.2955\cdot0.4794+0.9553\cdot0.8776) = (0.4580+0.2593,\;-0.1417+0.8384) = (0.7173,\;0.6967)$. Matches $\mathbf{PE}(8)$ to four decimals. And the inner product $\langle\mathbf{PE}(5),\mathbf{PE}(8)\rangle = 0.3439+0.6114 = 0.9553 = \cos(0.3)$ — a function of $k$ alone.

8. Prove RoPE's relative property, then show that applying the rotation to $\mathbf{q}$ only (not to $\mathbf{k}$) destroys it, by computing both scores for the pair in the module's table.

Solution The proof: $\langle\mathbf{R}_m\mathbf{q},\mathbf{R}_n\mathbf{k}\rangle = \mathbf{q}^\top\mathbf{R}_m^\top\mathbf{R}_n\mathbf{k} = \mathbf{q}^\top\mathbf{R}_{n-m}\mathbf{k}$, using $\mathbf{R}_m^\top = \mathbf{R}_{-m}$ and $\mathbf{R}_a\mathbf{R}_b = \mathbf{R}_{a+b}$. If only $\mathbf{q}$ is rotated, the score is $\mathbf{q}^\top\mathbf{R}_m^\top\mathbf{k} = \mathbf{q}^\top\mathbf{R}_{-m}\mathbf{k}$, which depends on $m$ alone — position, not offset. Check with $\mathbf{q}=(1,0)$, $\mathbf{k}=(0,1)$, $\theta=1$: the correct pair $(m,n)=(1,2)$ gives $-0.8415$ (offset 1), and $(0,1)$ also gives $-0.8415$. With only $\mathbf{q}$ rotated, $(m,n)=(1,2)$ gives $\mathbf{q}^\top\mathbf{R}_{-1}\mathbf{k} = (\cos(-1), -\sin(-1))\cdot(0,1) = -\sin(-1)\cdot1$... evaluating: $\mathbf{R}_{-1}\mathbf{k} = (-\sin(-1), \cos(-1)) = (0.8415, 0.5403)$, and $\mathbf{q}\cdot$ that $= 0.8415$; while $(m,n) = (0,1)$ gives $\mathbf{q}^\top\mathbf{k} = 0$. Different offsets, so the property holds; but $(1,2)$ and $(2,3)$ would give the same value under the broken scheme too — check: $m=2$ gives $\mathbf{R}_{-2}\mathbf{k} = (-\sin(-2),\cos(-2)) = (0.9093,-0.4161)$, dot with $(1,0)$ = $0.9093 \ne 0.8415$. So the broken scheme depends on $m$ (absolute position) rather than on $n-m$; the two coincide only when comparing pairs with equal $m$.

9. A 70B model has $L=80$, $h=64$, $d_h=128$. Compute the KV cache per token and at 8192 context in fp16, for MHA and for GQA with $n_{kv}=8$.

Solution Per token MHA: $2\cdot80\cdot64\cdot128\cdot2 = 2{,}621{,}440$ bytes $= 2.5$ MiB. At 8192 tokens: $2.5\ \text{MiB}\times8192 = 20$ GiB per sequence. With $n_{kv}=8$: $2\cdot80\cdot8\cdot128\cdot2 = 327{,}680$ bytes $= 320$ KiB per token, and $2.5$ GiB at 8192 — an $8\times$ reduction, exactly the ratio $64/8$. At $2.5$ GiB per sequence you fit 30 sequences in 80 GB; at 20 GiB you fit 4. This is the arithmetic that made GQA universal.

Stretch (build or break it)

10. Write the causality test as a function, and predict exactly what it returns for a mask applied after the softmax.

Solution ```python @torch.no_grad() def causality_test(model, x, t=None): t = x.shape[1] // 2 if t is None else t a = model(x) x2 = x.clone(); x2[:, t] = (x2[:, t] + 1) % model.tok.num_embeddings b = model(x2) return (a[:, :t] - b[:, :t]).abs().max().item(), (a[:, t:] - b[:, t:]).abs().max().item() ``` A correct causal model returns `(0.0, > 0)`: the diff must be *exactly* zero, not merely small, because each earlier position's entire computation is a function of a strict prefix. A post-softmax mask still blocks the future, so the first number is also `0.0` — the test does not catch that bug. What it catches is the *transposed* mask, a mask of the wrong shape that broadcasts harmlessly, and a missing mask; all three give a nonzero first number. This is why you need both the causality test and the row-sum assertion.

11. Derive the FlashAttention IO bound and evaluate it for $n=16384$, $d=128$, with SRAM holding $M=100{,}000$ fp16 elements. Compare with the naive implementation.

Solution Query blocks have $c = M/d = 781$ rows; there are $n/c$ of them, each reading all $n$ keys of width $d$: traffic $= (n/c)\cdot nd = n^2d/c = n^2d^2/M = (16384^2\cdot128^2)/10^5 = 4.4\times10^{9}$ element-transfers. Naive: writing and re-reading the $n\times n$ matrix is $\Theta(n^2) = 2.7\times10^{8}$ elements per head — so for one head the naive version moves *less* data, and the tiled version wins only because it processes all $h$ heads with the same $O(n)$ Q block resident. The real comparison in the paper is against an implementation that materializes per-head matrices and re-reads them across the backward pass; the tiled version's advantage grows with the number of passes and with $n$. The honest statement: tiling reduces HBM traffic from $O(n^2+nd)$ *per pass* with many passes, to $O(n^2d^2/M)$ with all passes fused, and it eliminates the $O(n^2)$ *allocation*, which is the constraint that actually prevents 16k context from running at all.

12. Show that a single head with $d_k=1$ cannot distinguish the sequences $(a,b)$ and $(b,a)$ under any projections, while $d_k=2$ can — and connect this to the rank argument.

Solution With $d_k=1$ the score is $\mathbf{S}_{ij} = (w_Q\cdot\mathbf{x}_i)(w_K\cdot\mathbf{x}_j)$, so the score matrix is the outer product of two vectors — rank 1. Permuting the inputs permutes rows and columns of that outer product identically, and the softmax of $uv^\top$ depends only on the *multiset* of the $w_Q\cdot\mathbf{x}_i$, so the attention output cannot encode which token came first. With $d_k=2$ the score is a rank-2 bilinear form with matrix $\mathbf{W}_Q^\top\mathbf{W}_K$, which can be asymmetric ($\mathbf{x}_a^\top\mathbf{M}\mathbf{x}_b \ne \mathbf{x}_b^\top\mathbf{M}\mathbf{x}_a$), so direction-dependent scores become representable. This is exactly the geometric content of $d_k$: it is the rank of the comparison the head can make, and rank 1 is order-blind.
