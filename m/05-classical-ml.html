Classical Machine Learning

Empirical risk, the models that minimise it, and the metrics that decide whether it worked.

on this page

Why this module exists

The models in this module are the ones whose behaviour you can fully derive, and they are where the vocabulary of the rest of the course is defined: overfitting, regularisation, the kernel trick, bootstrap aggregation, gradient boosting, the bias–variance decomposition, cross-validation, AUC. Without them, a neural network is a black box with knobs, and the same failure modes appear unnamed — a model that memorises, a metric that flatters, a validation split that leaks. More concretely: the SVM dual is where the representer theorem comes from, and attention's kernel-like structure (M12) is unreadable without it; gradient boosting is functional gradient descent, which frames every later discussion of additive models; and precision, recall, calibration, and AUC are the tools with which M20 judges a language model. This module is deliberately low on proofs-of-existence and high on derivations you can redo on paper.

Core concepts

The supervised setup and empirical risk minimisation

(1) Intuition. You have pairs $(\mathbf{x}_i, y_i)$; you want a function that predicts $y$ from $\mathbf{x}$ for pairs you have not seen. Everything else is a choice about how to measure error and how to keep the function from cheating.

(2) Formal. With a loss $\ell(\hat y, y)$, empirical risk is $\hat{R}(\mathbf{w}) = \frac1N\sum_i\ell(f_{\mathbf{w}}(\mathbf{x}_i), y_i)$ and ERM returns $\arg\min_{\mathbf{w}}\hat{R}(\mathbf{w}) + \lambda\Omega(\mathbf{w})$, where $\Omega$ is a complexity penalty. The true risk is $\mathbb{E}_{(\mathbf{x},y)\sim P}[\ell]$ over the data distribution you do not have.

(3) Why. ERM is a proxy: minimising training error is only a means, and the gap between $\hat R$ and $R$ is what generalisation means. Every classical model in this module is a different answer to the same two questions — which function class, and which penalty — and the whole of M08 is the modern version of that gap.

(4) Micro-example. Two hypotheses for 5 points: $A$ predicts all 5 correctly and is a degree-4 polynomial; $B$ predicts 4 and is a line. $\hat R_A = 0 < \hat R_B = 0.2$, but if the truth is linear, $R_B$ much less than $R_A$. ERM prefers $A$; a penalty on curvature prefers $B$. That trade is the module.

Linear regression, solved three ways

(1) Intuition. Fit the hyperplane that minimises squared vertical distance. The normal equations are the closed form; QR/SVD are the numerically safe way to compute it; gradient descent is how you would do it if the matrix were too large to factorise.

(2) Formal. $\hat{\mathbf{w}} = \arg\min\|\mathbf{X}\mathbf{w}-\mathbf{y}\|^2$ gives $\mathbf{X}^\top\mathbf{X}\mathbf{w} = \mathbf{X}^\top\mathbf{y}$, so $\hat{\mathbf{w}} = (\mathbf{X}^\top\mathbf{X})^{-1}\mathbf{X}^\top\mathbf{y}$. Equivalently, orthogonally project $\mathbf{y}$ onto $\mathcal{C}(\mathbf{X})$ (M01), so the residual is orthogonal to every column.

(3) Why. Three solve paths, three failure modes. Normal equations square the condition number ($\kappa(\mathbf{X}^\top\mathbf{X}) = \kappa(\mathbf{X})^2$) and fail outright when $\mathbf{X}$ has dependent columns. QR (or SVD) operates on $\mathbf{X}$ itself, so it is accurate to $\kappa(\mathbf{X})$ and handles rank deficiency by truncation; it costs $O(Nd^2)$ instead of $O(Nd^2 + d^3)$ but is the right default. Gradient descent costs $O(Nd)$ per step and never forms a $d\times d$ matrix, which is the only option when $d$ is enormous or the data is streamed.

(4) Micro-example. $\mathbf{X} = \begin{pmatrix}1&0\\0&1\\1&1\\2&1\end{pmatrix}$, $\mathbf{y} = (1,2,3,4)$: $\mathbf{X}^\top\mathbf{X} = \begin{pmatrix}6&3\\3&3\end{pmatrix}$ and $\mathbf{X}^\top\mathbf{y} = (12,9)$, so $\mathbf{w} = (1,2)$ with residuals identically zero — the model interpolates, so there is no training error to see and nothing about generalisation to infer.

Ridge, lasso, and why only one sparsifies

(1) Intuition. Ridge shrinks coefficients smoothly toward zero; lasso shrinks some of them exactly to zero. The difference is geometry: the constraint regions have different shapes, and the lasso's has corners on the axes.

(2) Formal. Ridge: $\min\|\mathbf{X}\mathbf{w}-\mathbf{y}\|^2 + \lambda\|\mathbf{w}\|_2^2$, giving $\hat{\mathbf{w}} = (\mathbf{X}^\top\mathbf{X}+\lambda\mathbf{I})^{-1}\mathbf{X}^\top\mathbf{y}$. Lasso: $\min\|\mathbf{X}\mathbf{w}-\mathbf{y}\|^2 + \lambda\|\mathbf{w}\|_1$, with no closed form but a coordinate-wise soft-threshold solution.

(3) Why. The level sets of the lasso penalty are diamonds, whose vertices sit on the axes; the level sets of the squared error are ellipses, and where an ellipse first touches a diamond it usually touches at a vertex — a coordinate exactly zero. The ridge ball is round, so tangency happens at a generic point with all coordinates nonzero. That is the geometric reason, and derivation 2 gives the algebraic counterpart.

(4) Micro-example. One feature with correlation $\rho = \mathbf{x}^\top\mathbf{y} = 3$ and $\lambda = 1.5$: lasso gives $\operatorname{sign}(3)\max(3-1.5, 0) = 1.5$, while ridge gives $3/(1+1.5) = 1.2$. With $\rho = 1$ the lasso gives exactly $0$ and ridge gives $0.4$ — sparsity versus shrinkage in one line. On the four-point data above, $\lambda = 0.5$ moves $\hat{\mathbf{w}}$ from $(1,2)$ to $(1.0909, 1.6364)$.

Logistic regression and IRLS

(1) Intuition. Linear regression predicts a number; classification needs a probability. Put a sigmoid on the linear score and fit by maximum likelihood — that is logistic regression, and it is a linear model in a transformed space, not a different animal.

(2) Formal. $p_i = \sigma(\mathbf{x}_i^\top\mathbf{w})$, $\ell(\mathbf{w}) = \sum_i[y_i\log p_i + (1-y_i)\log(1-p_i)]$, so $\nabla\ell = \mathbf{X}^\top(\mathbf{y}-\mathbf{p})$ and $\mathbf{H} = -\mathbf{X}^\top\mathbf{W}\mathbf{X}$ with $\mathbf{W} = \operatorname{diag}(p_i(1-p_i))$. The Newton step is

$$\mathbf{w}_{t+1} = \mathbf{w}_t + (\mathbf{X}^\top\mathbf{W}\mathbf{X})^{-1}\mathbf{X}^\top(\mathbf{y}-\mathbf{p}),$$

which is weighted least squares with weights $p_i(1-p_i)$ — hence iteratively reweighted least squares.

(3) Why. The log-likelihood is concave (since $\mathbf{H} \le 0$), so Newton converges to the global optimum in a handful of iterations and no learning rate is needed. Compare gradient descent, which needs the same step-size analysis as M04 and can be slow when classes are separable (the optimum is at infinity). The Hessian's weights are also diagnostic: examples the model is confident about (…$p$ near 0 or 1) get almost no weight, so they stop influencing the fit.

(4) Micro-example. The four-point data with $\mathbf{w}_0 = \mathbf{0}$: $\mathbf{p} = (0.5,0.5,0.5,0.5)$, $\mathbf{g} = (-8,-10,-7.5)$, and $\mathbf{W} = 0.25\mathbf{I}$, so

$$\mathbf{H} = -0.25\,\mathbf{X}_b^\top\mathbf{X}_b \quad\text{with}\quad \mathbf{X}_b = \begin{pmatrix}1&1&0\\1&0&1\\1&1&1\\1&2&1\end{pmatrix}.$$

One Newton step reaches $\mathbf{w} = (-2, 4, 8)$ and probabilities $(0.881, 0.998, 1.000, 1.000)$ — essentially converged, with the bias driven large because the data is separable.

Basis expansion and the kernel trick

(1) Intuition. A linear model is only linear in the features you give it. Give it $\phi(\mathbf{x})$ — squares, products, splines — and it becomes nonlinear in the original inputs while remaining linear in the weights, so all the linear machinery still applies.

(2) Formal. Replace $\mathbf{x}$ by $\phi(\mathbf{x})\in\mathbb{R}^D$ and fit $\mathbf{w}^\top\phi(\mathbf{x})$. If the algorithm only ever uses inner products $\langle\phi(\mathbf{x}_i),\phi(\mathbf{x}_j)\rangle$, define $k(\mathbf{x}_i,\mathbf{x}_j) = \langle\phi(\mathbf{x}_i),\phi(\mathbf{x}_j)\rangle$ and never form $\phi$: the kernel trick. The representer theorem states that the minimiser of any regularised risk of the form $\sum_i\ell(y_i, f(\mathbf{x}_i)) + \lambda\|f\|_{\mathcal{H}}^2$ over $f$ in a reproducing kernel Hilbert space lies in the span of the training data, $f^{*} = \sum_i\alpha_ik(\mathbf{x}_i,\cdot)$ — so an infinite-dimensional problem reduces to $N$ coefficients.

(3) Why. The trick converts an explicit feature map of dimension $D$ (possibly infinite, as with the Gaussian kernel) into an $N\times N$ Gram matrix. Its cost is that prediction requires touching every training point, so inference is $O(N)$ per query rather than $O(d)$ — which is precisely the tradeoff that kernel methods lose on large datasets and that attention (M12) revisits in a learned form.

(4) Micro-example. The polynomial kernel $k(\mathbf{a},\mathbf{b}) = (1+\mathbf{a}^\top\mathbf{b})^2$ on $\mathbb{R}^2$ equals $\langle\phi(\mathbf{a}),\phi(\mathbf{b})\rangle$ with $\phi(\mathbf{a}) = (1, \sqrt2a_1, \sqrt2a_2, a_1^2, \sqrt2a_1a_2, a_2^2)$ — six explicit features for a two-dimensional input, computed with one dot product and one squaring.

Decision trees and the CART criterion

(1) Intuition. A tree asks a sequence of yes/no questions, each chosen to make the two resulting groups as pure as possible. It is the most interpretable model in the module and the least stable.

(2) Formal. For a node with class proportions $\mathbf{p}$, impurity is Gini $G = 1-\sum_k p_k^2$ or entropy $H = -\sum_k p_k\log p_k$. A split into left/right with fractions $n_L/n$, $n_R/n$ is scored by the weighted impurity decrease

$$\Delta = I(\text{parent}) - \frac{n_L}{n}I(\text{left}) - \frac{n_R}{n}I(\text{right}),$$

and CART greedily takes the largest $\Delta$ over all features and thresholds.

(3) Why. Greedy is not optimal — finding the globally best tree is NP-hard — but the impurity decrease is exactly the criterion that a top-down search can evaluate incrementally, which is what makes the algorithm $O(dN\log N)$ with sorting rather than exponential. Gini and entropy almost always pick the same split; the difference is that entropy penalises impurity more sharply near purity.

(4) Micro-example. Parent node $(30, 10)$: $G = 1 - 0.75^2 - 0.25^2 = 0.375$. Splitting into $(20,0)$ and $(10,10)$ gives weighted Gini $0.5\cdot0 + 0.5\cdot0.5 = 0.25$, a gain of $0.125$. The competing split $(18,2)/(12,8)$ gives $0.45\cdot0.198 + 0.55\cdot0.5 = 0.33$, a gain of only $0.045$. The gain criterion strongly prefers the split that isolates a pure group, which is the behaviour you want.

Bagging and random forests

(1) Intuition. A single tree is unstable — perturb the data slightly and the tree changes shape. Average many trees grown on bootstrap resamples and the variance falls, without the bias rising much.

(2) Formal. Bagging: draw $B$ bootstrap samples, fit $f_b$ on each, predict $\frac1B\sum_bf_b$. Random forests add feature subsampling at each split. For $B$ predictors each with variance $\sigma^2$ and pairwise correlation $\rho$,

$$\mathrm{Var}\left(\frac1B\sum_b f_b\right) = \rho\sigma^2 + \frac{1-\rho}{B}\sigma^2 .$$

(3) Why. The formula shows the two knobs exactly. More trees ($B\to\infty$) removes only the second term; the floor is $\rho\sigma^2$, set by correlation. Feature subsampling exists solely to lower $\rho$ — it decorrelates the trees, which is why a random forest beats plain bagging. It also shows the limit: if all trees saw identical data they would be identical, $\rho=1$, and averaging would do nothing.

(4) Micro-example. $\sigma^2 = 1$, $\rho = 0.4$, $B = 25$: variance is $0.4 + 0.6/25 = 0.424$. Moving to $B=100$ gives $0.406$ — most of the benefit is already captured, and the remaining $0.4$ can only be removed by decorrelating the trees. Practical advice follows directly: past a few hundred trees, buy decorrelation, not more trees.

Gradient boosting as functional gradient descent

(1) Intuition. Boosting builds a model additively, one weak learner at a time, each fitted to what the current model gets wrong. Framed properly, it is gradient descent where the "parameter" is an entire function.

(2) Formal. With $F_{t} = F_{t-1} + \nu h_t$ and $h_t$ fitted to the negative gradient (pseudo-residuals) $r_i = -\partial\ell(y_i, F(\mathbf{x}_i))/\partial F(\mathbf{x}_i)$, evaluated at $F = F_{t-1}$. For squared loss the pseudo-residual is $y_i - F_{t-1}(\mathbf{x}_i)$; for logistic loss it is $y_i - p_i$.

(3) Why. The function-space view explains every hyperparameter at once: the learning rate $\nu$ (shrinkage) is a step size, the number of rounds is the iteration count, and the tree depth controls the smoothness of the step — a depth-1 stump can only move along axis-aligned steps, so deeper trees are a more expressive step direction but overfit faster. It also explains why boosting reduces bias and raises variance, exactly opposite to bagging.

(4) Micro-example. Four points with targets $(1, 2, 3, 4)$, $F_0 = 2.5$ (the mean). Squared-loss residuals: $(-1.5,-0.5,0.5,1.5)$. Fit a stump with $\nu = 0.1$ that predicts $-1$ on the left two and $+1$ on the right two; the update moves predictions to $2.4$ and $2.6$. Residuals shrink, and the next tree sees smaller targets — bias falls monotonically, and if you kept going with $\nu = 1$ the model would interpolate and the variance would explode.

kNN and the curse of dimensionality

(1) Intuition. To predict, find the $k$ nearest training points and average their labels. It is the laziest possible learner — no training at all — and it exposes what "nearest" costs in high dimension.

(2) Formal. $\hat f(\mathbf{x}) = \frac1k\sum_{i\in\mathcal{N}_k(\mathbf{x})}y_i$. Under mild conditions it is consistent as $N\to\infty$ with $k\to\infty$, $k/N\to 0$. Distance concentration: for i.i.d. coordinates, the ratio of nearest to farthest distance approaches 1 as $d$ grows.

(3) Why. In high dimension every point is almost equidistant from every other, so "nearest neighbour" stops being informative and $k$NN degenerates toward a constant predictor. This is the concrete meaning of the curse of dimensionality, and it is the reason representation learning exists: the useful move is not a better neighbour search but a learned metric in which distances mean something.

(4) Micro-example. 1000 uniform points in $[0,1]^d$ and one query point: the nearest/farthest distance ratio is $0.0074$ at $d=2$, $0.223$ at $d=10$, $0.720$ at $d=100$, and $0.898$ at $d=1000$. By 1000 dimensions the nearest neighbour is 90% as far away as the farthest — the neighbourhood has stopped being local. Embedding dimensions in the hundreds with a learned metric are viable precisely because the metric is not uniform.

The bias–variance decomposition

(1) Intuition. Your expected error at a point has three parts: the noise in the data (irreducible), how far the average model is from the truth (bias), and how much the model moves between datasets (variance).

(2) Formal. For $y = f(\mathbf{x})+\varepsilon$ with $\mathbb{E}[\varepsilon] = 0$, $\mathrm{Var}[\varepsilon] = \sigma^2$, and $\hat f$ fitted on a random dataset,

$$\mathbb{E}\left[(y-\hat f(\mathbf{x}))^2\right] = \sigma^2 + \left(\mathbb{E}[\hat f(\mathbf{x})]-f(\mathbf{x})\right)^2 + \mathrm{Var}[\hat f(\mathbf{x})].$$

(3) Why. It makes the complexity trade explicit and falsifiable: a deep tree has low bias and high variance, a stump the reverse, and the sum is U-shaped in complexity. It also explains why ensembles help in two different ways — averaging reduces variance, boosting reduces bias — and why "more data" helps only the variance term.

(4) Micro-example. $f(x) = x$ on $[0,1]$, noise $\sigma^2 = 0.04$, $N = 20$ points, and a model that is piecewise constant on $m$ equal bins. Squared bias is approximately $1/(12m^2)$; the variance of each bin's mean estimate contributes $\sigma^2m/N$ to the prediction error. Total $\approx 0.04(1+m/20) + 1/(12m^2)$: $m=1$ gives $0.1253$, $m=5$ gives $0.0533$, $m=20$ gives $0.0802$ — a U-shape whose minimum at $m\approx5$ is nowhere near either extreme, and whose right-hand rise is variance.

Drag the polynomial degree and watch the fit, the squared bias, the variance, and the test error move on the same axes. Notice that the minimum of the test error is not at the minimum of either component, and that the training error keeps falling after the test error turns up.

Cross-validation

(1) Intuition. To know how a model will do on unseen data, hold data out. To know how the procedure (including its hyperparameter choice) will do, hold out data, choose on the rest, then measure once.

(2) Formal. $K$-fold cross-validation partitions the data into $K$ folds, trains $K$ times on $K-1$ folds, and averages the held-out errors. Its bias is pessimistic (each model sees $(K-1)/K$ of the data) and its variance falls with $K$ but so does the training-set size per fit.

(3) Why. The subtlety is leakage: any preprocessing fitted on the full dataset before splitting — feature scaling, imputation, target encoding, feature selection — leaks test information into training and reports an optimistic score. Cross-validation must wrap the entire pipeline, which is why pipelines exist as objects. The same principle governs a language model's held-out set (M20), where the leak is contamination rather than scaling.

(4) Micro-example. Choosing $\lambda$ by 5-fold CV: for each of 5 held-out folds you refit on the other 4 for each candidate $\lambda$, then average the 5 errors. If you instead scaled the features using all the data before folding, the scaling constants encode the held-out means and variances, and the reported error is too low — often by more than the differences between candidate $\lambda$ values, which is exactly when it matters.

Metrics: what to measure, and how each one lies

(1) Intuition. Accuracy is the fraction you got right, and it is the first thing people report, and it is the one that lies worst under imbalance. Precision asks "when I say positive, how often am I right"; recall asks "of the real positives, how many did I find"; and calibration asks whether "70% sure" means 70%.

(2) Formal. Confusion matrix counts $\mathrm{TP},\mathrm{FP},\mathrm{FN},\mathrm{TN}$; precision $= \mathrm{TP}/(\mathrm{TP}+\mathrm{FP})$; recall $= \mathrm{TP}/(\mathrm{TP}+\mathrm{FN})$; $F_1 = 2PR/(P+R)$. ROC-AUC is the probability that a random positive scores above a random negative; PR-AUC (average precision) summarises the precision–recall curve. Calibration error is $\sum_b \frac{n_b}{N}\left|\text{acc}(b) - \text{conf}(b)\right|$ over confidence bins.

(3) Why. ROC-AUC is insensitive to the base rate, which sounds like a virtue and is a vice when positives are rare: a model can have an excellent ROC-AUC while almost every positive prediction is wrong. PR-AUC's baseline is the prevalence itself, so it exposes that. Calibration is separate again — a model can rank perfectly (AUC 1.0) and be systematically overconfident, which is fatal for any downstream decision that treats probabilities as probabilities.

(4) Micro-example. 1000 examples, $\mathrm{TP} = 30$, $\mathrm{FP} = 20$, $\mathrm{FN} = 10$, $\mathrm{TN} = 940$: precision $0.60$, recall $0.75$, $F_1 = 0.667$, accuracy $0.97$ — and predicting everything negative scores $0.94$. Now an imbalanced benchmark with 1% positives: ROC-AUC $0.8323$ but average precision only $0.1610$, against a baseline of $0.01$. The ROC number says "good", the PR number says "better than chance by a factor of 16 and useless for triage". Both are true.

The algorithm, step by step

The algorithm is fitting a classification tree by CART's greedy split search, because it exercises impurity, greedy search, recursion, and the variance argument for ensembles, and because it is the base learner for both bagging and boosting.

  1. Start at the root with all $N$ training examples and their labels.
  2. For each candidate feature $j$ and each candidate threshold $t$ (the midpoints between sorted distinct values): split the node into $L = \{i : x_{ij}\le t\}$ and $R$ its complement. Reject splits that leave fewer than min_samples_leaf examples on a side.
  3. Compute the impurity decrease $\Delta = I(\text{node}) - \frac{n_L}{n}I(L) - \frac{n_R}{n}I(R)$ for each candidate; keep the argmax. If the best $\Delta \le 0$, stop — the node becomes a leaf.
  4. Recurse on $L$ and $R$ with $depth+1$.
  5. Stop when: max_depth is reached, the node is pure, the node has fewer than min_samples_split examples, or no split improves impurity.
  6. A leaf predicts the majority class (classification) or the mean target (regression).
  7. Pruning: grow deep, then remove subtrees whose contribution to held-out accuracy is negative — cost-complexity pruning minimises $R(T) + \alpha|T|$ over subtrees, with $\alpha$ chosen by cross-validation.

```text BUILD(node, depth): if depth == max_depth or pure(node) or n(node) < min_split: return leaf(majority_class(node)) best <- (0, None, None) for j in features: for t in midpoints(sorted unique values of column j): L, R <- partition(node, j, t) if |L| < min_leaf or |R| < min_leaf: continue gain <- I(node) - (|L|/n)*I(L) - (|R|/n)*I(R) if gain > best.gain: best <- (gain, j, t) if best.gain <= 0: return leaf(majority_class(node)) L, R <- partition(node, best.j, best.t) return Node(best.j, best.t, BUILD(L, depth+1), BUILD(R, depth+1)) ```

Complexity. Per node: $O(d\,N\log N)$ if thresholds are found by sorting once per feature (each split evaluation is $O(1)$ after prefix sums of class counts), or $O(dN^2)$ with the naive loop; depth $O(\log N)$ for balanced data, $O(N)$ worst case. Total training is $O(dN^2)$ for the naive version and $O(dN\log^2N)$ for the prefix-sum version. Prediction is $O(\text{depth})$, independent of $N$ — the property that kernel methods and $k$NN lack.

Derivations

1. The normal equations, and why they fail

Minimise $R(\mathbf{w}) = \|\mathbf{X}\mathbf{w}-\mathbf{y}\|^2 = \mathbf{w}^\top\mathbf{X}^\top\mathbf{X}\mathbf{w} - 2\mathbf{y}^\top\mathbf{X}\mathbf{w} + \mathbf{y}^\top\mathbf{y}$. Differentiating (M02, identity 1 with $\mathbf{A} = \mathbf{X}^\top\mathbf{X}$ symmetric):

$$\nabla R = 2\mathbf{X}^\top\mathbf{X}\mathbf{w} - 2\mathbf{X}^\top\mathbf{y} = 0 \;\Longrightarrow\; \mathbf{X}^\top\mathbf{X}\mathbf{w} = \mathbf{X}^\top\mathbf{y}.$$

If $\mathbf{X}$ has full column rank, $\mathbf{X}^\top\mathbf{X}$ is invertible and $\hat{\mathbf{w}} = (\mathbf{X}^\top\mathbf{X})^{-1}\mathbf{X}^\top\mathbf{y}$. Two structural facts follow immediately. The residual is orthogonal to the column space: $\mathbf{X}^\top(\mathbf{y}-\mathbf{X}\hat{\mathbf{w}}) = 0$, so this is the orthogonal projection of $\mathbf{y}$ onto $\mathcal{C}(\mathbf{X})$ (M01), and the fitted values are $\mathbf{X}\hat{\mathbf{w}} = \mathbf{P}\mathbf{y}$ with $\mathbf{P} = \mathbf{X}(\mathbf{X}^\top\mathbf{X})^{-1}\mathbf{X}^\top$ idempotent.

Where it fails. (i) Rank deficiency: duplicated or linearly dependent columns make $\mathbf{X}^\top\mathbf{X}$ singular, so $\hat{\mathbf{w}}$ is not unique. (ii) Conditioning: $\kappa(\mathbf{X}^\top\mathbf{X}) = \kappa(\mathbf{X})^2$, so a design with $\kappa = 10^4$ produces normal equations with $\kappa = 10^8$ and eight digits lost; the SVD route (M01, derivation 5) solves the same problem at $\kappa(\mathbf{X})$. (iii) Cost: forming $\mathbf{X}^\top\mathbf{X}$ is $O(Nd^2)$ and inverting is $O(d^3)$, unusable when $d$ is $10^6$.

2. Ridge in closed form, and lasso's exact zeros

Ridge. Add $\lambda\|\mathbf{w}\|^2$: $\nabla$ becomes $2\mathbf{X}^\top\mathbf{X}\mathbf{w} - 2\mathbf{X}^\top\mathbf{y} + 2\lambda\mathbf{w} = 0$, so

$$\hat{\mathbf{w}} = (\mathbf{X}^\top\mathbf{X}+\lambda\mathbf{I})^{-1}\mathbf{X}^\top\mathbf{y}.$$

Every eigenvalue of $\mathbf{X}^\top\mathbf{X}$ is shifted up by $\lambda$, so the condition number falls from $\lambda_{\max}/\lambda_{\min}$ to $(\lambda_{\max}+\lambda)/(\lambda_{\min}+\lambda)$ — the matrix is always invertible, and the solution is unique even under rank deficiency. In the SVD basis, $\hat{\mathbf{w}} = \sum_i \frac{\sigma_i}{\sigma_i^2+\lambda}\mathbf{v}_i\mathbf{u}_i^\top\mathbf{y}$: each singular direction is shrunk by the factor $\sigma_i^2/(\sigma_i^2+\lambda)$, which is near 1 for strong directions and near 0 for weak ones. That is exactly a soft filter on the spectrum, and it is why ridge behaves like a shrinkage estimator rather than a selector.

Lasso, coordinate-wise. For one coordinate with the others fixed, write the objective as a function of $w_j$ alone: $\sum_i(x_{ij}w_j - r_i)^2 + \lambda|w_j| + \text{const}$, where $r_i$ is the partial residual using the other coordinates. With $a = \sum_ix_{ij}^2$ and $\rho = \sum_ix_{ij}r_i$, the subgradient condition is

$$2aw_j - 2\rho + \lambda\,\partial|w_j| \text{ contains } 0, \qquad \partial|w_j| = \begin{cases}\{+1\} & w_j>0\\ \{-1\} & w_j<0\\ [-1,1] & w_j = 0\end{cases}$$

For $w_j > 0$: $2aw_j = 2\rho - \lambda$, requiring $\rho > \lambda/2$. For $w_j<0$: $\rho < -\lambda/2$. For $w_j = 0$: consistency requires $|2\rho| \le \lambda$. Combining, with $\lambda' = \lambda/2$ rescaled,

$$\hat w_j = \operatorname{sign}(\rho)\max\left(|\rho| - \lambda', 0\right) .$$

The max with zero is the whole story: whenever the correlation $|\rho|$ between the feature and the partial residual falls below the threshold, the coefficient is exactly zero, not merely small. Ridge's solution, $2aw_j - 2\rho + 2\lambda w_j = 0 \Rightarrow w_j = \rho/(a+\lambda)$, is zero only if $\rho$ is exactly zero.

3. Logistic regression: gradient, Hessian, and IRLS

With $p_i = \sigma(\mathbf{z}_i)$, $\mathbf{z} = \mathbf{X}\mathbf{w}$, the log-likelihood is $\ell = \sum_i[y_i\log p_i + (1-y_i)\log(1-p_i)]$. Using $\sigma'(z) = \sigma(z)(1-\sigma(z))$ and $\partial\ell/\partial p_i = y_i/p_i - (1-y_i)/(1-p_i) = (y_i-p_i)/(p_i(1-p_i))$,

$$\frac{\partial\ell}{\partial z_i} = \frac{y_i-p_i}{p_i(1-p_i)}\cdot p_i(1-p_i) = y_i - p_i,$$

the same collapse as M02's softmax identity, in the two-class case. Then $\nabla_{\mathbf{w}}\ell = \mathbf{X}^\top(\mathbf{y}-\mathbf{p})$.

For the Hessian, differentiate again: $\partial p_i/\partial z_i = p_i(1-p_i)$, so

$$\mathbf{H} = \frac{\partial}{\partial\mathbf{w}}\left[\mathbf{X}^\top(\mathbf{y}-\mathbf{p})\right] = -\mathbf{X}^\top\operatorname{diag}\left(p_i(1-p_i)\right)\mathbf{X} = -\mathbf{X}^\top\mathbf{W}\mathbf{X}.$$

$\mathbf{W}$ positive definite makes $\mathbf{H} \le 0$: the log-likelihood is concave, so any stationary point is the global maximum. Newton's step for maximisation is $\mathbf{w}_{t+1} = \mathbf{w}_t - \mathbf{H}^{-1}\nabla\ell = \mathbf{w}_t + (\mathbf{X}^\top\mathbf{W}\mathbf{X})^{-1}\mathbf{X}^\top(\mathbf{y}-\mathbf{p})$. Since $\mathbf{W}$ depends on $\mathbf{w}_t$, each iteration is a weighted least-squares solve — that is IRLS. Note the weight $p(1-p)$: confident examples get weight near zero, so they stop pulling the fit, which is what makes separable data drive the weights to infinity rather than to a finite optimum.

4. The SVM dual and the representer theorem

Primal. For labels $y_i\in\{-1,+1\}$ and a hyperplane $\mathbf{w}^\top\mathbf{x}+b = 0$, hard-margin SVM maximises the margin subject to correct classification:

$$\min_{\mathbf{w},b}\frac12\|\mathbf{w}\|^2 \quad\text{s.t.}\quad y_i(\mathbf{w}^\top\mathbf{x}_i+b)\ge1 \ \ \forall i .$$

Lagrangian. With multipliers $\alpha_i \ge 0$,

$$\mathcal{L}(\mathbf{w},b,\boldsymbol{\alpha}) = \frac12\|\mathbf{w}\|^2 - \sum_i\alpha_i\left[y_i(\mathbf{w}^\top\mathbf{x}_i+b)-1\right].$$

Stationarity in the primal variables:

$$\frac{\partial\mathcal{L}}{\partial\mathbf{w}} = \mathbf{w} - \sum_i\alpha_iy_i\mathbf{x}_i = 0 \;\Longrightarrow\; \mathbf{w} = \sum_i\alpha_iy_i\mathbf{x}_i, \qquad \frac{\partial\mathcal{L}}{\partial b} = -\sum_i\alpha_iy_i = 0 .$$

Dual. Substitute back. The $\|\mathbf{w}\|^2/2$ term becomes $\frac12\sum_{ij}\alpha_i\alpha_jy_iy_j\mathbf{x}_i^\top\mathbf{x}_j$, and by the stationarity relation it appears twice with opposite sign:

$$\mathcal{L} = \frac12\sum_{ij}\alpha_i\alpha_jy_iy_j\mathbf{x}_i^\top\mathbf{x}_j - \sum_{ij}\alpha_i\alpha_jy_iy_j\mathbf{x}_i^\top\mathbf{x}_j - b\underbrace{\sum_i\alpha_iy_i}_{=0} + \sum_i\alpha_i = \sum_i\alpha_i - \frac12\sum_{ij}\alpha_i\alpha_jy_iy_j\mathbf{x}_i^\top\mathbf{x}_j .$$

So the dual problem is

$$\max_{\boldsymbol{\alpha}\ge0}\ \sum_i\alpha_i - \frac12\sum_{ij}\alpha_i\alpha_jy_iy_j\langle\mathbf{x}_i,\mathbf{x}_j\rangle \quad\text{s.t.}\quad \sum_i\alpha_iy_i = 0 .$$

Three consequences. (i) The data enter only through inner products $\langle\mathbf{x}_i,\mathbf{x}_j\rangle$, so replacing them by $k(\mathbf{x}_i,\mathbf{x}_j)$ gives a nonlinear classifier for free — the kernel trick, exactly and only because of this dual form. (ii) KKT gives $\alpha_i[y_i(\mathbf{w}^\top\mathbf{x}_i+b)-1] = 0$, so only points on the margin have $\alpha_i>0$; these are the support vectors, and every other point is irrelevant to the solution. (iii) $\mathbf{w} = \sum_i\alpha_iy_i\mathbf{x}_i$ says the solution lies in the span of the data — the finite-dimensional case of the representer theorem, which extends it to any regularised risk in a reproducing kernel Hilbert space: the minimiser has the form $f^{*} = \sum_i\alpha_ik(\mathbf{x}_i,\cdot)$ regardless of the dimension of $\mathcal{H}$.

5. CART's criterion, from Gini and from entropy

For a node with class proportions $\mathbf{p}$, Gini impurity is $G = 1-\sum_kp_k^2$ — the probability that two independent draws from the node disagree. For a split with fractions $\pi_L = n_L/n$ and $\pi_R$,

$$\Delta_G = G(\text{parent}) - \pi_LG(L) - \pi_RG(R) .$$

Expand the two-class case to see what is actually being maximised. Write the parent's positive fraction as $p$ and the two children's as $p_L, p_R$. Since $G = 1 - p^2 - (1-p)^2 = 2p(1-p)$,

$$\Delta_G = 2p(1-p) - 2\pi_Lp_L(1-p_L) - 2\pi_Rp_R(1-p_R).$$

Now the entropy version. Define $H(p) = -p\log p - (1-p)\log(1-p)$; the impurity decrease is

$$\Delta_H = H(p) - \pi_LH(p_L) - \pi_RH(p_R) .$$

Both are special cases of a general impurity $I$ that is concave in $p$ and symmetric about $1/2$. The reason to prefer one is not correctness but convenience: Gini avoids logarithms and is marginally faster. And $\Delta_H$ has an information-theoretic identity worth knowing — it equals the mutual information between the split indicator $S$ and the label $Y$:

$$I(S;Y) = H(Y) - H(Y\mid S) = H(p) - \left[\pi_LH(p_L) + \pi_RH(p_R)\right] = \Delta_H,$$

using the M03 definition of mutual information. A tree that greedily maximises entropy decrease is greedily maximising the information each split reveals about the label.

Micro-check. Parent $(30,10)$, so $p = 0.75$ and $G = 0.375$. Split $(20,0)/(10,10)$: $\pi_L = 0.5$, $p_L = 1$, $p_R = 0.5$, so $\Delta_G = 0.375 - 0.5(0) - 0.5(0.5) = 0.125$. Split $(18,2)/(12,8)$: $p_L = 0.9$, $p_R = 0.6$, giving weighted Gini $0.45\cdot0.18 + 0.55\cdot0.48 = 0.345$ and $\Delta_G = 0.030$. The first split isolates a pure node and wins by a factor of four — the criterion's preference for purity, quantified.

6. The bias–variance decomposition, algebraically

Let $y = f(\mathbf{x}) + \varepsilon$ with $\mathbb{E}[\varepsilon] = 0$, $\mathrm{Var}[\varepsilon] = \sigma^2$, and let $\hat f = \hat f_D(\mathbf{x})$ depend on the training set $D$, with $\varepsilon$ independent of $D$. Write $\bar f = \mathbb{E}_D[\hat f]$. Then

$$\begin{aligned} \mathbb{E}_{D,\varepsilon}\left[(y-\hat f)^2\right] &= \mathbb{E}\left[(f+\varepsilon-\hat f)^2\right] \\ &= \mathbb{E}\left[(f-\hat f)^2\right] + 2\mathbb{E}\left[\varepsilon(f-\hat f)\right] + \mathbb{E}[\varepsilon^2] . \end{aligned}$$

The cross term vanishes because $\varepsilon$ is independent of $D$ and mean zero: $\mathbb{E}[\varepsilon]\cdot\mathbb{E}[f-\hat f] = 0$. The last term is $\sigma^2$. For the first, add and subtract $\bar f$:

$$\begin{aligned} \mathbb{E}\left[(f-\hat f)^2\right] &= \mathbb{E}\left[(f-\bar f + \bar f-\hat f)^2\right] \\ &= (f-\bar f)^2 + 2(f-\bar f)\,\mathbb{E}[\bar f - \hat f] + \mathbb{E}[(\bar f-\hat f)^2] \\ &= \mathrm{Bias}^2 + 0 + \mathrm{Var}(\hat f), \end{aligned}$$

since $\mathbb{E}[\bar f-\hat f] = \bar f-\bar f = 0$. Collecting:

$$\mathbb{E}\left[(y-\hat f)^2\right] = \sigma^2 + \mathrm{Bias}^2(\hat f) + \mathrm{Var}(\hat f).$$

The decomposition is exact, not approximate, and the three terms are genuinely independent knobs: noise is a property of the problem, bias of the model class, variance of the model class and the sample size.

7. Bagging's variance reduction, with correlation

Let $f_1,\ldots,f_B$ have common variance $\sigma^2$ and pairwise correlation $\rho$. Then

$$\begin{aligned} \mathrm{Var}\left(\frac1B\sum_b f_b\right) &= \frac{1}{B^2}\left[\sum_b\mathrm{Var}(f_b) + \sum_{b\ne c}\mathrm{Cov}(f_b,f_c)\right] \\ &= \frac{1}{B^2}\left[B\sigma^2 + B(B-1)\rho\sigma^2\right] = \frac{\sigma^2}{B} + \frac{B-1}{B}\rho\sigma^2 = \rho\sigma^2 + \frac{1-\rho}{B}\sigma^2 . \end{aligned}$$

Two limits: $B\to\infty$ leaves $\rho\sigma^2$, so averaging cannot beat correlation; $\rho = 1$ gives $\sigma^2$ for any $B$, so averaging identical models is pointless. Random forests subsample features precisely to reduce $\rho$, which is the only term in the formula that a practitioner can actually move. This is also why ensembles of independently trained neural networks help less than the naive $1/B$ suggests — they see the same data and are strongly correlated.

8. Gradient boosting is gradient descent in function space

Treat the model as a vector $F = (F(\mathbf{x}_1),\ldots,F(\mathbf{x}_N))$ in $\mathbb{R}^N$ and the loss as a function of that vector, $L(F) = \sum_i\ell(y_i, F_i)$. Ordinary gradient descent on $F$ would take $F \leftarrow F - \nu\nabla_F L$, i.e.

$$F_i \leftarrow F_i - \nu\,\frac{\partial\ell(y_i,F_i)}{\partial F_i} .$$

The negative gradient $r_i = -\partial\ell(y_i,F_i)/\partial F_i$ is the pseudo-residual. But $F$ must remain a function representable by the model class, so instead of stepping along $-r$ directly, fit a weak learner $h_t$ to the targets $r$ and step along its direction:

$$F_t = F_{t-1} + \nu h_t, \qquad h_t = \arg\min_{h\in\mathcal{H}}\sum_i\left(r_i - h(\mathbf{x}_i)\right)^2 .$$

That is gradient descent with the step direction constrained to $\mathcal{H}$ and the step length $\nu$. For squared loss, $\partial\ell/\partial F_i = F_i - y_i$, so $r_i = y_i - F_i$: the pseudo-residual is the residual, and "fit the next tree to the residuals" is exactly gradient descent. For logistic loss, $\partial\ell/\partial F_i = p_i - y_i$, so $r_i = y_i - p_i$ — the same $\mathbf{p}-\mathbf{y}$ that appears in M02 and in derivation 3, for the third time and the same reason. The shrinkage $\nu$ is a step size; the tree depth bounds the norm and smoothness of the step direction; and the number of rounds is the iteration count. One framework, three hyperparameters, no separate theory.

Implementation from scratch

A CART classifier with an exhaustive split search, Gini impurity, and a depth limit. Everything the derivations claim is visible in about fifty lines.

What to expect. The root splits on feature 0 at threshold $0.2$, isolating the two positive-class points, and a depth-2 tree reaches 100% training accuracy on this separable toy set. Print every node's gini before and after the split and you will see the decrease the algorithm is maximising. Two things worth breaking deliberately: set max_depth=1 and watch accuracy fall to $0.75$ (bias), then set min_leaf=1 with max_depth=None on noisy data and watch training accuracy go to 1.0 while nothing generalises (variance). The exhaustive search is $O(dN^2)$ here; sorting once per feature and using prefix sums of class counts makes it $O(dN\log N)$.

Common misconceptions

"Regularisation is about preventing the weights from getting large"

That is the mechanism, not the purpose. The purpose is to trade bias for variance, which the decomposition makes precise: a shrunk estimator is biased but may have much lower variance, and the sum is what matters. Ridge is a soft filter on the singular spectrum, not a magnitude cap; lasso is a selector, and the geometry is why it produces exact zeros rather than small numbers. A model with large weights and correct predictions is not thereby overfitted.

"A decision tree is interpretable, so it is the safe choice"

A single tree is interpretable and unstable: change one training point and the whole structure can change. Its predictions are also piecewise constant, so it cannot extrapolate — a tree trained on prices up to 100 predicts at most the largest leaf mean for a price of 1000. The interpretability is real but so is the variance, and bagging fixes the variance while destroying the interpretability. That is the honest trade, not a free lunch.

"Boosting and bagging both reduce variance"

They reduce different terms. Bagging averages correlated predictors and reduces variance with the bias essentially unchanged. Boosting fits successive models to the gradient, so it reduces bias (the model becomes more expressive as rounds accumulate) while its variance grows — which is why boosting needs shrinkage, shallow trees, and early stopping, and why it can overfit if run too long while bagging essentially cannot.

"ROC-AUC is the right summary for an imbalanced problem"

ROC-AUC is prevalence-invariant, which is a bug when the base rate is 1%: an excellent AUC can coexist with almost every positive prediction being wrong (0.8323 versus average precision 0.1610 above). PR-AUC's baseline is the prevalence, so it reflects the operational question. Neither is universally correct: ROC-AUC is the right comparison when prevalences genuinely differ between deployment populations.

"If the loss is lower, the model is better calibrated"

Loss and calibration are different properties. A model can have low cross-entropy and be badly calibrated in the tails, or be perfectly calibrated with a worse loss than a sharper model. Calibration is a property of the mapping from scores to probabilities, measurable with a reliability diagram, and fixable post hoc by isotonic or temperature scaling (M20) — which changes no ranking at all.

Core (do the math)

5.4 Derive the lasso coordinate solution and say what happens at $\rho = 0$.

Solution Minimise $aw_j^2 - 2\rho w_j + \lambda|w_j|$ over $w_j$. For $w_j>0$ the subgradient is $2aw_j-2\rho+\lambda = 0 \Rightarrow w_j = (\rho-\lambda/2)/a$, valid when $\rho>\lambda/2$. For $w_j<0$, $w_j = (\rho+\lambda/2)/a$, valid when $\rho<-\lambda/2$. Otherwise $w_j = 0$ with the subgradient condition $|2\rho|\le\lambda$ satisfied. Combining, $\hat w_j = \operatorname{sign}(\rho)\max(|\rho|-\lambda/2, 0)/a$. At $\rho = 0$ the solution is exactly 0 for any $\lambda>0$ — the feature is dropped entirely, not merely down-weighted.

5.5 Show that the entropy split criterion equals the mutual information between the split and the label.

Solution By definition, $I(S;Y) = H(Y) - H(Y\mid S)$. Conditioning on $S$ gives $H(Y\mid S) = \pi_LH(p_L) + \pi_RH(p_R)$, and $H(Y) = H(p)$ for the parent. So $I(S;Y) = H(p) - \pi_LH(p_L) - \pi_RH(p_R) = \Delta_H$. Consequently a tree that maximises entropy decrease is maximising how much each split tells you about the label — the same criterion as a decision-tree induction algorithm seeking information gain.

5.6 Derive the ridge solution in the SVD basis and show each direction is filtered by $\sigma_i^2/(\sigma_i^2+\lambda)$.

Solution With $\mathbf{X} = \mathbf{U}\mathbf{\Sigma}\mathbf{V}^\top$, $\mathbf{X}^\top\mathbf{X} = \mathbf{V}\mathbf{\Sigma}^2\mathbf{V}^\top$, so $(\mathbf{X}^\top\mathbf{X}+\lambda\mathbf{I})^{-1} = \mathbf{V}(\mathbf{\Sigma}^2+\lambda\mathbf{I})^{-1}\mathbf{V}^\top$. Then $\hat{\mathbf{w}} = \mathbf{V}(\mathbf{\Sigma}^2+\lambda\mathbf{I})^{-1}\mathbf{\Sigma}\mathbf{U}^\top\mathbf{y} = \sum_i\frac{\sigma_i}{\sigma_i^2+\lambda}\mathbf{v}_i(\mathbf{u}_i^\top\mathbf{y})$. Compare the unregularised $\sum_i\frac{1}{\sigma_i}\mathbf{v}_i(\mathbf{u}_i^\top\mathbf{y})$: the ridge version is the unregularised coefficient times $\sigma_i^2/(\sigma_i^2+\lambda)$, which is $\approx1$ for $\sigma_i^2$ far above $\lambda$ and $\approx\sigma_i^2/\lambda$ for $\sigma_i^2$ far below $\lambda$. Weak, noise-dominated directions are suppressed; strong ones pass almost unchanged.

Stretch (build or break it)

5.7 Construct a dataset on which kNN with $k=1$ achieves zero training error and 50% test error, and explain it with the curse of dimensionality.

Solution Take $N$ points uniform in $[0,1]^d$ with labels drawn as independent fair coin flips — pure noise, no signal. Any classifier's expected test error is 50%. 1-NN gets zero training error (the nearest neighbour of a training point is itself, distance 0, so the label is copied) and 50% test error, since the nearest *test* neighbour carries an independent label. Adding dimensions makes it worse in a specific way: the nearest neighbour's distance approaches the farthest, so the neighbour's label carries almost no information about the query, and the gap between training and test error is now structural rather than sample-size-related. This is the cleanest demonstration that zero training error is uninformative.

5.8 Show that a soft-margin SVM with hinge loss is equivalent to an unregularised linear classifier with an L2 penalty, and identify the parameter pairing.

Solution The soft-margin primal is $\min\frac12\|\mathbf{w}\|^2 + C\sum_i\xi_i$ subject to $y_i(\mathbf{w}^\top\mathbf{x}_i+b)\ge1-\xi_i$, $\xi_i\ge0$. Eliminating $\xi_i$ by substituting the minimal feasible value $\xi_i = \max(0, 1-y_i(\mathbf{w}^\top\mathbf{x}_i+b))$ gives the unconstrained problem $\min\frac12\|\mathbf{w}\|^2 + C\sum_i\max(0,1-y_if(\mathbf{x}_i))$ — hinge loss plus L2 regularisation, with $C$ playing the role of $1/\lambda$ (larger $C$, weaker regularisation). This is why an SVM is "just" a regularised linear classifier, and why the kernel trick applies equally to any loss whose solution admits the representer form.

5.9 Prove that the expected calibration error of a perfectly calibrated model is zero, and construct two models with identical ROC-AUC but different calibration.

Solution If $\mathbb{P}(y=1\mid \hat p = c) = c$ for every $c$, then in each bin the observed frequency equals the mean confidence, so every term in $\sum_b\frac{n_b}{N}|\text{acc}(b)-\text{conf}(b)|$ is zero. For the construction: let model $A$ output $\hat p = \sigma(s)$ and model $B$ output $\hat p' = \sigma(2s)$ where $s$ is any score. Both are monotone transforms of $s$, so they induce identical rankings and identical ROC-AUC, and identical PR-AUC. They differ only in the numbers: $B$ is sharper and therefore less calibrated if the true probability is $\sigma(s)$. Calibration is a property of the score *values*, discrimination of the score *order* — two independent properties of one model, and only one of them can be measured by AUC.

Answers 1. $\mathbf{X}^\top\mathbf{X}\mathbf{w} = \mathbf{X}^\top\mathbf{y}$. Fails under rank deficiency (no unique solution), under poor conditioning ($\kappa$ squares), and under scale ($O(Nd^2+d^3)$ time, $O(d^2)$ memory). 2. Geometrically, the lasso's diamond constraint has vertices on the axes and the error ellipse usually first touches a vertex; the ridge ball is round, so tangency is generic. Algebraically, the coordinate solution is $\operatorname{sign}(\rho)\max(|\rho|-\lambda/2,0)/a$, which is exactly zero for small $|\rho|$, while ridge gives $\rho/(a+\lambda)$, which is never exactly zero. 3. $\nabla\ell = \mathbf{X}^\top(\mathbf{y}-\mathbf{p})$; $\mathbf{H} = -\mathbf{X}^\top\mathbf{W}\mathbf{X}$ with $\mathbf{W} = \operatorname{diag}(p_i(1-p_i))$. Newton's step is a weighted least-squares solve with those weights, hence IRLS. 4. $\max_{\alpha\ge0}\sum_i\alpha_i - \frac12\sum_{ij}\alpha_i\alpha_jy_iy_j\langle\mathbf{x}_i,\mathbf{x}_j\rangle$ subject to $\sum_i\alpha_iy_i = 0$. The data appear only through inner products, so a kernel can replace them — the kernel trick — and the solution is supported only on the support vectors. 5. $I(S;Y) = H(Y)-H(Y\mid S) = H(p) - [\pi_LH(p_L)+\pi_RH(p_R)]$, which is exactly $\Delta_H$. 6. $\mathbb{E}[(y-\hat f)^2] = \sigma^2 + \mathrm{Bias}^2 + \mathrm{Var}$, obtained by adding and subtracting $\bar f = \mathbb{E}_D[\hat f]$ and using $\mathbb{E}[\bar f-\hat f] = 0$. Bagging reduces variance; boosting reduces bias. 7. $\rho\sigma^2 + (1-\rho)\sigma^2/B$; $B\to\infty$ leaves $\rho\sigma^2$, and $\rho=1$ leaves $\sigma^2$ for any $B$. 8. Because only 4% of examples are positive: with 30 TP, 20 FP, 10 FN, 940 TN, accuracy is 0.97 while precision is 0.60, and always predicting negative already scores 0.94.
