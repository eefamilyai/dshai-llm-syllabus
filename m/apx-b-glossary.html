Glossary

One crisp sentence per term, for the words papers use without defining.

on this page

How to use this glossary

Terms are alphabetical within each letter. Where a term has a contested meaning, the entry says so in the second clause — a definition that hides a dispute is worse than no definition. Module ids in parentheses point to the derivation.

A

Ablation — An experiment that removes one component of a method and re-measures, in order to attribute the result to that component. (M27) Absmax quantization — A symmetric quantization scheme whose scale is set by the largest absolute value in the tensor or group, so that no code is wasted on unreachable values but a single outlier compresses everything else. (M26) Activation checkpointing — Recomputing a layer's forward activations during the backward pass instead of storing them, trading roughly 30 percent more compute for a large reduction in memory. (M26) Activation function — The pointwise nonlinearity applied after an affine layer; without one, a stack of layers collapses to a single matrix. (M06) AdaGrad — An optimiser that divides each coordinate's learning rate by the square root of its accumulated squared gradient, which is monotone and therefore stalls on long runs. (M04) Adam — An optimiser combining momentum on the gradient (first moment) with a per-coordinate normalisation by the square root of the second moment, plus bias correction for the zero initialisation. (M04) AdamW — Adam with decoupled weight decay, applied as a direct shrinkage of the parameters rather than folded into the gradient, which is what makes the decay strength independent of the adaptive denominator. (M04) Affine quantization — Quantization with both a scale and a zero-point, mapping a float range onto integer codes so that zero is exactly representable. (M26) Agent — A system that interleaves model calls with actions in an environment, using observations to choose the next action, rather than producing a single response. (M22) Alignment tax — The claimed capability cost of making a model helpful and harmless; genuinely contested, because most reported taxes are not measured at matched tuning budgets. (M18, M29) Attention head — One of several parallel attention problems in a layer, each with its own query, key, and value projections into a lower-dimensional subspace. (M12) Attention mask — An additive matrix of $0$ and $-\infty$ applied to attention logits before the softmax, used to forbid positions (causal) or pad tokens. (M12) Attention sink — The empirical phenomenon in which the first few tokens absorb a large share of attention regardless of content, which is why they cannot be dropped from a cache without breaking the model. (M19) Autoregressive — Generating a sequence one token at a time, conditioning each token on all previous ones. (M15) Auxiliary loss — An extra term added to the training objective to shape intermediate behaviour, such as a mixture-of-experts load-balancing penalty. (M13)

B

Backbone — The shared trunk of a model that task-specific heads are attached to. (M13) Base model — A pretrained model before instruction tuning or preference tuning; it continues text rather than following instructions. (M17) Batch normalisation — Standardising each feature across the batch, then rescaling with learned parameters; batch-dependent, and therefore rarely used in sequence models. (M08) Beam search — A decoding procedure that keeps the $k$ highest-scoring partial sequences at each step, which maximises likelihood and often produces bland text. (M15) Bfloat16 — A 16-bit float with the exponent range of fp32 and 8 mantissa bits; the default for training because range matters more than precision there. (M26) Bits per byte (BPB) — A loss normalisation that divides by the bytes of underlying text, making it comparable across tokenizers with different vocabularies. (M14) Bradley–Terry model — A model of pairwise comparison in which the probability that one item beats another is a sigmoid of their score difference; the assumption behind reward models. (M18) Byte-pair encoding (BPE) — A tokenizer that starts from bytes and repeatedly merges the most frequent adjacent pair, growing the vocabulary one token per merge. (M14)

C

Calibration — The agreement between a model's stated confidence and its empirical accuracy; a model that says 80 percent and is right 80 percent of the time is calibrated. (M20) Capacity factor — In a mixture-of-experts layer, the multiplier on the average number of tokens per expert that sets each expert's buffer size; tokens beyond capacity are dropped. (M13) Catastrophic forgetting — The loss of previously acquired capability when a model is trained on a new distribution, the standard risk of narrow fine-tuning. (M17) Causal mask — The lower-triangular mask that prevents position $i$ from attending to positions $j>i$, enforcing that generation cannot see the future. (M12) Chain-of-thought — Prompting or training a model to produce intermediate reasoning steps before its answer, which improves accuracy on multi-step tasks. (M18) Chinchilla scaling — The compute-optimal allocation result that parameters and training tokens should grow together, at roughly 20 tokens per parameter. (M16) Compute-optimal — The $(N, D)$ pair that minimises loss for a fixed training compute budget. (M16) Continuous batching — A serving scheduler that admits and retires requests at every decoding step rather than in fixed batches, keeping the GPU busy at variable sequence lengths. (M19) Contrastive learning — Training by pulling representations of related pairs together and unrelated pairs apart, as in infoNCE. (M23) Convolution — A linear operation applying the same learned kernel at every spatial position, giving translation equivariance and parameter sharing. (M10) Cosine schedule — A learning-rate schedule that anneals from peak to near-zero along a half cosine, the default for language-model pretraining. (M04) Cross-entropy — The expected surprisal of the true distribution when coded with the model's predicted distribution; the standard classification and language-modelling loss. (M03)

D

Data contamination — The presence of benchmark items, or text from which they are reconstructible, in a model's pretraining data, which inflates the score without improving capability. (M20) Data parallelism — Replicating the model on every device and splitting each batch across them, synchronising gradients with an all-reduce. (M25) Dataset mixture — The weighting of domains or sources in a training corpus, which measurably changes downstream capability at fixed compute. (M16) Decoding — The procedure that turns a model's next-token distribution into a sequence: greedy, sampled, beam, or speculative. (M15) Deep double descent — The empirical curve in which test error rises, peaks at the interpolation threshold, and then falls again as model size increases. (M08) Diffusion model — A generative model trained to reverse a gradual noising process, learning to predict the noise added at each step. (M23) Distillation — Training a smaller model to match a larger model's output distribution rather than hard labels, transferring soft information as well as answers. (M26) DPO (Direct Preference Optimisation) — A preference-learning objective that reparameterises the RLHF reward in terms of the policy's log-ratio to a reference model, removing the separate reward model and the RL loop. (M18) Dropout — Randomly zeroing activations during training as a regulariser, which approximates an ensemble over subnetworks. (M08)

E

Early stopping — Halting training when validation loss stops improving, which is both a regulariser and a practical necessity. (M08) Effective batch size — The total number of examples contributing to one parameter update, including gradient accumulation, as distinct from the micro-batch that fits in memory. (M25) ELBO (evidence lower bound) — A tractable lower bound on the log-likelihood, equal to a reconstruction term minus a KL term to the prior; the objective behind VAEs and a template for variational methods. (M23) Embedding — A learned lookup table mapping discrete tokens to dense vectors, usually the largest single parameter block in a small language model. (M14) Emergent abilities — Capabilities that appear to appear abruptly as scale increases; the discontinuity is contested, since it depends on whether the metric is all-or-nothing or continuous. (M16, M29) Empirical risk minimisation — Choosing parameters that minimise average loss on the training sample, as a proxy for minimising expected loss. (M05) Entropy — The expected surprisal of a distribution, $-\sum_i p_i\log p_i$; for a language model's next-token distribution, a measure of its uncertainty. (M03) Epoch — One full pass over the training set. (M05) Evaluation harness — The code that runs a model over a benchmark, extracts answers, scores them, and reports uncertainty; differences between harnesses move scores by more than most methods. (M20) Expert — One of several independently parameterised feed-forward sub-networks in a mixture-of-experts layer, of which each token activates only a few. (M13) Exponential moving average (EMA) — A running average of parameters or gradients with geometric weights, used for momentum, adaptive optimisers, and evaluation-time weight averaging. (M04)

F

Feature (SAE feature) — A direction in activation space that a sparse autoencoder identifies as firing on a coherent concept; interpretable and often causally effective, but not thereby a mechanism. (M21) Few-shot prompting — Providing a handful of worked examples in the prompt, which lets a model perform a task without weight updates. (M15) Fine-tuning — Further training of a pretrained model on a narrower dataset or objective. (M17) FlashAttention — A fused, exact attention kernel that tiles the computation to keep intermediate matrices in on-chip memory, removing the quadratic memory traffic rather than the quadratic FLOPs. (M24) Floating point format — The exponent and mantissa split that determines range and precision; fp32 trains, bf16 is the training default, fp16 needs loss scaling, and fp8 is emerging for inference and some training. (M26) Forward pass — The computation from inputs to loss that stores the activations the backward pass will need. (M07) FSDP (fully sharded data parallel) — A data-parallel scheme that shards parameters, gradients, and optimiser state across devices and gathers each layer only when needed. (M25)

G

GAE (generalised advantage estimation) — An exponentially weighted sum of temporal-difference residuals, interpolating between low-variance/biased and high-variance/unbiased advantage estimates via $\lambda$. (M18) Generalisation gap — The difference between training and held-out loss or error; the quantity every capacity and regularisation decision ultimately targets. (M08) Global batch size — The number of examples across all devices in one optimiser step. (M25) GQA (grouped-query attention) — An attention variant in which several query heads share one key/value head, shrinking the KV cache by the group factor at a small quality cost. (M13) Gradient accumulation — Summing gradients over several micro-batches before stepping, which emulates a larger batch without the memory. (M26) Gradient clipping — Rescaling the gradient when its norm exceeds a threshold, preserving direction; the standard defence against loss spikes in language-model training. (M04) Grokking — Delayed generalisation, in which a model's training loss reaches zero long before its validation accuracy jumps, sometimes thousands of steps later; a small-scale phenomenon whose relevance at scale is contested. (M08) GRPO (Group Relative Policy Optimisation) — An RL objective that computes each sampled response's advantage relative to the mean and standard deviation of its own group, eliminating the critic model. (M18)

H

Hallucination — Fluent output that is not grounded in fact or in the provided context; a behaviour of the training objective, which rewards plausibility rather than truth. (M22) He initialisation — Weight initialisation with variance $2/n_{\text{in}}$, which preserves activation variance through ReLU layers by compensating for the half of units that are zeroed. (M08) Head — A task-specific output module attached to a backbone, such as a classification head or a language-modelling head. (M13) Held-out set — Data never used for any fitting decision, including hyperparameter selection, so that its error estimates something other than memorisation. (M20) Hidden state — A layer's internal activation, or in a recurrent network the summary of the sequence seen so far. (M11) Hyperparameter — A training setting not learned by gradient descent: learning rate, batch size, schedule, rank, and so on. (M04)

I

Implicit reward — In DPO, the quantity $\beta\log(\pi_\theta/\pi_{\text{ref}})$, which plays the role a reward model plays in RLHF. (M18) In-context learning — A model's ability to perform a task from examples in its prompt without any weight update. (M15) Induction head — An attention circuit that completes a pattern by attending to the token that followed a previous occurrence of the current token; the mechanism behind much of in-context copying. (M21) Inference — Running a trained model to produce outputs, in contrast to training. (M19) infoNCE — The contrastive objective that treats identifying the true paired sample among $K$ candidates as a $K$-way classification problem. (M23) Instruction tuning — Supervised fine-tuning on instruction-response pairs, which converts a text continuer into a responder. (M17) Interpolation threshold — The model capacity at which training error first reaches zero, the peak of the double-descent curve. (M08) Interpretability — The project of explaining a model's computation in human terms; the field distinguishes description (what correlates) from mechanism (what computes). (M21) IPO (Identity Preference Optimisation) — A preference objective that replaces DPO's log-sigmoid with a squared loss on the log-ratio difference, motivated by avoiding overfitting to deterministic preferences. (M18)

J

Jensen's inequality — For a concave function $f$, $\mathbb{E}[f(X)] \le f(\mathbb{E}[X])$; applied to $\log$ it produces the ELBO by moving the expectation inside. (M23)

K

Kernel (convolution) — The small learned weight tensor slid across an input, whose size defines the receptive field contributed per layer. (M10) Kernel (CUDA) — A function executed in parallel across many GPU threads; the unit of GPU work and the unit of GPU optimisation. (M24) Key-value cache (KV cache) — The stored keys and values of all previous tokens in a layer, which makes autoregressive decoding $O(T)$ per token instead of $O(T^2)$, at a memory cost linear in context and batch. (M19) KL divergence — A non-negative, asymmetric measure of how much one distribution costs relative to another; zero only when they are identical. (M03) KL penalty — A term pricing the divergence of the policy from a reference model, which is what keeps RL fine-tuning from drifting into degenerate high-reward text. (M18) Knowledge distillation — see distillation. (M26)

L

Label smoothing — Training against a softened target distribution instead of a one-hot vector, which limits overconfidence and improves calibration. (M05) Latency — The wall-clock time to complete a request, reported as a distribution (p50, p95, p99) rather than a mean. (M19) Layer normalisation — Standardising each example across its own feature dimension, then rescaling; batch-independent, which is why it dominates in transformers. (M08) Learning rate — The step size multiplier on the gradient; the single most consequential hyperparameter. (M04) Likelihood — The probability the model assigns to the observed data under its parameters; maximising it is equivalent to minimising cross-entropy. (M03) Linear attention — Any attention variant that avoids materialising the $T\times T$ score matrix, reducing cost from quadratic to linear in sequence length at some cost in expressiveness. (M13) Linear probing — Training a linear classifier on frozen representations to test what information they carry. (M21) Logit — The pre-softmax output of the final linear layer; a real number whose differences determine probability, not its magnitude. (M15) Logit lens — Reading intermediate residual-stream states by projecting them through the final unembedding, which shows how the model's prediction evolves across layers. (M21) LoRA (low-rank adaptation) — Freezing the base weights and learning a low-rank update $\mathbf{B}\mathbf{A}$ per adapted matrix, cutting trainable parameters by two to three orders of magnitude. (M17) Loss landscape — The geometry of the loss as a function of parameters; its curvature, saddle points, and sharp versus flat minima shape what optimisation can do. (M04)

M

Masked language modelling — Pretraining by predicting randomly masked tokens from their context, the objective behind BERT-style encoders. (M15) Master weights — The fp32 copy of parameters kept alongside the bf16 training copy so that small updates are not lost to rounding. (M26) Matrix multiplication — The dominant operation in every layer, and the reason GPUs and tensor cores exist; its cost is $2mnk$ FLOPs for an $m\times n$ by $n\times k$ product. (M24) Max-pooling — Downsampling by taking the maximum over each window, giving local translation invariance and a smaller feature map. (M10) MFU (model FLOPs utilisation) — Achieved model FLOPs per second divided by the hardware's peak; well-tuned large-scale training typically lands between 30 and 50 percent. (M25) Micro-batch — The subset of a global batch that fits in memory for one forward-backward pass. (M25) Mixed precision — Training with low-precision compute and higher-precision accumulation, which is faster and, with loss scaling, numerically safe. (M26) MLP (multilayer perceptron) — A stack of affine layers with nonlinearities; in a transformer, the feed-forward block that holds roughly two thirds of the parameters. (M06) Model collapse — Degradation of a model's output distribution after repeated training on its own generated data, most clearly demonstrated in toy recursions and contested in its severity at scale. (M29) MoE (mixture of experts) — A layer that routes each token to a subset of expert sub-networks, raising parameter count without raising per-token compute. (M13) Momentum — An exponential moving average of past gradients added to the update, which damps oscillation along steep directions and accelerates along consistent ones. (M04) Multi-head attention — Running several attention computations in parallel subspaces and concatenating their outputs, letting one layer attend to different relations at once. (M12) Multi-query attention — Attention in which all query heads share a single key/value head, the most aggressive KV-cache reduction before going cacheless. (M13)

N

NaN loss — A non-finite loss, almost always from a division by zero, an overflow in the softmax, or a learning rate that has destabilised the second moment. (M04) Negative sample — A non-matching item used to train a contrastive or retrieval objective. (M23) Next-token prediction — The pretraining objective: maximise the log-probability of each token given its prefix. (M15) NF4 (4-bit normal float) — A 4-bit quantization grid whose levels are quantiles of a normal distribution, so that the codes are equally likely under normally distributed weights. (M26) NLL (negative log-likelihood) — $-\log p(y\mid x)$; the loss whose average over a corpus, exponentiated, is perplexity. (M03) Noise schedule — In diffusion, the sequence of variance levels $\beta_t$ that governs how quickly signal is destroyed. (M23) Nucleus sampling (top-p) — Sampling from the smallest set of tokens whose cumulative probability exceeds $p$, which adapts the candidate count to the distribution's shape. (M15)

O

Off-policy — Learning from data generated by a policy other than the one being optimised, which is what makes experience replay and PPO's multiple epochs possible. (M18) One-hot vector — A vector with a single $1$ and zeros elsewhere, the hard target against which cross-entropy is computed. (M03) Online RLHF — Preference learning in which the policy is updated and re-sampled during training, as opposed to offline DPO on a fixed pair set. (M18) Optimiser — The update rule that turns gradients into parameter changes: SGD, momentum, AdaGrad, RMSProp, Adam, AdamW. (M04) Out-of-distribution (OOD) — Inputs drawn from a different distribution than the training data, where performance and calibration both degrade. (M20) Overfitting — Fitting the training sample's noise rather than its structure, visible as a widening gap between training and held-out loss. (M08)

P

Padding — Filling variable-length sequences to a common length so they can be batched; the reason naive batching wastes compute and paged caches exist. (M19) Paged attention — Storing the KV cache in fixed-size blocks indexed by a per-sequence block table, like virtual-memory paging, so that memory is allocated on demand and fragmentation disappears. (M19) PEFT (parameter-efficient fine-tuning) — Adapting a frozen pretrained model with a small number of new or selected parameters: LoRA, adapters, prefixes. (M17) Perplexity — The exponentiated mean negative log-likelihood, interpretable as the effective number of equally likely choices the model is deciding among. (M03) Pipeline parallelism — Splitting a model's layers across devices so that different micro-batches occupy different stages simultaneously, at the cost of a pipeline bubble. (M25) Policy — In RL, the distribution over actions given states; for a language model, the distribution over the next token. (M18) Policy gradient — The family of methods that estimate the gradient of expected reward with respect to policy parameters via the log-derivative trick. (M18) Positional encoding — Any mechanism that injects order into a permutation-invariant attention operation: sinusoidal, learned, relative, RoPE, ALiBi. (M12) Post-training — Everything after pretraining: supervised fine-tuning, preference tuning, reasoning RL. (M17) PPO (proximal policy optimisation) — A policy-gradient method whose clipped surrogate limits how far the new policy may move from the old one per update. (M18) Precision — The number of bits used to represent a number; distinct from range, and the distinction is why bf16 beats fp16 for training. (M26) Prefill — The compute-bound phase that processes the prompt and populates the KV cache, as distinct from the bandwidth-bound decode phase. (M19) Pretraining — Training on a large general corpus with a self-supervised objective, which produces the base model's capabilities. (M16) Projection — A learned linear map, usually between representation spaces, as in the $Q$, $K$, $V$, and output projections of attention. (M12) Prompt — The conditioning text supplied to a model at inference time. (M15)

Q

QLoRA — LoRA on top of a base model whose frozen weights are stored in 4-bit NF4 with per-block scaling, which puts fine-tuning of large models on a single GPU. (M17) Quantization — Representing weights or activations with fewer bits, trading numerical precision for memory and bandwidth. (M26) Quantization-aware training (QAT) — Simulating quantization during training so that weights adapt to the rounding they will experience at inference. (M26) Query, key, value — The three projections in attention: the query asks what is relevant, the key advertises what each position offers, and the value is what gets aggregated. (M12)

R

RAG (retrieval-augmented generation) — Supplying retrieved documents in the context so that generation can condition on external knowledge rather than parameters alone. (M22) Reference model — The frozen copy of the policy against which KL divergence is measured in RLHF and DPO. (M18) Rejection sampling — Generating several candidates and keeping the best-scoring one, a simple alternative to policy optimisation for preference tuning. (M18) Reranking — Re-scoring retrieved candidates with a stronger model before generation, which usually improves relevance more cheaply than a better retriever. (M22) Residual connection — Adding a sublayer's input to its output, which gives gradients an identity path and makes deep stacks trainable. (M08) Residual stream — The running sum that residual connections accumulate, viewed as a shared communication bus that every sublayer reads from and writes to. (M21) Reward hacking — Optimising a proxy reward in ways the designer did not intend, the central failure mode of RLHF and of any learned objective. (M18) Reward model — A model trained on preference pairs to score responses, used as the objective in RLHF. (M18) RLHF (reinforcement learning from human feedback) — Training a policy against a learned reward model with a KL constraint to a reference model. (M18) RLVR (RL with verifiable rewards) — Reinforcement learning in which the reward is computed by a checker, such as a unit test or an exact-answer comparison, rather than learned from preferences. (M18) RMSNorm — Normalisation by the root mean square of the features, without mean subtraction or bias; cheaper than layer norm and empirically equivalent in transformers. (M08) RMSProp — An optimiser that normalises each coordinate by a decaying average of squared gradients, fixing AdaGrad's monotone decay. (M04) Rollout — A sequence of actions and observations sampled from a policy, used as training data in RL. (M18) RoPE (rotary position embedding) — Encoding position by rotating query and key vectors in 2-D subspaces at position-dependent angles, so that dot products depend only on relative offset. (M12)

S

SAE (sparse autoencoder) — A model trained to reconstruct activations from a sparse, overcomplete dictionary of learned directions, used to extract candidate features. (M21) Sampling — Drawing the next token from the model's distribution rather than taking the argmax; the source of both diversity and error. (M15) Scaling law — An empirical power-law relationship between loss and parameters, data, or compute within a model family. (M16) Scheduler — The function mapping training step to learning rate: warmup, cosine, linear, inverse-square-root, WSD. (M04) Self-attention — Attention in which queries, keys, and values all come from the same sequence, letting positions interact. (M12) Self-consistency — Sampling several reasoning paths and taking a majority vote over final answers, which improves accuracy at proportional cost. (M18) SFT (supervised fine-tuning) — Training on demonstrations of desired behaviour, the step that turns a base model into an assistant. (M17) SGD (stochastic gradient descent) — Updating parameters with the gradient of a minibatch, the simplest optimiser and still the baseline. (M04) Softmax — The normalised exponential map from logits to probabilities; shift-invariant, so the max can be subtracted for stability. (M03) Speculative decoding — Drafting several tokens with a small model and verifying them in one pass of the large model, which accelerates decoding when the draft is often right. (M19) Superposition — Representing more features than there are dimensions by using nearly-orthogonal directions and tolerating interference; the geometric reason individual neurons are not features. (M21) Synthetic data — Training data generated by a model rather than collected from the world; useful, and contested in its long-run effect on distributional diversity. (M29) System prompt — Instructions supplied outside the user's turn, which shape behaviour across an entire conversation. (M22)

T

Temperature — A divisor on logits before the softmax: below 1 sharpens the distribution, above 1 flattens it, and 0 is equivalent to greedy. (M15) Tensor parallelism — Splitting individual weight matrices across devices, so each device computes a slice of every layer and the partial results are combined with all-reduce. (M25) Throughput — Work completed per unit time, usually tokens per second across all concurrent requests; distinct from latency, and the two trade against each other. (M19) Token — The unit of text a tokenizer produces: a subword, a byte, or a character, depending on the scheme. (M14) Tokenizer — The deterministic function mapping text to token ids and back, learned from a corpus and fixed at pretraining time. (M14) Top-k sampling — Restricting sampling to the $k$ most probable tokens, a fixed-width truncation that ignores the distribution's shape. (M15) Top-p sampling — see nucleus sampling. (M15) TPOT (time per output token) — The mean inter-token latency during decode, excluding the prefill; what a streaming user perceives as speed. (M19) Transformer — The architecture built from alternating attention and feed-forward sublayers with residual connections and normalisation, which processes a whole sequence in parallel. (M12) TTFT (time to first token) — The latency from request arrival to the first streamed token, dominated by queueing plus prefill. (M19)

U

Uncertainty — In evaluation, the interval around a measured quantity; in modelling, the distinction between aleatoric (data) and epistemic (knowledge) uncertainty. (M20) Underfitting — Failing to fit the training data, usually from insufficient capacity or excessive regularisation. (M08) Unembedding matrix — The final linear map from the residual stream to vocabulary logits, often tied to the input embedding. (M12)

V

VAE (variational autoencoder) — A generative model trained by maximising the ELBO, with an encoder approximating the posterior and a decoder reconstructing. (M23) Validation set — Data used for model selection and early stopping, distinct from the test set, which must be touched once. (M20) Value head — The critic's output estimating expected return from a state, used to compute advantages in PPO. (M18) Vanishing gradient — Exponential decay of gradients through depth or time, caused by repeated multiplication by Jacobians with spectral radius below one. (M11) ViT (vision transformer) — An image model that splits the image into patches and treats them as a token sequence for a standard transformer. (M23) Vocabulary size — The number of distinct tokens a tokenizer can emit, trading sequence length against embedding parameters. (M14)

W

Warmup — A short initial ramp of the learning rate, which stabilises adaptive optimisers whose second-moment estimates are unreliable in the first steps. (M04) Weight decay — An L2-like penalty shrinking parameters toward zero; decoupled from the gradient in AdamW. (M04) Weight tying — Sharing parameters between the input embedding and the output unembedding, which saves $Vd$ parameters and usually improves small models. (M14)

X

Xavier initialisation — Weight initialisation with variance $2/(n_{\text{in}}+n_{\text{out}})$, which preserves activation variance for symmetric activations such as tanh. (M08)

Y

YaRN — A context-extension method that combines NTK-aware frequency scaling of RoPE with an attention-temperature correction, extending usable context with limited fine-tuning. (M13)

Z

ZeRO (zero redundancy optimiser) — A family of sharding schemes that partition optimiser state, then gradients, then parameters across data-parallel devices so that no state is replicated. (M25) Zero-point — The integer code that represents exactly zero in affine quantization, which is what allows asymmetric ranges to be represented without waste. (M26) Zero-shot — Performing a task with no examples in the prompt, relying only on instructions and pretraining. (M15)
