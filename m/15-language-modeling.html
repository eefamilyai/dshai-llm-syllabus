Language Modeling and Decoding

From the chain rule to a single sequence, and why those are different problems.

on this page

Why this module exists

A language model is trained on one objective — predict the next token — and deployed on a different one: emit one particular sequence that a human will read. Almost every confusing property of LLM behaviour lives in that gap. Temperature has no meaning in training but decides whether the output is a poem or a loop; perplexity measures calibration over all continuations while your evaluation measures one realized string; greedy decoding is optimal for exactly the objective that produces bland, repetitive text. If you skip this module you will treat sampling parameters as folklore, believe that "the model's distribution" is what you get from an API, and have no way to reason about why beam search — which provably maximizes the thing the model was trained to maximize — produces worse text than a noisy sampler.

Prerequisites check

If two or more are shaky, revisit M12 and M03.

  1. Write $P(A,B)$ in terms of $P(A)$ and $P(B\mid A)$.
  2. What is the entropy of a distribution in the limit as it becomes uniform over $K$ outcomes?
  3. If $z_1 = 2$ and $z_2 = 0$, what is $\operatorname{softmax}(\mathbf{z})_1$?
  4. What does it mean for a function to be monotonically increasing, and why does it matter that $\exp$ is?
Answers 1. $P(A,B) = P(A)P(B\mid A)$. 2. $\log K$ — the maximum entropy for $K$ outcomes. 3. $e^2/(e^2+e^0) = 7.389/8.389 = 0.8808$. 4. $x \le y \Rightarrow f(x)\le f(y)$. Because $\exp$ is monotone, dividing logits by $T$ and exponentiating cannot reorder which token is most likely — only how sharply.

Learning objectives

  • Derive the autoregressive factorization from the chain rule and state exactly what independence assumption it does not make.
  • Show, with every step, that minimizing mean negative log-likelihood is minimizing cross-entropy, and write the decomposition into data entropy plus KL divergence.
  • Compute perplexity both as $\exp(L)$ and as the geometric mean of inverse token probabilities, and state three reasons two perplexity numbers may be incomparable.
  • Derive the effect of temperature on the distribution and on its entropy, including the sign and magnitude of $dH/dT$.
  • Implement top-$k$, top-$p$, min-$p$, and typical sampling, and explain what each preserves and destroys.
  • Derive the speculative-decoding acceptance rule and prove it is distribution-preserving, then compute the expected speedup as a function of acceptance rate and draft length.
  • Construct a logit mask for a grammar constraint and name the failure mode that arises when masks meet a tokenizer.

Core concepts

The autoregressive factorization

(1) Intuition. You do not need to model the probability of a whole sentence at once. You need to model the probability of the next word given everything before it, and then multiply. A sentence is built left to right, one conditional at a time.

(2) Formal definition. For any distribution over sequences,

$$p(x_1,\ldots,x_T) = \prod_{t=1}^{T} p(x_t \mid x_{

This is exact for every distribution on $\{1,\ldots,V\}^{T}$; it assumes nothing. It is a rewriting of the chain rule of probability, not an approximation.

(3) Why it is built this way. The alternative — a single $V^{T}$-way classifier — has a parameter count exponential in $T$. The factorization turns that into $T$ calls to one shared classifier over $V$ outcomes, which is what a transformer with a causal mask computes in parallel: $T$ conditionals in one forward pass, because position $t$ cannot attend to anything after $t$.

(4) Worked micro-example. Vocabulary $\{a,b\}$, $T=3$. There are 8 sequences. The autoregressive model needs 1 + 2 + 4 = 7 numbers (the conditionals for $a$, $aa$, $ab$, plus their complements). The tabular model needs 7 numbers too — at $T=3$. At $T=20$ the tabular model needs $2^{20}-1 = 1{,}048{,}575$ and the autoregressive model still needs $2^{20}-1$ if it memorizes, but with a shared parametric function it needs a fixed number of parameters and generalizes across prefixes. That difference is the entire reason neural LMs exist.

Training loss is mean negative log-likelihood is cross-entropy

(1) Intuition. The model outputs a probability for the token that actually came next. Training makes that probability bigger. Nothing else happens.

(2) Formal definition. Over a corpus of $N$ tokens,

$$\mathcal{L}(\theta) = -\frac{1}{N}\sum_{t=1}^{N}\log p_\theta(x_t \mid x_{

This is the mean negative log-likelihood, and it is the cross-entropy between the empirical one-hot label at each position and the model's distribution.

(3) Why it is built this way. Maximum likelihood is the statistically efficient estimator for a correctly specified model, and its log makes the product of conditionals a sum, which is what gradient descent needs. The mean (rather than the sum) makes the loss independent of corpus size, so learning rates transfer.

(4) Worked micro-example. Model outputs $\mathbf{p} = (0.6, 0.3, 0.1)$ and the true next token is the second. Loss $= -\log 0.3 = 1.204$ nats. Had the model said $(0.1,0.1,0.8)$, the loss at that position would be $-\log 0.1 = 2.303$. Every token contributes one such number, uniformly weighted, regardless of position.

Perplexity, exactly

(1) Intuition. Perplexity is "how many equally likely options is the model effectively choosing between at each step".

(2) Formal definition.

$$\mathrm{PP} = \exp(\mathcal{L}) = \exp\left(-\frac{1}{N}\sum_t \log p_t\right) = \left(\prod_{t=1}^{N}\frac{1}{p_t}\right)^{1/N}$$

(3) Why it is built this way. The geometric mean is the right average for a product of probabilities: it converts "multiply $N$ numbers" into "the equivalent per-step factor". A model that assigns uniform probability to $K$ options has $\mathrm{PP} = K$ exactly.

(4) Worked micro-example. Three tokens with probabilities $0.5, 0.25, 0.125$. $\mathcal{L} = (0.693+1.386+2.079)/3 = 1.386$ nats, $\mathrm{PP} = e^{1.386} = 4.0$. The geometric mean of $(2,4,8)$ is $4$. Exactly the branching factor you would have guessed. Limits, stated precisely: (i) it is per token, so it depends on the tokenizer (see M14); (ii) it depends on the corpus, so two corpora with different entropy give different floors; (iii) it measures calibration over the whole distribution at every position and says nothing about whether the top-ranked continuation is any good; (iv) it is dominated by the easy, high-frequency positions, so formatting and whitespace can move it more than reasoning.

The training floor is the entropy of the data and the excess is the KL divergence. Drag probability mass and watch all three numbers separate: only the cross-entropy term depends on the model.

The softmax bottleneck

(1) Intuition. The model's output is a matrix product between a $d$-dimensional hidden state and a $d$-dimensional embedding table. A product of two skinny matrices has low rank, and a low-rank matrix cannot express an arbitrary table of log-probabilities.

(2) Formal definition. With hidden states $\mathbf{H}\in\mathbb{R}^{N\times d}$ and output embeddings $\mathbf{W}\in\mathbb{R}^{d\times V}$, the log-probability matrix (before normalization) is $\mathbf{Z} = \mathbf{H}\mathbf{W}^{\top}$, so

$$\operatorname{rank}(\mathbf{Z}) \le \min(N, d, V) = d$$

(3) Why it is built this way. There is no choice: the output layer is a linear map from a $d$-dimensional residual stream. The consequence is a genuine capacity limit — the true conditional distribution of natural language is not rank-$d$ for any realistic $d$ — which is why mixture-of-softmaxes and larger $d$ help.

(4) Worked micro-example. $d = 4096$, $V = 50{,}257$. The model parameterizes a rank-4096 matrix of size $N\times V$. With $N = 10{,}000$ positions and 50,257 columns, the full matrix has $5\times10^{8}$ entries but only 4096 degrees of freedom per row. Any pattern of log-probabilities requiring more than 4096 independent directions across the vocabulary is unrepresentable — the residual stream would have to encode it, and it cannot.

Temperature

(1) Intuition. Divide the logits by a number before the softmax. Below 1 sharpens the distribution toward its mode; above 1 flattens it toward uniform. It cannot change which token is most likely, only how confidently.

(2) Formal definition.

$$p_i(T) = \frac{\exp(z_i/T)}{\sum_j \exp(z_j/T)}$$

(3) Why it is built this way. It is the temperature of the Boltzmann distribution: a single scalar that trades exploitation for exploration without touching the ordering. That is exactly what you want when the model is right about the ranking but wrong about the confidence.

(4) Worked micro-example. Logits $\mathbf{z} = (3.0, 1.5, 0.8, 0.2, -0.5, -1.2, -2.0)$:

$T$ $p_1$ $p_2$ $p_3$ $H$ $H/\log 7$
0.1 1.0000 0.0000 0.0000 0.000 0.000
0.5 0.9373 0.0467 0.0115 0.283 0.145
1.0 0.6912 0.1542 0.0766 1.027 0.528
2.0 0.4115 0.1944 0.1370 1.642 0.844
10.0 0.1856 0.1598 0.1490 1.933 0.994

At $T=10$ the distribution is nearly uniform and $H \to \log 7 = 1.946$; at $T=0.1$ it is a point mass. The effective number of choices moves from 1 to 6.9.

Drag the logits and the temperature. Watch three things at once: the bar heights, the entropy readout, and the cumulative-mass curve. Confirm that raising $T$ never reorders the bars — only their relative heights.

Truncation: top-$k$, top-$p$, min-$p$, typical

(1) Intuition. Temperature reshapes the whole distribution, including the 40,000 tokens you would never want. Truncation deletes them outright and renormalizes. The question each method answers is "which tokens are plausible here", and they answer it differently.

(2) Formal definition. All four produce $\tilde{p}_i \propto p_i \mathbf{1}[i \in S]$ for a support $S$:

  • Top-$k$. $S$ = the $k$ highest-probability tokens. Fixed size.
  • Top-$p$ (nucleus). Sort descending, let $c_i = \sum_{j\le i} p_{(j)}$, and take the smallest prefix with $c_i \ge p$; $S$ = that prefix. Adaptive size.
  • Min-$p$. $S = \{i : p_i \ge p_{\min}\cdot \max_j p_j\}$. Threshold relative to the peak.
  • Typical. Let $H = -\sum_i p_i\log p_i$. $S = \{i : |{-\log p_i} - H| \le \tau\}$, i.e. tokens whose surprisal is close to the entropy.

(3) Why it is built this way. Each fixes a failure of the previous one. Top-$k$ is size-fixed, so when the model is confident it keeps 40 implausible tokens as noise, and when it is uncertain it may cut off reasonable options. Top-$p$ adapts to confidence but can retain a long tail when the distribution is flat, and its support can shrink to 1 on a peaked distribution. Min-$p$ scales with the peak, so it keeps a rich set when the model is unsure and almost nothing when it is sure. Typical sampling addresses a subtler point: the typical set of a distribution is where the probability mass actually lives, and the highest-probability single token is often outside it.

(4) Worked micro-example. Sorted probabilities $(0.6912, 0.1542, 0.0766, 0.0420, 0.0209, 0.0104, 0.0047)$, cumulative $0.6912, 0.8455, 0.9221, 0.9641, 0.9850, 0.9953, 1.0$. Top-$p = 0.9$ keeps 3 tokens carrying 92.2% of the mass. Min-$p = 0.1$ keeps tokens with $p_i \ge 0.0691$, which is also 3 tokens here — but with $\mathbf{p} = (0.35, 0.30, 0.20, 0.15)$ min-$p=0.1$ keeps all 4 while top-$p=0.9$ keeps 4 as well, and with $(0.95, 0.02, 0.02, 0.01)$ min-$p=0.1$ keeps 1 while top-$p=0.9$ also keeps 1. The methods agree at extremes and diverge in the middle, which is where generation quality is decided.

Apply top-$k$, top-$p$, and min-$p$ to the same distribution. Watch which bars survive, how the mass is renormalized, and note that the same numeric threshold selects very different support sizes as the distribution's shape changes.

Repetition and frequency penalties

(1) Intuition. Sampling has no memory of what it already said, so it will happily loop. A penalty applied to the logits of already-emitted tokens makes a loop progressively more expensive.

(2) Formal definition. Given the set of tokens already generated with counts $c_i$, the CTRL-style repetition penalty with $\theta>1$ is

$$z_i' = \begin{cases} z_i/\theta & z_i > 0 \\ z_i\cdot\theta & z_i \le 0 \end{cases}$$

with frequency and presence penalties added linearly instead: $z_i' = z_i - \lambda_f c_i - \lambda_p \mathbf{1}[c_i > 0]$.

(3) Why it is built this way. Dividing positive logits and multiplying negative ones both move every seen token down in the ranking, regardless of sign — a plain subtraction would not, because logits are unbounded. The linear variants are additive in log-space, which makes them easy to reason about and to combine.

(4) Worked micro-example. $\theta = 1.2$, and the previously seen token has $z = 6.0$: $z' = 5.0$. A seen token with $z = -2.0$ becomes $-2.4$. With $\lambda_f = 0.5$ and a count of 4, the frequency penalty gives $z' = 6.0 - 2.0 = 4.0$ instead. Note the arithmetic consequence: at $\theta = 1.2$ a large positive logit is reduced by 17%, while at $\theta = 1.2$ a logit of 20 is reduced by 3.3 — the penalty is not scale-invariant, which is why heavy repetition penalties distort confident predictions.

Greedy decoding, beam search, and why beam search is unloved

(1) Intuition. Greedy takes the best token now. Beam search keeps the $b$ best partial sequences, hoping to find the whole sequence with the highest total probability. Both optimize the model's own score, and the model's own score is not what you want.

(2) Formal definition. Beam search maintains a set of $b$ hypotheses and at each step extends all of them and keeps the $b$ highest-scoring, where the score of a completed or partial sequence is

$$\text{score}(y) = \sum_{t=1}^{|y|}\log p_\theta(y_t\mid y_{

Length normalization divides by $|y|^{\ell}$ (typically $\ell = 1$ or a tuned $\alpha$) to prevent the systematic preference for short sequences that the unnormalized sum creates.

(3) Why it is built this way. For tasks with a nearly deterministic correct output — translation, transcription, code completion with one right answer — maximizing sequence probability is a reasonable proxy and beam search finds a better optimum than greedy. For open-ended generation there is no single correct sequence, and the highest-probability sequence under a model trained on a diverse corpus tends to be degenerate: bland, repetitive, and unrepresentative. This is the "beam search curse", documented experimentally: increasing beam width improves likelihood and degrades human-judged quality.

(4) Worked micro-example. Vocabulary $\{a,b\}$, $b=2$. Step 1: $p(a)=0.6$, $p(b)=0.4$. Extend both: $aa$: 0.36, $ab$: 0.24, $ba$: 0.24, $bb$: 0.16. Keep $aa$ and $\{ab, ba\}$ (tie). Greedy would commit to $a$ and never see that $bb$ might have a strong continuation — the beam recovers that at a cost of $b$ times the compute, and no guarantee about quality.

Constrained and structured decoding

(1) Intuition. If the output must be valid JSON, or must parse as a SQL query, or must match one of three labels, then any token that would make the output invalid should get probability zero. That is a mask on the logits.

(2) Formal definition. With a state machine (finite automaton, context-free grammar, or JSON schema parser) tracking which continuations are legal after the prefix generated so far, define $\mathbf{m}_t\in\{0,-\infty\}^{V}$ and sample from

$$\tilde{p} = \operatorname{softmax}(\mathbf{z}_t + \mathbf{m}_t)$$

(3) Why it is built this way. It removes the invalid mass before sampling, so the distribution you sample from is a valid distribution over valid continuations — no retry loop, no post-hoc repair. The cost is that the constrained distribution is generally not the model's distribution restricted to valid strings; it is a renormalization, and the two differ whenever the model's preferred continuation was invalid.

(4) Worked micro-example. Grammar requires {"label": " followed by one of pos/neg. At that position the logits over the vocabulary are masked to the tokens that begin pos or neg. In practice pos may be a single token and neg two, so the mask has 2 non--inf entries. Two implementation notes that bite: use a large negative number such as $-10^{9}$ rather than literal -inf, because -inf times a zero gradient produces NaN; and if a token straddles the grammar boundary (the token "pos includes a quote the grammar wants to place separately), you must either allow partial-token matches or apply token healing.

Speculative decoding

(1) Intuition. Small models are cheap and mostly agree with large models. Let a small draft model propose $\gamma$ tokens, then check all of them in a single forward pass of the large model — which costs about the same as generating one token, because decoding is memory-bandwidth-bound, not compute-bound. Accept the ones the large model agrees with; the result is exactly the large model's distribution.

(2) Formal definition. Target distribution $p$, draft distribution $q$. For each draft token $x$: draw $x\sim q$, accept with probability $\min(1, p(x)/q(x))$. If rejected, draw from $r(x)\propto\max(0, p(x)-q(x))$ and end the round. Repeat for up to $\gamma$ tokens per round.

(3) Why it is built this way. The accept/reject rule is the only rule that makes the output distribution exactly $p$ while using $q$ to save work. Any simpler scheme (accept if the ranks agree, accept with fixed probability) changes the distribution, and then you are no longer serving the model you trained.

(4) Worked micro-example. $p = (0.5, 0.3, 0.2)$, $q = (0.2, 0.5, 0.3)$. Acceptance probabilities: $\min(1, 0.5/0.2) = 1$, $\min(1, 0.3/0.5) = 0.6$, $\min(1, 0.2/0.3) = 0.667$. The rejection distribution: $\max(0, p-q) = (0.3, 0, 0)$, normalized to $(1,0,0)$. Check: $P(X=1) = \min(0.5,0.2) + 0.7\cdot1 = 0.2+0.7 = 0.9$? That is wrong, so the correction matters — the full rejection probability is $1-\sum\min(p,q)$, computed below in Derivation 4, and the arithmetic works out to exactly $p$. Do it there before trusting the intuition.

The algorithm, step by step

  1. Forward. Compute logits $\mathbf{z}_L\in\mathbb{R}^{V}$ for the final position from the KV cache; this pass is dominated by reading the weights, so its cost is nearly independent of how many positions you score.
  2. Mask. Add any constraint mask $\mathbf{m}$ and any repetition or frequency penalty.
  3. Temperature. Divide by $T$. If $T=0$, skip to the argmax.
  4. Truncate. Compute $S$ by the chosen rule (top-$k$, top-$p$, min-$p$, typical) and set the logits outside $S$ to a large negative number.
  5. Renormalize and sample. Compute $\operatorname{softmax}$ over $S$ and draw one index.
  6. Append. Append the sampled token, update the KV cache and the penalty bookkeeping, and repeat.

```text function DECODE(prompt, model, T, filter, max_new): cache <- model.prefill(prompt) logits <- model.last_logits() # (V,) out <- prompt repeat max_new times: z <- logits z <- apply_penalties(z, counts(out)) # repetition, frequency z <- apply_constraint_mask(z, parser_state) # -1e9 outside the grammar if T == 0: tok <- argmax(z) else: z <- z / T S <- support(filter, softmax(z)) # top-k / top-p / min-p / typical z <- where(S, z, -1e9) p <- softmax(z) tok <- sample(p) out.append(tok) logits <- model.step(tok, cache) # one position, cache reused return out ```

Complexity. Per generated token: $O(P)$ to read the weights plus $O(V)$ for the output head, plus $O(V\log V)$ if the filter sorts (top-$p$ does; top-$k$ needs only a partial selection, $O(V)$; min-$p$ is $O(V)$). Space: the KV cache is $2\cdot l\cdot n_{\mathrm{kv}}\cdot d_h\cdot L\cdot b$ bytes for $L$ positions and $b$ bytes per element. For $l=32$, $n_{\mathrm{kv}}=8$, $d_h=128$, $L=8192$, $b=2$: exactly 1.00 GiB.

Derivations

Derivation 1: mean NLL is cross-entropy, and its floor is the data entropy

Step 1 — maximum likelihood. The likelihood of a corpus under the factorized model is $\prod_t p_\theta(x_t\mid x_{

$$\arg\max_\theta \prod_t p_\theta(x_t\mid x_{

Dividing by $N$ does not move the argmin, so the trained $\theta$ is the same whether you optimize the sum or the mean. The mean is used so the loss scale does not depend on batch size.

Step 2 — it is a cross-entropy. Let $\delta_t$ be the one-hot distribution over $V$ tokens placing all mass on the observed token $x_t$. Then the cross-entropy between $\delta_t$ and the model is

$$H(\delta_t, p_\theta(\cdot\mid x_{

Averaging over positions, $\mathcal{L} = (1/N)\sum_t H(\delta_t, p_\theta)$. Mean NLL is mean cross-entropy; the two names refer to the same scalar.

Step 3 — decomposition. Since $H(\delta_t) = 0$ for a one-hot label,

$$H(\delta_t, p_\theta) = H(\delta_t) + D_{\mathrm{KL}}(\delta_t \,\|\, p_\theta) = D_{\mathrm{KL}}(\delta_t\,\|\,p_\theta) = -\log p_\theta(x_t\mid x_{

Step 4 — the population version. Let $p_{\text{data}}$ be the true distribution over token sequences. The expected loss is

$$\mathbb{E}_{x\sim p_{\text{data}}}\left[-\log p_\theta(x)\right] = H(p_{\text{data}}) + D_{\mathrm{KL}}(p_{\text{data}}\,\|\,p_\theta)$$

The first term does not depend on $\theta$, so training can only ever minimize the KL term, and the loss floor is $H(p_{\text{data}})$ — the entropy of the text itself. This is the precise sense in which lower loss means "closer to the data distribution", and the precise sense in which a loss of 2.0 nats cannot be interpreted without knowing the corpus.

Derivation 2: temperature changes entropy by $\mathrm{Var}_p(\mathbf{z})/T^{3}$

Write $\beta = 1/T$ so that $p_i = e^{\beta z_i}/Z$ with $Z = \sum_j e^{\beta z_j}$. First, the derivative of a single probability:

$$\frac{\partial p_i}{\partial \beta} = \frac{z_i e^{\beta z_i}Z - e^{\beta z_i}\sum_j z_j e^{\beta z_j}}{Z^{2}} = p_i\left(z_i - \sum_j p_j z_j\right) = p_i\left(z_i - \bar{z}\right)$$

where $\bar{z} = \mathbb{E}_p[z]$. Since $\partial\beta/\partial T = -1/T^{2}$,

$$\frac{\partial p_i}{\partial T} = -\frac{1}{T^{2}}p_i\left(z_i-\bar{z}\right)$$

Now differentiate the entropy $H = -\sum_i p_i\log p_i$:

$$\frac{dH}{dT} = -\sum_i \frac{\partial p_i}{\partial T}\left(\log p_i + 1\right) = \frac{1}{T^{2}}\sum_i p_i\left(z_i-\bar{z}\right)\left(\log p_i + 1\right)$$

Split the sum. The "$+1$" part is $\sum_i p_i(z_i-\bar{z}) = \bar{z}-\bar{z} = 0$. For the log part, substitute $\log p_i = \beta z_i - \log Z$:

$$\frac{dH}{dT} = \frac{1}{T^{2}}\sum_i p_i\left(z_i-\bar{z}\right)\left(\beta z_i - \log Z\right) = \frac{\beta}{T^{2}}\sum_i p_i\left(z_i-\bar{z}\right)z_i - \frac{\log Z}{T^{2}}\cdot 0$$

and the remaining sum is a variance:

$$\sum_i p_i\left(z_i-\bar{z}\right)z_i = \sum_i p_i z_i^{2} - \bar{z}\sum_i p_i z_i = \mathbb{E}[z^{2}] - \bar{z}^{2} = \mathrm{Var}_p(\mathbf{z})$$

Therefore

$$\frac{dH}{dT} = \frac{\beta}{T^{2}}\mathrm{Var}_p(\mathbf{z}) = \frac{\mathrm{Var}_p(\mathbf{z})}{T^{3}} \ge 0$$

So entropy increases with temperature, at a rate proportional to the variance of the logits under the current distribution and inversely to $T^{3}$. Two consequences: the effect is largest at small $T$ (where $1/T^{3}$ explodes, which is why small temperature changes matter a lot when sampling cold), and a distribution with all logits equal has zero variance so temperature does nothing at all — as it must.

The limits. As $T\to\infty$, $\beta\to0$, every $p_i\to1/V$, and $H\to\log V$. As $T\to0$, let $z_{\max}$ be the largest logit. Then

$$p_{\max} = \frac{1}{1+\sum_{j\ne\max}e^{(z_j-z_{\max})/T}} \to \frac{1}{1+0} = 1$$

because every exponent in the sum is negative and divided by a vanishing $T$. So the distribution collapses to the argmax and $H\to0$.

Derivation 3: what truncation does to the distribution

Let $S$ be the retained support and $Z_S = \sum_{i\in S}p_i$. The sampled distribution is $\tilde{p}_i = p_i/Z_S$ for $i\in S$ and zero elsewhere. Two facts follow immediately.

First, the expected value of any statistic $f$ changes: $\mathbb{E}_{\tilde p}[f] \ne \mathbb{E}_p[f]$ in general, and specifically the truncation raises the probability of everything retained by the factor $1/Z_S$. This is why "sampling with top-$p$" is not "sampling from the model" — it is sampling from a different distribution that shares the model's ranking on $S$.

Second, the KL cost of truncation is exactly the negative log of the retained mass:

$$D_{\mathrm{KL}}(\tilde p\,\|\,p) = \sum_{i\in S}\frac{p_i}{Z_S}\log\frac{p_i/Z_S}{p_i} = \log\frac{1}{Z_S} = -\log Z_S$$

So a top-$p$ of 0.9 that retains 0.9221 of the mass perturbs the distribution by $\log(1/0.9221) = 0.081$ nats. A high temperature (which flattens $p$ and lowers $p_{\max}$) tends to increase the retained mass for a fixed $p$ threshold, and therefore to reduce this distortion — which is the real reason "high temperature with top-$p$" behaves better than either alone.

Derivation 4: speculative decoding is exactly distribution-preserving

Step 1 — the rejection probability. Define the acceptance probability $a(x) = \min(1, p(x)/q(x))$ and the rejection probability mass

$$P(\text{reject}) = 1 - \sum_x q(x)a(x) = 1 - \sum_x \min(q(x), p(x))$$

Step 2 — an identity. Since $\sum_x p(x) = \sum_x q(x) = 1$, the total variation distance gives

$$\sum_x \min(p(x),q(x)) = 1 - \frac{1}{2}\sum_x|p(x)-q(x)|$$

and, because $(p-q)^{+} - (p-q)^{-} = p-q$ and these terms sum to zero overall,

$$\sum_x \max(0, p(x)-q(x)) = \sum_x \max(0, q(x)-p(x)) = \frac{1}{2}\sum_x|p(x)-q(x)|$$

Therefore

$$P(\text{reject}) = 1-\sum_x\min(p,q) = \sum_x\max(0,p(x)-q(x))$$

Step 3 — the corrected distribution. Define $r(x) = \max(0,p(x)-q(x))/P(\text{reject})$, a valid distribution by Step 2.

Step 4 — the output law. For any token $x$,

$$P(X=x) = q(x)\min\left(1,\frac{p(x)}{q(x)}\right) + P(\text{reject})\cdot r(x)$$

The first term is $\min(q(x), p(x))$. The second is $P(\text{reject})\cdot\max(0,p(x)-q(x))/P(\text{reject}) = \max(0,p(x)-q(x))$. Summing:

$$P(X=x) = \min(p(x),q(x)) + \max(0,p(x)-q(x)) = p(x)$$

using $\min(a,b) + \max(0,a-b) = a$. So the sampler emits exactly $p$ — not approximately, and regardless of how bad $q$ is. A bad draft model costs speed, never quality. This is the whole appeal.

Step 5 — how many tokens per round. If each draft token is accepted independently with probability $\alpha$ (a reasonable approximation when the draft model's per-token agreement is roughly constant), then the number accepted before the first rejection is geometric, and the round produces $1$ extra token from the correction step when it rejects. With $\gamma$ drafts offered, the expected number of tokens produced per target forward pass is

$$\mathbb{E}[\text{tokens}] = 1 + \alpha + \alpha^{2} + \cdots + \alpha^{\gamma} = \frac{1-\alpha^{\gamma+1}}{1-\alpha}$$

Step 6 — the speedup. One round costs one target step (1 unit) plus $\gamma$ draft steps at $c$ units each, so

$$\text{speedup}(\gamma) = \frac{1-\alpha^{\gamma+1}}{(1-\alpha)(1+\gamma c)}$$

This is maximized at a finite $\gamma$: the numerator saturates at $1/(1-\alpha)$ while the denominator grows linearly. Solving numerically:

$\alpha$ $c$ optimal $\gamma$ speedup $\lim_{\gamma\to\infty}$ bound
0.6 0.05 4 1.92 50.0
0.8 0.05 8 3.09 100.0
0.8 0.10 6 2.47 50.0
0.9 0.05 13 4.67 200.0
0.9 0.10 10 3.43 100.0

The bound column is $1/((1-\alpha)c)$, the asymptote if drafting were free — a useful reminder that the accept rate, not the draft model's speed, is the binding constraint once $c$ is small.

Implementation from scratch

```python import numpy as np def softmax(z, T=1.0): z = np.asarray(z, dtype=np.float64) / T z = z - z.max() # numerical stability e = np.exp(z) return e / e.sum() def filter_support(p, top_k=None, top_p=None, min_p=None, typical=None): """Return a boolean mask over the vocabulary of tokens to keep.""" keep = np.ones_like(p, dtype=bool) order = np.argsort(-p) if top_k is not None: # fixed-size support keep = np.zeros_like(keep) keep[order[:top_k]] = True if top_p is not None: # smallest prefix with mass >= top_p csum = np.cumsum(p[order]) n = int(np.searchsorted(csum, top_p) + 1) m = np.zeros_like(keep) m[order[:n]] = True keep &= m if min_p is not None: # threshold relative to the peak keep &= p >= min_p * p.max() if typical is not None: # |surprisal - entropy| <= typical H = -(p * np.log(p + 1e-300)).sum() keep &= np.abs(-np.log(p + 1e-300) - H) <= typical if not keep.any(): keep[np.argmax(p)] = True # never return an empty support return keep def sample(logits, T=1.0, rng=None, **filters): rng = rng or np.random.default_rng(0) if T == 0.0: # greedy return int(np.argmax(logits)) p = softmax(logits, T) keep = filter_support(p, **filters) p = np.where(keep, p, 0.0) p = p / p.sum() # renormalise over the retained support return int(rng.choice(len(p), p=p)) def kv_cache_bytes(n_layer, n_kv_head, d_head, n_pos, bytes_per_elem=2): """Two tensors (K and V) per layer, each n_kv_head x d_head x n_pos.""" return 2 * n_layer * n_kv_head * d_head * n_pos * bytes_per_elem if __name__ == "__main__": z = np.array([3.0, 1.5, 0.8, 0.2, -0.5, -1.2, -2.0]) for T in (0.5, 1.0, 2.0): p = softmax(z, T) print(f"T={T}: p={np.round(p, 4)} H={-(p*np.log(p)).sum():.4f}") print("top-k=3 ->", filter_support(softmax(z), top_k=3).astype(int)) print("top-p=.9 ->", filter_support(softmax(z), top_p=0.9).astype(int)) print("min-p=.1 ->", filter_support(softmax(z), min_p=0.1).astype(int)) print("KV GiB:", kv_cache_bytes(32, 8, 128, 8192) / 2**30) ```

What to expect. Three temperature rows matching the table in the temperature section, the three masks each showing three 1s for these logits (they agree here), and the KV-cache figure of exactly 1.0 GiB. Try logits np.log([0.95, 0.02, 0.02, 0.01]) to see the filters disagree: top-$k=3$ keeps 3, top-$p=0.9$ keeps 1, min-$p=0.1$ keeps 1.

Worked example

Decode one token from logits $\mathbf{z} = (3.0, 1.5, 0.8, 0.2, -0.5, -1.2, -2.0)$ with $T = 0.7$, top-$p = 0.9$, and a repetition penalty of $\theta = 1.2$ already applied to token 0 and token 1 (both with positive logits).

Step 1 — penalty. $z_0 = 3.0/1.2 = 2.5$, $z_1 = 1.5/1.2 = 1.25$. Others unchanged.

Step 2 — temperature. Divide by $0.7$: $(3.571, 1.786, 1.143, 0.286, -0.714, -1.714, -2.857)$.

Step 3 — softmax. Subtract the max $3.5714$ and exponentiate: $(1.0000, 0.1677, 0.0882, 0.0374, 0.0138, 0.0050, 0.0016)$, sum $= 1.3138$. So

$$\mathbf{p} = (0.7612,\ 0.1276,\ 0.0671,\ 0.0285,\ 0.0105,\ 0.0039,\ 0.0012), \qquad H = 0.8305$$

Step 4 — top-$p = 0.9$. Cumulative: $0.7612$, $0.8888$, $0.9560$ — crosses $0.9$ at the third token. So $S = \{0,1,2\}$ and the retained mass is $Z_S = 0.9560$.

Step 5 — renormalize. $\tilde{p} = (0.7963,\ 0.1335,\ 0.0702)$. Sample from that.

Step 6 — measure the distortion. $D_{\mathrm{KL}}(\tilde p\,\|\,p) = -\log Z_S = -\log 0.9560 = 0.0450$ nats. Small, because the model was confident: three tokens held 96% of the mass, so truncating changed almost nothing. Take the same penalized logits at $T = 1.5$ instead: the distribution flattens, four tokens are needed to reach $0.9$, and $Z_S$ rises to about $0.98$, moving the KL down further — higher temperature makes a fixed $p$ threshold less distorting, which is the quantitative version of "high temperature with top-$p$ behaves better".

Step 7 — temperature's effect on entropy. At $T=0.7$, $H = 0.8305$; at $T=1.0$, $H = 1.2229$; at $T=1.5$, $H = 1.5600$. The formula says the instantaneous rate is $\mathrm{Var}_p(\mathbf{z})/T^{3}$, which evaluates to $1.6432$ at $T=0.7$, $1.0040$ at $T=1.0$, and $0.4337$ at $T=1.5$ — the rate itself falls because $T^{3}$ grows faster than the variance. Check the formula against the finite difference: over $[1.0, 1.5]$ the observed slope is $(1.5600-1.2229)/0.5 = 0.6742$, and the trapezoid average of the two endpoint rates is $(1.0040+0.4337)/2 = 0.7189$. They agree to 6%, the residual being trapezoid error over an interval where the rate changes by a factor of 2.3. The formula is a derivative, not a linear law: reading entropy differences off it across a wide temperature range will mislead you.

Common misconceptions

"Temperature $0$ is greedy and temperature $1$ is the model's true distribution"

$T=1$ is the model's distribution before any truncation; once you apply top-$p$ or min-$p$ you are sampling from a renormalized distribution that differs by exactly $-\log Z_S$ in KL. And a scripted API's default "temperature 1" is typically combined with a default top-$p$ near 1, which still truncates the tail. Only an unmasked softmax with no penalty is the model's distribution.

"Beam search gives better text because it optimizes the objective"

It optimizes the objective better, and the objective is the wrong one for open-ended generation. Maximizing sequence likelihood selects the mode of a distribution over strings, and the mode of a language model trained on diverse text is a bland, self-repeating sequence. Human-judged quality typically peaks at small beam widths and declines after.

"Perplexity tells you how good the model is"

It tells you how well it predicts one corpus at one tokenization. A model can have excellent perplexity and be useless at following instructions, and a model fine-tuned on a narrow distribution can reduce perplexity on that distribution while getting worse at everything else. Perplexity is a compression measure, not a capability measure.

"Sampling parameters are cosmetic"

They change which distribution you draw from, and therefore the expected quality, diversity, and pass@1 of the system. Truncation changes the sampling distribution by a measurable KL divergence; temperature changes entropy at rate $\mathrm{Var}(\mathbf{z})/T^{3}$; repetition penalties distort confident predictions more than weak ones. These are the levers that decide whether a demo works.

"Constrained decoding gives you the model's distribution over valid outputs"

It gives you the model's distribution conditioned on the constraint by renormalization at each step, which is the same thing only when the model's preferred continuation was already valid. When the preferred token is masked, the mass moves to the next-best token, and the resulting text can be markedly less fluent than an unconstrained sample that happens to be valid. The correct comparison is to rejection sampling conditioned on validity, which is generally a different distribution.

"Speculative decoding trades a little quality for speed"

It trades nothing. Derivation 4 shows the output law is exactly $p$ for any draft distribution $q$. A draft model that agrees 10% of the time gives you almost no speedup; it never gives you worse text.

Warm-up (check understanding)

1. Six tokens with probabilities $0.5, 0.2, 0.1, 0.1, 0.05, 0.05$. Compute the loss and the perplexity.

2. Given $\mathbf{z} = (1,1,1,1)$, what is $dH/dT$ at any $T$, and why?

3. A distribution has $p_{\max} = 0.4$ and 200 other tokens with $p_i \approx 0.003$. Which of top-$k=10$, top-$p=0.9$, min-$p=0.1$ keeps the most tokens?

Solution 1. $\mathcal{L} = -(0.5\log 0.5 + 0.2\log 0.2 + 2(0.1\log 0.1) + 2(0.05\log 0.05)) = 0.3466 + 0.3219 + 0.4605 + 0.2996 = 1.4286$ nats, so $\mathrm{PP} = e^{1.4286} = 4.17$. Read it as the $p$-weighted geometric mean of the surprisals, $\exp(\sum_i p_i\log(1/p_i))$. Do not take the unweighted geometric mean: for these six tokens that would be $(2\cdot 5\cdot 10\cdot 10\cdot 20\cdot 20)^{1/6} = 8.58$, which is wrong because perplexity weights each surprisal by how often it occurs. 2. Zero, because all logits are equal so $\mathrm{Var}_p(\mathbf{z}) = 0$; the distribution is already uniform and temperature cannot change it. 3. Top-$p=0.9$: the mass above $p_{\max}$ accumulates slowly, so it retains roughly $0.4 + 0.5/0.003 \approx 167$ tokens. Top-$k=10$ keeps 10 by construction. Min-$p = 0.1$ requires $p_i \ge 0.04$, which no token except the first satisfies, so it keeps 1. Top-$p$ keeps by far the most.

Core (do the math)

4. Derive $dH/dT$ from scratch for two logits $z_1 = 0$, $z_2 = -\Delta$ and verify it against the formula $\mathrm{Var}_p(\mathbf{z})/T^{3}$.

Solution $p_1 = 1/(1+e^{-\Delta/T})$, $p_2 = e^{-\Delta/T}/(1+e^{-\Delta/T})$. Let $\sigma = p_1$. Then $H = -\sigma\log\sigma - (1-\sigma)\log(1-\sigma)$, and $d\sigma/dT = \sigma(1-\sigma)\Delta/T^{2}$. So $$dH/dT = (dH/d\sigma)(d\sigma/dT) = \log\frac{1-\sigma}{\sigma}\cdot\sigma(1-\sigma)\frac{\Delta}{T^{2}}$$ Now $\log((1-\sigma)/\sigma) = -\Delta/T$ (from the definition of $\sigma$), so $$dH/dT = -\frac{\Delta}{T}\sigma(1-\sigma)\frac{\Delta}{T^{2}}$$ Wait for the sign: $dH/d\sigma = \log((1-\sigma)/\sigma)$, and $\sigma > 1/2$ makes this negative, which would give negative $dH/dT$ — so check $d\sigma/dT$: as $T$ rises the distribution flattens and $\sigma \to 1/2$, so $d\sigma/dT < 0$ for $\sigma>1/2$. With $d\sigma/dT = -\sigma(1-\sigma)\Delta/T^{2}$, $$dH/dT = \log\frac{1-\sigma}{\sigma}\cdot\left(-\sigma(1-\sigma)\frac{\Delta}{T^{2}}\right) = \left(-\frac{\Delta}{T}\right)\left(-\sigma(1-\sigma)\frac{\Delta}{T^{2}}\right) = \frac{\Delta^{2}\sigma(1-\sigma)}{T^{3}}$$ And for two points, $\mathrm{Var}_p(z) = \sigma(1-\sigma)(z_1-z_2)^{2} = \sigma(1-\sigma)\Delta^{2}$, so this equals $\mathrm{Var}_p(\mathbf{z})/T^{3}$. Confirmed.

5. A draft model agrees with the target with per-token acceptance $\alpha = 0.75$ and costs $c = 0.08$. Compute the speedup for $\gamma \in \{1,2,4,8,16\}$ and identify the optimum.

Solution $\mathbb{E}[\text{tokens}] = (1-\alpha^{\gamma+1})/(1-\alpha) = 4(1-0.75^{\gamma+1})$. $\gamma=1$: $4(1-0.5625)=1.75$; denominator $1.08$; speedup $1.62$. $\gamma=2$: $4(1-0.4219)=2.312$; $1.16$; $1.99$. $\gamma=4$: $4(1-0.2373)=3.051$; $1.32$; $2.31$. $\gamma=8$: $4(1-0.0751)=3.700$; $1.64$; $2.26$. $\gamma=16$: $4(1-0.0075)=3.970$; $2.28$; $1.74$. The optimum is around $\gamma=5$–$6$ at roughly 2.33x. Note the asymptote: $\mathbb{E}[\text{tokens}] \to 4$, so the ceiling with $c=0.08$ is $4/(1+0.08\gamma)$, which is maximized at $\gamma=0$ — meaning the tradeoff is entirely about how much drafting you buy per round.

6. Prove that a repetition penalty of the form $z_i \mapsto z_i/\theta$ for $z_i>0$ is not scale-invariant, and show what that implies for two tokens with logits 4 and 20.

Solution The multiplicative change is $z/\theta$, so the *absolute* drop is $z(1-1/\theta)$, which grows with $z$; the *relative* drop is the constant $1-1/\theta$. In log-odds terms the penalty depends on the logit's magnitude, so a confidently-correct repetition (logit 20) loses $20(0.1667) = 3.33$ nats while a marginal one (logit 4) loses $0.667$. Since the softmax depends on logit differences, the penalty's effect on the *ranking* is therefore inconsistent: it can demote a highly confident token below a weak one when both are penalized. The additive frequency penalty $\lambda_f c_i$ has the opposite property — constant absolute shift, so it preserves differential structure and is easier to tune.

7. Show that the softmax bottleneck bounds the rank of the log-probability matrix by $d$, and compute the bound for a model with $d = 4096$ on a corpus of 10,000 positions.

Solution $\mathbf{Z} = \mathbf{H}\mathbf{W}^{\top}$ with $\mathbf{H}\in\mathbb{R}^{N\times d}$ and $\mathbf{W}\in\mathbb{R}^{V\times d}$. For any product $\mathbf{A}\mathbf{B}$ with $\mathbf{A}$ of rank $\le r_1$ and $\mathbf{B}$ of rank $\le r_2$, $\operatorname{rank}(\mathbf{A}\mathbf{B})\le\min(r_1,r_2)$; here both factors have rank at most $d$ since their inner dimension is $d$. So $\operatorname{rank}(\mathbf{Z})\le d = 4096$. For $N=10{,}000$ and $V=50{,}257$, the matrix has $5.03\times10^{8}$ entries but rank at most 4096, i.e. at most 4096 independent directions across the vocabulary dimension. Note the softmax normalization is a row-wise constant, which does not change the rank of the log-probabilities.

Stretch (build or break it)

8. Implement speculative decoding for a 3-token vocabulary and empirically verify that the output distribution matches $p$ to within sampling error, using a deliberately bad $q$.

Solution ```python import numpy as np rng = np.random.default_rng(0) p = np.array([0.7, 0.2, 0.1]) q = np.array([0.1, 0.1, 0.8]) # deliberately disagreeing draft def one_draw(): x = rng.choice(3, p=q) if rng.random() < min(1.0, p[x] / q[x]): return x r = np.maximum(0.0, p - q) return int(rng.choice(3, p=r / r.sum())) emp = np.bincount([one_draw() for _ in range(200_000)], minlength=3) / 200_000 print(np.round(emp, 4), "vs", p) ``` With 200k draws the empirical frequencies land within about 0.002 of $p$. The check that makes the proof concrete: $\sum\max(0,p-q) = 0.1 + 0.1 + 0 = 0.2$, and the rejection probability computed as $1 - \sum\min(p,q) = 1 - 0.8 = 0.2$ — they agree, which is the identity the proof rests on.

9. Build the logit mask for the constraint "the output must be one of the integers 1 to 5". What goes wrong if the tokenizer splits a number across tokens, and how do you fix it?

Solution At the first position, mask to tokens whose string is a prefix of some allowed string (`1`,`2`,`3`,`4`,`5`). Once a token is chosen, the constraint is satisfied, so subsequent positions are either all-masked-out (stop) or masked to an end-of-sequence token. Implementation: keep a set of allowed strings, track the string emitted so far, and at each step mask to tokens $u$ such that emitted+$u$ is a prefix of some allowed string, plus EOS if emitted is itself allowed. The problem: a tokenizer may encode `12` as a single token, or `1` and `5` as parts of multi-character tokens like `15` or `1.`; then the set of *tokens* that can start `1` includes strings that do not start with `1` as a character sequence, or vice versa. If the vocabulary contains no token equal to `5` (because `5` is always part of a longer token), the constraint is unsatisfiable. The fixes are (i) build the mask by matching on the token's decoded string, not its identity; (ii) use a tokenizer-aware trie so each grammar state maps to the set of legal token IDs; (iii) allow "token healing" — retract the last token and re-decode from a shorter prefix so a clean boundary is possible.
